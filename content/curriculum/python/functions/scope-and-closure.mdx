## 目的

本课建立名称解析模型：一个名字在某个位置被读到时，从哪里取值；一个函数被返回之后，它还能不能看到定义处的名字。

上一课处理了「调用如何把对象绑定到形参」。本课处理绑定发生在哪一层，以及函数对象在定义处的作用域离开之后如何继续访问那里的名字。理解这段模型之后，闭包、回调与装饰器的行为都可以逐步推出，而不是靠模式记忆。

## 模型

名称查找是运行期行为，按由内到外的顺序搜索四层作用域：

| 层 | 内容 | 何时存在 |
| --- | --- | --- |
| Local | 当前函数执行帧中绑定的名字 | 函数执行期间 |
| Enclosing | 外层函数的局部名，供内层函数读取 | 外层函数执行期间及其内层函数存续期间 |
| Global | 定义该函数的模块的命名空间 | 模块存活期间 |
| Builtin | 内建命名空间（`len`、`print` 等） | 解释器存活期间 |

两条规则决定了名字落在哪一层：

- **赋值使名字成为局部的**。函数体内任何位置的赋值（包括 `for` 目标、`with ... as`、`except ... as`、解包目标）都让该名字属于本函数，除非用 `global` 或 `nonlocal` 声明。函数体内的名称绑定在执行函数时建立，读取一个尚未绑定的局部名抛 `UnboundLocalError`。
- **函数对象带着它的定义作用域**。内层函数被返回后，外层帧已经结束，但内层函数通过闭包（closure）继续访问外层帧里的那些名字。捕获的是变量本身，不是当时的取值。

模块对象是全局层的载体：写在模块顶层的名字存放在模块的命名空间里，导入该模块的代码与模块内的函数看到的是同一个对象。

## 名称来自哪一层

```python run id="py.scope.resolution"
size = "module"


def show():
    size = "local"
    return size


print("inside:", show())
print("module:", size)
print("builtin fallback:", len("abcd"))
```

函数内的 `size = "local"` 让这个名字在本函数里成为局部名，模块层的 `size` 不受影响。`len` 在任何一层都没有绑定时由内建命名空间提供，因此可以直接调用；当前模块中给 `len` 赋值会遮蔽内建的那一个，这个遮蔽只影响该模块。

## 赋值使名字成为局部

```python run id="py.scope.unbound-local"
totals = [1, 2, 3]


def append_bad():
    try:
        totals.append(4)
        totals = []
    except UnboundLocalError as exc:
        print("UnboundLocalError:", exc)


append_bad()
print("module-level list is untouched:", totals)
```

`totals = []` 出现在函数体里，于是整个函数中的 `totals` 都是局部名；第一行的 `totals.append(4)` 读的是一个还没有绑定的局部名，抛 `UnboundLocalError`。加一行 `global totals` 才会读到模块对象，但这类写法通常说明设计需要重新划分状态归属。

## global 与 nonlocal

```python run id="py.scope.global-and-nonlocal"
counter = 0


def bump_global():
    global counter
    counter += 1


def make_counter():
    count = 0

    def bump():
        nonlocal count
        count += 1
        return count

    return bump


bump_global()
bump_global()
print("module counter:", counter)

first = make_counter()
second = make_counter()
print("first:", first(), first(), first())
print("second:", second())
```

`global` 让赋值作用于模块命名空间，`nonlocal` 让它作用于最近的外层函数帧。`make_counter` 的每次调用都产生新的 `count`，因此 `first` 与 `second` 各自累计，互不影响；这正是闭包捕获变量的直接后果。

## 闭包捕获变量

```python run id="py.scope.closure-cells"
def make_accumulator():
    running = []

    def add(value):
        running.append(value)
        return sum(running)

    return add


accumulate = make_accumulator()
print("results:", accumulate(1), accumulate(2), accumulate(3))
print("captured cells:", [cell.cell_contents for cell in accumulate.__closure__])
print("still reachable after the outer call returned:", accumulate(4))
```

`running` 属于 `make_accumulator` 的帧。外层调用返回后帧本身已经结束，但列表对象被闭包引用着，因此继续存活；`accumulate.__closure__` 里的 cell 就是这个引用。闭包延长的是被引用的对象的存活期，而不是整个帧。

## 延迟绑定

被捕获的是变量，读取发生在函数真正被调用时，因此同一变量上的多次修改对已创建的所有函数都可见。

```python run id="py.scope.late-binding"
functions = [lambda value: f"{index}:{value}" for index in range(3)]
print("late binding:", [function("x") for function in functions])

def make_formatter(index):
    return lambda value: f"{index}:{value}"


early = [make_formatter(index) for index in range(3)]
print("captured per call:", [function("x") for function in early])

with_defaults = [lambda value, index=index: f"{index}:{value}" for index in range(3)]
print("captured by default argument:", [function("x") for function in with_defaults])
```

循环变量 `index` 只有一个，三个 lambda 都捕获了它，调用时它已经是 2。用具名工厂函数把当前值绑定到那次调用的形参，或用默认参数在定义时求值，都得到每次迭代自己的值。默认参数方案把绑定时机提前到定义时，代价是签名上多了一个不该出现在公共接口里的参数。

## 边界与失败情形

- **类体不是外层函数作用域**：类体有自己的命名空间，但方法不会把它当作 enclosing 层，因此方法体里不能直接读到类体的名字，只能通过 `self`、类名或模块名访问。
- **推导式有自己的作用域**：推导式内绑定的名字不会泄漏到外层；推导式是隐式函数，因此在类体中写的推导式同样读不到类体的名字。
- **模块全局名对所有函数可见且可变**：把一个模块级容器当作跨函数状态，是隐式共享状态，跨调用、跨请求都会累积。
- **`global` 不创建名字**：只声明归属；名字仍要由赋值产生。
- **`nonlocal` 必须有外层绑定**：找不到外层帧里的同名绑定时抛 `SyntaxError`，而不是运行期错误。
- **闭包延长对象存活期**：被捕获的大对象随函数对象存活，长生命周期回调会因此持有本可释放的内存。
- **重复定义同名函数不报错**：后一个定义直接覆盖前一个，闭包与默认值都随之替换。
- **递归深度由实现决定**：超过限制抛 `RecursionError`，该限制是实现配置而非语言约定（见 <CrossRef id="python.runtime-vs-language" />）。

## 小结

- 名称按 Local → Enclosing → Global → Builtin 顺序查找，查找发生在运行期。
- 函数体内任何位置的赋值都让名字成为局部名；读未绑定的局部名抛 `UnboundLocalError`。
- `global` 与 `nonlocal` 声明赋值作用于哪一层，不创建名字。
- 闭包捕获变量而不是值，并通过 cell 引用延长这些对象的存活期。
- 延迟绑定使循环中创建的函数在调用时看到循环变量的最终值；用工厂函数或默认参数绑定当前值。
- 类体与推导式不构成外层函数作用域，方法读不到类体的名字。
