`def resize(width: int, height: int) -> int` 声明参数与返回值都是 `int`。给 `width` 传入 `"abc"`，类型检查器会拒绝这次调用：`str` 与 `int` 不一致；解释器不读标注，照常把 `"abc"` 绑定到 `width` 并返回一个字符串。

```python run id="py.typing.not-enforced"
def resize(width: int, height: int) -> int:
    return width * height


print(resize(3, 4))
print(resize("abc", 4))
try:
    resize(3)
except TypeError:
    print("missing argument: call binding failed")
```

检查器拒绝 `resize("abc", 4)`，运行时的乘法把 `"abc"` 重复成 `"abcabcabcabc"`。少传一个参数的调用抛 `TypeError`，来自 <CrossRef id="python.call-semantics" /> 的参数绑定规则，与标注无关。文中标出的静态错误都是类型契约的推导；浏览器单元格运行 Python，不运行静态检查器。

## 标注写下的契约

标注描述参数、返回值、容器元素与可空性，供检查器在运行前核对。`int` 标注不限制取值范围：正数、非空、单位一致这类业务不变量仍要在代码里单独建立。标注也不创建值，类体里单写 `label: str` 只记录一条标注，不会产生一个属性。

## Any 与 object

`object` 表示任意 Python 对象，但只允许依赖所有对象共有的操作。`Any` 让检查器接受任意操作与类型赋值，在该处停止核对（见 [typing：Any](https://docs.python.org/3.14/library/typing.html#the-any-type)）。两种标注都能接收字符串，之后的推理能力不同：

```python
from typing import Any


def unchecked(value: Any) -> int:
    return value + 1      # Any 使检查器接受这条数据流


def unknown(value: object) -> int:
    return value + 1      # 静态错误：object 没有承诺数值加法
```

`unchecked("text")` 会在运行时失败：字符串没有整数加法。把未知数据标成 `object`，要求代码在使用前提供证据；标成 `Any`，允许代码跳过这一步。`Any` 常用于与缺少类型信息的代码交接，需要在这里接受检查器不再核对。

## union 与收窄

联合类型（union）`int | None` 表示值可能属于两种情形。收窄（narrowing）是检查器依据分支条件缩小当前可能类型集合的过程：

```python run id="py.typing.narrowing"
def increment(value: int | None) -> int:
    if value is None:
        return 0
    return value + 1


def describe(value: object) -> str:
    if isinstance(value, str):
        return value.upper()
    return "not text"


print(increment(None), increment(4))
print(describe("hello"), describe(4))
```

`None` 分支返回后，剩余路径上的 `value` 为 `int`，加法才有依据。`isinstance` 分支把 `object` 收窄为 `str`，于是字符串方法可用。分支既提供静态证据，也在运行时选择路径；单写标注或 `typing.cast` 不会执行这种验证。

## 外部数据与业务约束

外部数据的静态类型来自 API 声明，不证明实际值满足业务要求。`os.environ` 声明为字符串键、字符串值的映射（见 [os：environ](https://docs.python.org/3.14/library/os.html#os.environ)）；JSON 解析结果可以包含数字、布尔值、列表、映射与空值，声明类型不覆盖取值范围。

```python run id="py.typing.validation"
def parse_limit(raw: str) -> int:
    value = int(raw)
    if not 1 <= value <= 100:
        raise ValueError("limit must be in 1..100")
    return value


for raw in ("12", "abc", "0"):
    try:
        print(repr(raw), "->", parse_limit(raw))
    except ValueError as failure:
        print(repr(raw), "->", type(failure).__name__)
```

三个输入都满足 `str` 契约，只有一个满足 `1..100` 的业务约束。解析检查表示是否有效，范围检查建立领域不变量。静态检查回答「依据声明，这段代码的类型使用是否一致」；运行时校验回答「这次实际输入是否满足前提」。跨越不可信数据边界时，需要后者的证据。

## 更进一步的静态关系（可选）

标注还能表达更强的静态关系：泛型（generic）把参数的输入类型与返回值的类型关联起来，方差（variance）规定可变容器的元素类型不能仅凭子类型关系互相赋值，Protocol 按成员与签名判断兼容性而不要求继承。这些标注服务的仍是检查器；运行时同样不读取它们，容器元素被写入之后发生什么，由真实的别名与数据决定。完整定义见 [类型规范：泛型与方差](https://typing.python.org/en/latest/spec/generics.html) 与 [typing 模块](https://docs.python.org/3.14/library/typing.html)。

## 实现边界

标注本身是可以被运行时工具读取的数据，例如库据此生成字段或接口，但读取不等于在调用时强制。标注表达式的求值时机属于版本敏感行为：Python 3.14 默认延迟求值，需要内省时用官方 API `annotationlib.get_annotations()`（见 [annotationlib](https://docs.python.org/3.14/library/annotationlib.html) 与 [标注最佳实践](https://docs.python.org/3.14/howto/annotations.html)）。

```python run id="py.typing.introspection"
from annotationlib import get_annotations


def parse(text: str) -> list[int]:
    return [int(part) for part in text.split()]


print(get_annotations(parse))
```

本例使用 Python 3.14 的 API。读取并求值标注不等于校验一次调用；维护其他版本的内省工具时按该版本文档选择读取方式。
