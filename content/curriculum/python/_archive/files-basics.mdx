程序退出后，内存里的数据随之消失。把结果写进文件，下次运行时读回来，是数据跨运行留存的最简方式。

## 打开、读写与关闭

`open(path, "w", encoding="utf-8")` 打开文件用于写入，`open(path, "r", encoding="utf-8")` 用于读取，两者都返回一个文件对象。把一段文本写进去，再读回来：

```python run id="py.files.text"
text = "first line\nsecond line\ncafé\n"

with open("notes.txt", "w", encoding="utf-8") as handle:
    written = handle.write(text)

with open("notes.txt", "r", encoding="utf-8") as handle:
    content = handle.read()

print("write returned the number of characters:", written)
print("closed after the block:", handle.closed)
print("read back:", repr(content))
```

`write` 返回写入的字符数；`read` 读回的是 `str`，内容与写入的字符串一致，`repr` 让换行在输出里可见。文件对象持有一个操作系统的文件句柄，进程能同时打开的句柄数有限，所以文件用完必须关闭；`with` 在块结束时关闭它，块内抛出异常时同样关闭。文本模式负责在磁盘字节与字符串之间做一次转换，这套模型见 <CrossRef id="python.text-and-bytes" />；`with` 的进入与退出协议见 <CrossRef id="python.context-managers" />。

## 按行读写

文件对象是可迭代的，`for line in handle` 一次给一行，行尾的换行符保留在字符串里：

```python run id="py.files.lines"
with open("notes.txt", "w", encoding="utf-8") as handle:
    handle.writelines(["alpha\n", "beta\n", "gamma\n"])

with open("notes.txt", "r", encoding="utf-8") as handle:
    for line in handle:
        print("line:", repr(line))

with open("notes.txt", "r", encoding="utf-8") as handle:
    first = handle.readline()
    rest = handle.read()

print("readline:", repr(first))
print("read gets the rest:", repr(rest))
```

`writelines` 接收一个字符串序列，不额外插入换行，换行符要自己写在每一项里。`readline()` 读一行，`read()` 读剩下的全部，`read()` 不带参数会把整个文件读进内存；大文件按行迭代或分批读。

## 失败情形

```python run id="py.files.failures"
try:
    open("missing-file.txt", "r", encoding="utf-8")
except FileNotFoundError as failure:
    print("missing file:", type(failure).__name__, "-", failure)

with open("notes.txt", "w", encoding="utf-8") as handle:
    handle.write("café")

try:
    with open("notes.txt", "r", encoding="ascii") as handle:
        handle.read()
except UnicodeDecodeError as failure:
    print("wrong encoding:", type(failure).__name__, "-", failure.reason)
```

两类失败发生在不同的步骤：文件不在路径上时 `open` 抛 `FileNotFoundError`；文件存在但其中的字节不能按 `encoding` 解码时，读的时候抛 `UnicodeDecodeError`。相对路径按进程的工作目录解析，脚本被从别处调用时数据文件应按调用方传入，或与调用方约定路径。
