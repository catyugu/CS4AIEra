`outer = [inner, 3]` 中 `outer[0]` 与 `inner` 是同一个列表。对同一个 `outer` 分别做浅拷贝与深拷贝，再向 `inner` 追加一个元素：浅拷贝跟着变，深拷贝不变。

## 别名、浅拷贝与深拷贝

```python run id="py.copy.depth"
import copy

inner = [1, 2]
outer = [inner, 3]

shallow = copy.copy(outer)
deep = copy.deepcopy(outer)

inner.append(99)

print("outer:  ", outer)
print("shallow:", shallow)
print("deep:   ", deep)
print("shallow[0] is inner:", shallow[0] is inner)
print("deep[0] is inner:   ", deep[0] is inner)
```

浅拷贝新建了外层列表，元素 `inner` 仍是同一个对象：`inner.append(99)` 在 `outer` 与 `shallow` 中都可见，在 `deep` 中不可见。`shallow[0] is inner` 为真，浅拷贝停在第一层；`deep[0] is inner` 为假，深拷贝复制到了内层。判断共享范围只需两个问题：两个名字是否指向同一对象（`is`），以及通过一个名字写入后另一个名字是否观察到变化。

复制停在哪一层由操作决定：

| 操作 | 效果 |
| --- | --- |
| `b = a` | 增加一个指向同一对象的名字 |
| `copy.copy(a)`、`a[:]`、`list(a)`、`dict(a)` | <Term id="shallow-copy">浅拷贝</Term>：新建外层容器，元素仍是原来的引用 |
| `copy.deepcopy(a)` | <Term id="deep-copy">深拷贝</Term>：递归复制到最内层，副本与原件不再共享可变对象 |

分片、`list(x)`、`dict(x)`、`copy.copy(x)` 都只复制一层，嵌套的元素继续共享：`a[:] is a` 为假，`a[:][0] is a[0]` 为真。复制不等于新建：对不可变对象，`copy.copy` 允许返回同一个对象，判断隔离始终用 `is`。不可变容器的不可变性只覆盖元素绑定，不覆盖元素指向的对象：`t = ([1], 2)` 上的 `t[0].append(3)` 合法。

## 重复引用与构造顺序

乘法的操作数决定复制的是什么。`[x] * n` 重复引用，推导式每次迭代重新求值。

```python run id="py.copy.repetition"
grid = [[0] * 3] * 3
rows = [[0] * 3 for _ in range(3)]

print("grid rows identical:", grid[0] is grid[1])
print("rows distinct:     ", rows[0] is not rows[1])

grid[0][0] = 1
rows[0][0] = 1
print("grid:", grid)
print("rows:", rows)
```

`grid` 的三行是同一个列表，写入第一行等于写入全部三行。`rows` 的每一行是独立求值得到的列表，写入只影响一行。只读时两者行为相同。

## 同一模式的其他出现位置

「定义时求值一次，此后所有使用者共享同一个对象」不只在复制里出现：函数的默认值、类属性、模块顶层的容器都是同一个形状。默认值的求值时机由 <CrossRef id="python.call-semantics" /> 建立，类属性与实例属性各自存在哪个对象上，由 <CrossRef id="python.classes" /> 建立；两者都让状态的存活期超出单次调用，修正方式也都是在单次调用或单个实例内构造容器。

迭代容器时修改它会让迭代跳过或重复元素，这是迭代协议的直接后果，由 <CrossRef id="python.iteration-protocol" /> 建立并给出修法。
