`a = [1, 2]` 之后执行 `b = a`，再通过 `b.append(3)` 追加一个元素：打印 `a`，得到 `[1, 2, 3]`。把 `b.append(3)` 换成 `b = [7]`，打印 `a`，得到的仍是 `[1, 2]`。两句都改变了 `b` 看到的内容，只有一句改变了 `a` 看到的内容。

区分这两种效果的，是名称与对象之间的指向关系。名称是命名空间里的一项绑定，它指向某个对象；数据存放在对象里。一条赋值只改变名称指向哪个对象，不修改任何对象。判断一段代码里谁看得到哪次改动，方法是画出这张指向图：哪些名称指向哪个对象，改动发生在对象上还是发生在名称上。

## 名称、对象与别名

```python run id="py.names.binding"
a = [1, 2]
b = a
b.append(3)
print("a =", a)
print("b =", b)
print("a is b:", a is b)

b = [7]
print("a =", a)
print("b =", b)
print("a is b:", a is b)
```

`b = a` 没有复制列表，它把 `b` 绑定到 `a` 已经指向的那个列表，两个名称指向同一个对象。`b.append(3)` 修改的是这个对象，因此从 `a` 或 `b` 读到的都是 `[1, 2, 3]`，`a is b` 为真。`b = [7]` 求值右边的字面量，创建了一个新列表，然后只把 `b` 重绑定到它；`a` 仍绑定在原来的列表上，`a is b` 变为假。

这张图里的对象有三个属性：身份（identity）、类型（type）、值（value）。身份在对象的整个存活期内不变，两个存活的对象身份不同，`id(x)` 给出身份对应的整数。名称是命名空间中的一项绑定。语句 `name = expr` 分两步执行：先求值 `expr` 得到一个对象，再把当前命名空间中的 `name` 绑定到该对象；执行前后没有任何对象被改写。读取名称是解引用，取回它当前指向的对象。两个名称指向同一对象时，称它们互为<Term id="alias">别名</Term>。

由此，操作分成两类：

| 操作 | 形式 | 效果 |
| --- | --- | --- |
| 修改对象 | `x.append(1)`、`x.sort()`、`x[k] = v` | 所有指向该对象的名称都观察到变化 |
| 重绑定名称 | `x = expr` | 只有被重新绑定的那个名称改变指向 |

链式赋值 `a = b = []` 把两个名称绑定到同一个列表，`a.append(1)` 之后 `b` 也是 `[1]`；需要两个独立容器时，写两条独立的赋值。`del name` 删除的是名称本身，不影响其他名称：对象只有在没有任何引用之后才被回收。`b = a[:]`、`list(x)`、`dict(d)` 消除的是外层容器的别名，元素仍然共享，子图的复制深度由 <CrossRef id="python.mutability-and-copy" /> 处理。

## 不可变对象只重绑定

`int`、`float`、`str`、`tuple` 不提供原地修改的操作。所有看起来在改它们的语句都产生新对象并把名称重绑定过去。

```python run id="py.names.immutable"
s = "ab"
t = s
s = s + "c"
print("s =", s)
print("t =", t)
print("s is t:", s is t)
print("lengths:", len(s), len(t))
```

`t` 保持 `"ab"`：`s + "c"` 创建了第三个字符串对象，`s` 换指它，`t` 的绑定没有变。对不可变对象，上表只剩重绑定这一行。

## 身份与相等

`is` 与 `==` 回答两个不同的问题：

| 表达式 | 判据 | 说明 |
| --- | --- | --- |
| `x is y` | 是否同一个对象 | 由语言保证：对存活对象，`is` 为真当且仅当身份相同 |
| `x == y` | 两个值是否相等 | 通常从 `x.__eq__(y)` 开始；默认实现比较身份，类可以重新定义 |

```python run id="py.names.identity"
x = [1, 2]
y = [1, 2]
z = x
print("x == y:", x == y)
print("x is y:", x is y)
print("x is z:", x is z)


class Tagged:
    pass


t = Tagged()
print("t == Tagged():", t == Tagged())
print("t is t:", t is t)
```

`x` 与 `y` 内容相同但是两个对象，`==` 为真而 `is` 为假。`z` 是 `x` 的别名，`x is z` 为真。自定义类没有定义 `__eq__` 时，相等退化到身份比较：`Tagged()` 的每个实例只与自身相等。判断两个名称是否指向同一对象用 `is`，判断两份内容是否相等用 `==`。

## 函数边界

函数调用按对象绑定传参：实参对象被绑定到形参名。同一个对象因此可能在调用方和函数内被两个名称指向。

```python run id="py.names.arguments"
def grow(values):
    values.append(99)


def replace(values):
    values = values + [99]


data = [1]
grow(data)
print("after grow:   ", data)
replace(data)
print("after replace:", data)
```

`grow` 通过形参修改了 `data` 指向的对象，调用方看到 `[1, 99]`。`replace` 只在函数内把形参重绑定到新对象，调用方的 `data` 不变。两个函数的签名相同，接口语义不同：形参是否会原地修改实参属于接口约定的一部分，这条约定从签名看不出来，只能写进文档，或用返回新对象、传入副本、返回不可变视图来体现在代码里。
