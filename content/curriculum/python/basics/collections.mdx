同一段程序里常同时需要几种分组：一组数要有先后、还能在末尾追加；一对确定后不再改动的 (宽, 高)；一条按字段名取值的记录；一批要去掉重复的地址。`list`、`tuple`、`dict`、`set` 各自覆盖其中一种，选哪一个由数据的访问方式与可变性决定。

| 容器 | 字面量 | 有序 | 可变 | 主要用途 |
| --- | --- | --- | --- | --- |
| 列表 `list` | `[1, 2]` | 是 | 是 | 有顺序、会变化的序列 |
| 元组 `tuple` | `(1, 2)` | 是 | 否 | 不可变序列，常用作固定结构的记录 |
| 字典 `dict` | `{"a": 1}` | 插入序 | 是 | 按键查找的映射 |
| 集合 `set` | `{1, 2}` | 否 | 是 | 去重与成员判断 |

## 列表

```python run id="py.collections.list"
items = [3, 1, 2]
items.append(4)
print(items)

items.sort()
print(items)
print(items[0], items[-1], items[1:3], len(items))
print(sorted([3, 1, 2]), [1, 2] + [3])
```

`append` 在末尾追加，`sort` 原地排序并返回 `None`，`sorted` 返回新列表。列表支持索引、切片、拼接与 `len`；下标越界抛 `IndexError`。写 `items = items.sort()` 会把 `items` 变成 `None`，原地方法不返回新容器。

## 元组与解包

```python run id="py.collections.tuple"
point = (3, 4)
print(point[0], len(point))

x, y = point
print(x, y)
print((1, 2) == (1, 2))
```

元组不可变，适合表示字段固定、不再改动的记录；相等比较看内容，`(1, 2) == (1, 2)` 为真。解包把序列中的元素一次绑定到多个名字。

## 字典

```python run id="py.collections.dict"
person = {"name": "Ada", "year": 1815}
print(person["name"], person.get("year"))
print(person.get("missing"), person.get("missing", "unknown"))

person["field"] = "computing"
print(person)
print(list(person.keys()), list(person.items()), len(person))
print("name" in person)
```

`person[key]` 在键不存在时抛 `KeyError`；`get` 返回 `None` 或指定的默认值。`in` 判断键是否存在。`items()` 一项给出一个 `(键, 值)` 元组，`list()` 展开后即可看到全部条目。键必须可哈希：列表与字典不能作键，元组在元素都可哈希时可以，相等与哈希的契约见 <CrossRef id="python.equality-and-hashing" />。

## 集合

```python run id="py.collections.set"
seen = {1, 2, 2, 3}
print(sorted(seen), len(seen))
print(sorted({1, 2} | {2, 3}))
print(sorted({1, 2} & {2, 3}))
```

集合自动去重，支持并集 `|` 与交集 `&`。集合没有下标，元素的顺序不受规定，查看内容时用 `sorted()` 排好序。

## 嵌套与选择

```python run id="py.collections.nested"
orders = [
    {"id": 1, "total": 250},
    {"id": 2, "total": 120},
]
print(orders[0]["id"], orders[0]["total"])
print(orders[1]["total"], orders[0]["total"] + orders[1]["total"])
print("total" in orders[0], len(orders))
```

列表里放字典是常见的记录集合形式：列表提供顺序，字典提供字段名。按字段取值比按位置取值更容易读懂与修改。

按用途选择容器：需要顺序与下标用列表；需要按键查找用字典；需要去重或集合运算用集合；需要不可变序列，或字段固定的记录，用元组。
