## 目的

本课解释整数与小数上的算术运算，以及它们各自的结果类型。

数值是程序里最常见的值。运算符在两种数值类型上的行为基本一致，但除法与取模有必须记住的规则。

## 模型：运算符

| 运算 | 符号 | 结果 |
| --- | --- | --- |
| 加、减、乘 | `+` `-` `*` | 两数同为 `int` 时是 `int`，任一为 `float` 时是 `float` |
| 除法 | `/` | 总是 `float` |
| 整除 | `//` | 向下取整的商 |
| 取模 | `%` | 余数，符号跟随除数 |
| 幂 | `**` | 幂运算 |

```python run id="py.numbers.operators"
print(7 + 3, 7 - 3, 7 * 3)
print(7 / 3)
print(7 // 3, 7 % 3)
print(2 ** 10)
print(10 / 4, 4 / 2)
print(2 + 3.0)
```

`7 / 3` 得到 `2.3333333333333335`。能整除时 `/` 也返回小数：`4 / 2` 是 `2.0`。整数与小数混合运算得到小数。

## 整除与取模的符号

```python run id="py.numbers.floor-mod"
print(-7 // 3, -7 % 3)
print(7 // 3, 7 % 3)
print(-7 % 3, 7 % -3)
```

`//` 向下取整，不是向零截断，因此 `-7 // 3` 是 `-3`。余数由恒等式 `a == (a // b) * b + a % b` 决定，所以 `%` 的结果符号跟随除数：`-7 % 3` 是 `2`，`7 % -3` 是 `-2`。

这条恒等式是判断奇偶、把值映射到固定范围（例如把秒数折算成分钟内的秒）的依据。

## 类型转换

```python run id="py.numbers.conversion"
print(int(3.7), int(-3.7))
print(float(3))
print(int("42"))
print(round(2.5), round(3.5))
```

`int()` 向零截断，`int(-3.7)` 是 `-3`。`float(3)` 得到 `3.0`。`int("42")` 解析文本。

`round()` 使用「四舍六入五成双」：`round(2.5)` 是 `2`，`round(3.5)` 是 `4`。它取最近的偶数，处理金额时会造成意外。

## 小数的表示

```python run id="py.numbers.float-approximation"
print(0.1 + 0.2)
print(1 / 3)
print(0.1 + 0.2 == 0.3)
```

`0.1 + 0.2` 得到 `0.30000000000000004`，与 `0.3` 的相等比较为 `False`。小数在计算机里用二进制近似表示，多数十进制小数无法精确存储。完整的模型由后续课时给出；当前需要记住的结论是：测量与科学计算用小数，金额与精确计数用整数。

## 边界与失败情形

- **除零**：`1 / 0`、`1 // 0`、`1 % 0` 都抛 `ZeroDivisionError`。
- **精度有限**：小数的有效位数固定，超过后相邻整数不再可区分。
- **`int()` 不接受小数字符串**：`int("3.5")` 抛 `ValueError`，先 `float("3.5")` 再取整。
- **整数没有上限**：整数运算精确，代价是内存与时间随位数增长。
- **跨类型比较按数值**：`1 == 1.0` 为真。
- **浮点除零不报错**：`1.0 / 0` 抛 `ZeroDivisionError`，但 `float("inf")` 这类特殊值可以参与运算并产生 `nan`。

## 生产后果

- 金额、计数与标识符用整数，以最小单位计；测量值用小数。
- `/` 总是返回小数，把结果用作索引或计数前必须显式取整，否则抛 `TypeError`。
- 指标聚合中的小数误差会累积，跨系统对账需要固定舍入规则与统计口径。
- 时间、货币与百分比换算容易落在整除与取模的符号规则上，负值场景尤其如此。

## 小结

- `/` 总是返回 `float`；`//` 向下取整；`%` 的符号跟随除数，且 `a == (a // b) * b + a % b` 恒成立。
- `int()` 向零截断，`round()` 五成双。
- 小数是二进制近似，相等比较不可靠；金额与计数用整数。
- 整数没有上限，运算精确。
- 除零抛 `ZeroDivisionError`。
