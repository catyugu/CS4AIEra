程序需要记住中间结果，这件事由名字完成。赋值语句把名字与值关联起来，之后用这个名字取回那个值。

## 模型：赋值

赋值语句 `name = expression` 分两步：先求值右边的表达式，再把左边的名字绑定到结果。

- 右边先算完，左边再更新，因此 `x = x + 1` 使用的是旧值。
- 名字可以反复赋值，指向的值可以换类型；`a = b` 让两个名字指向同一个值，赋值不复制数据。
- 名字在赋值之前使用会抛 `NameError`。
- 名字由字母、数字与下划线组成，不能以数字开头，不能与关键字同名，区分大小写。
- 函数内部赋值的名字默认属于函数内部，局部与全局名字的关系由 <CrossRef id="python.scope-and-closure" /> 处理。

```python run id="py.names.reassignment"
x = 10
x = x + 5
print(x)

a = b = 0
a = a + 1
print(a, b)
```

`x = x + 5` 先算 `10 + 5` 得到 15，再把 `x` 绑定到 15。`a = b = 0` 把两个名字绑定到同一个值；整数不可变，`a = a + 1` 让 `a` 指向新值，`b` 仍是 0。

## 复合赋值

```python run id="py.names.augmented"
count = 3
count += 1
print(count)

text = "ab"
text += "c"
print(text)
```

`count += 1` 等价于 `count = count + 1`。`+=` 对字符串做拼接。对列表这类可变对象，`+=` 修改对象而不是重绑定名称，这个区别由 <CrossRef id="python.names-and-objects" /> 处理。

## 名字没有类型

```python run id="py.names.no-type"
counter = 1
print(counter, type(counter))

counter = "one"
print(counter, type(counter))
```

同一个名字先后指向整数与字符串。`type()` 报告的是名字当前指向的值的类型。

## 输出多个值

```python run id="py.names.print-args"
total = 42
print("value is", total)
print("value is " + str(total))
print("value is " + total)
```

`print` 接受多个参数并用空格分隔，自动把值转成文本。用 `+` 拼接时两侧都必须是字符串，`str(total)` 做显式转换；漏掉转换抛 `TypeError`。
