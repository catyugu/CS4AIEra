## 目的

本课解释赋值与名字的使用规则。

程序需要记住中间结果，这件事由名字完成。赋值语句把名字与值关联起来，之后用这个名字取回那个值。

## 模型：赋值

赋值语句 `name = expression` 分两步：先求值右边的表达式，再把左边的名字绑定到结果。

- 右边先算完，左边再更新，因此 `x = x + 1` 使用的是旧值。
- 名字可以反复赋值，指向的值可以换类型。
- 名字在赋值之前使用会抛 `NameError`。
- 名字由字母、数字与下划线组成，不能以数字开头，不能与关键字同名，区分大小写。

```python run id="py.names.reassignment"
x = 10
x = x + 5
print(x)

a = b = 0
a = a + 1
print(a, b)
```

`x = x + 5` 先算 `10 + 5` 得到 15，再把 `x` 绑定到 15。`a = b = 0` 把两个名字绑定到同一个值；整数不可变，`a = a + 1` 让 `a` 指向新值，`b` 仍是 0。

## 复合赋值

```python run id="py.names.augmented"
count = 3
count += 1
print(count)

text = "ab"
text += "c"
print(text)
```

`count += 1` 等价于 `count = count + 1`。`+=` 对字符串做拼接。对列表这类可变对象，`+=` 的语义与整数上不同，这个区别由后续课时处理。

## 名字没有类型

```python run id="py.names.no-type"
counter = 1
print(counter, type(counter))

counter = "one"
print(counter, type(counter))
```

同一个名字先后指向整数与字符串。`type()` 报告的是名字当前指向的值的类型。

## 输出多个值

```python run id="py.names.print-args"
total = 42
print("value is", total)
print("value is " + str(total))
print("value is " + total)
```

`print` 接受多个参数并用空格分隔，自动把值转成文本。用 `+` 拼接时两侧都必须是字符串，`str(total)` 做显式转换；漏掉转换抛 `TypeError`。

## 边界与失败情形

- **使用未赋值的名字**：抛 `NameError`，消息里给出名字。
- **大小写敏感**：`total`、`Total`、`TOTAL` 是三个名字。
- **关键字不能作名字**：`if`、`for`、`class`、`None`、`True` 等是语言保留字。
- **赋值不复制数据**：`a = b` 让两个名字指向同一个值。对可变对象，通过任一名字的修改对另一个名字可见，这条规则的完整模型由对象模型课时展开。
- **函数内部的赋值默认只影响函数内部**：局部与全局名字的关系由函数与作用域课时处理。

## 生产后果

- 变量命名承载接口语义。名字含义模糊会让后续修改无法判断影响范围。
- 把中间结果绑定到有含义的名字，比嵌套的长表达式更容易检查与调试。
- 生成代码常把文本与数字直接拼接，`TypeError` 与错误的输出文本都由此而来。

## 小结

- 赋值先求值右边，再绑定左边；`x = x + 1` 使用旧值。
- 名字可以重复赋值并改变类型，名字本身没有类型。
- 使用未赋值的名字抛 `NameError`。
- `+=` 是复合赋值；对可变对象有特殊语义。
- `print` 用空格分隔多个参数并自动转文本；用 `+` 拼接需要显式 `str()`。
- 赋值不复制数据，两个名字可以指向同一个值。
