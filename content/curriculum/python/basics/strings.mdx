字符串是文本在程序里的表示形式。它是序列，可以按位置取值；它不可变，所有「修改」都产生新字符串。

## 字符串是序列

- `len(s)` 给出字符串的码位数；字节数、字位丛数与显示宽度是另外的度量，按它们施加约束的场景见 <CrossRef id="python.text-and-bytes" />。
- `s[i]` 按位置取值，位置从 0 开始；负下标从末尾倒数，`s[-1]` 是最后一个字符。
- `s[start:stop]` 是切片：取 `start` 到 `stop` 之前的部分，不含 `stop`。
- 下标越界抛 `IndexError`；切片越界不报错，返回能取到的部分，完全越界时是空字符串。
- 字符串不可变，`s[0] = "x"` 抛 `TypeError`，改变内容只能构造新字符串。
- 比较按码位逐个进行：`"Z" < "a"` 为真，因为大写字母的码位小于小写字母；语言相关的排序需要专门的排序规则。
- 单引号与双引号等价，`'a'` 与 `"a"` 是同一个值；文本里含引号时换用另一种引号，或写成转义序列。
- 换行与制表符用转义序列（`\n`、`\t`）表示，反斜杠本身写两次（`\\`）；用 `repr` 看清真实内容。

```python run id="py.strings.indexing"
word = "python"
print(len(word))
print(word[0], word[1], word[-1])
print(word[0:3], word[:3], word[3:], word[:])
```

`word[0:3]` 是 `pyt`，`word[:3]` 等价，`word[3:]` 取到末尾，`word[:]` 复制整个字符串。

引号与转义是同一层内容的不同写法，`repr` 显示转义形式，`ord` 与 `chr` 在码位与单字符之间转换：

```python run id="py.strings.escapes"
print(repr("two\nlines"))
print(repr("tab\there"))
print(chr(65), ord("A"))
```

## 拼接、重复与成员判断

```python run id="py.strings.operators"
print("py" + "thon")
print("ab" * 3)
print("th" in "python", "z" in "python")
print("5" + "3")
```

`+` 拼接，`*` 重复，`in` 判断子串。`"5" + "3"` 得到 `"53"`，这是文本拼接，不是加法。

## 常用方法

```python run id="py.strings.methods"
word = "python"
print(word.upper(), word.replace("p", "P"))
print("  padded  ".strip())
print("a,b,c".split(","))
print("-".join(["a", "b", "c"]))
```

方法不修改原字符串，而是返回新字符串。`split` 把字符串切成列表，`join` 把列表拼成字符串，分隔符由调用方给出。

## 把值插入文本

```python run id="py.strings.formatting"
word = "python"
count = 6
padded = "  padded  "
print(f"{word} has {count} letters")
print(f"{padded!r} inserts the repr, so the spaces stay visible")
print("total: " + str(12))
print("value is", 42)
```

f-string 在引号前加 `f`，用 `{}` 插入表达式，插入的值自动转成文本。`{}` 里还能写转换标志与格式说明符：`{值!r}` 插入该值的 `repr` 结果，用于显示边界空格、引号与转义（`repr` 见 <CrossRef id="python.programs-and-expressions" />）；`{值:20s}` 一类说明符控制宽度、对齐与类型，本课程用它对齐表格输出。`print` 接受多个参数并用空格分隔，是最省事的输出方式。
