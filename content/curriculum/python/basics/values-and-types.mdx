## 目的

本课解释值的类型，以及类型如何决定一段代码的行为。

Python 的每个值都有类型。类型决定这个值能参与哪些运算、运算结果是什么类型。读一段代码时的第一步判断是：这个位置的值是什么类型。

## 模型

- 值有类型，名字没有类型。名字指向某个值，可以随时改指另一个类型的值。
- 类型决定运算的含义。`+` 在整数上是加法，在字符串上是拼接。
- `type(value)` 返回值的类型；`isinstance(value, T)` 判断值是否属于某个类型。
- 内置类型：`int`（整数）、`float`（小数）、`str`（字符串）、`bool`（真/假）、`NoneType`（唯一值 `None`），以及后面会详细讲的容器类型 `list`、`tuple`、`dict`、`set`。

```python run id="py.types.overview"
print(type(1), type(1.5), type("text"), type(True), type(None))
print(type([1, 2]), type((1, 2)), type({1: 2}), type({1, 2}))
print(type(type(1)))
```

输出依次给出每个值的类型。最后一行说明类型本身也是值，它的类型是 `type`。

## 类型决定运算

```python run id="py.types.operator-meaning"
print(1 + 1)
print("1" + "1")
print(1 + 1.5)
```

同一个 `+` 在整数上是加法，在字符串上是拼接，在整数与小数之间是数值加法并返回小数。

类型不匹配时，运算没有定义：

```python run id="py.types.mismatch"
print("abc" + 1)
```

抛 `TypeError`：字符串与整数之间没有 `+` 的定义。修法取决于意图，把数字转成文本用 `str(1)`，把文本转成数字用 `int("1")`。

## 值、类型与名字

```python run id="py.types.name-has-no-type"
value = 1
print(value, type(value))

value = "now a string"
print(value, type(value))
```

`value` 先指向整数，后指向字符串。名字没有类型，值有类型；`type()` 报告的是名字当前指向的值的类型。

## 边界与失败情形

- **`bool` 是 `int` 的子类型**：`True == 1` 为真，`True + True` 得到 2。这是语言的定义，不是转换规则。
- **隐式转换很少**：Python 只在数值类型之间做隐式提升，`int` 与 `float` 混合运算得到 `float`。文本与数字之间必须显式转换。
- **转换可能失败**：`int("abc")` 抛 `ValueError`，说明类型正确但值不合法，与 `TypeError` 是两类不同的错误。
- **`None` 表示「没有值」**：它不等于空字符串，也不等于 0。
- **可变与不可变**：`int`、`float`、`str`、`tuple` 不可变；`list`、`dict`、`set` 可变。这个区别的后果由后续课时展开。
- **类型检查发生在运行时**：类型不匹配只在执行到那一行时报错，未执行的部分不受检查。

## 生产后果

- 接口边界上必须明确类型。从 JSON、表单、命令行、环境变量读入的都是文本，进入计算前要显式转换并处理转换失败。
- `bool` 与 `int` 的关系会让 `True` 参与算术与字典键，校验数据时要单独判断。
- 报错信息里的类型名是排查起点：`TypeError` 表示类型不匹配，`ValueError` 表示类型正确但值不合法。

## 小结

- 值有类型，名字没有类型。
- 类型决定可用运算；类型不匹配抛 `TypeError`。
- `type()` 观察类型，`isinstance()` 判断归属。
- 数值之间会隐式提升为 `float`；文本与数字之间必须显式转换。
- 转换失败抛 `ValueError`，与 `TypeError` 是两类不同的错误。
