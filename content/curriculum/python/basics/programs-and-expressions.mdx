## 目的

本课从零开始：一段代码如何被执行，执行过程中产生哪些可观察的结果。

Python 程序由语句组成，语句中的表达式被求值成值。分清这两类结构，是读懂后续所有代码的前提。

## 模型：求值

解释器从上到下读代码，遇到一条语句就执行它。

- **表达式**（expression）是有值的代码片段：`2 + 3`、`len("hello")`、`"a" + "b"`。
- **语句**（statement）是让解释器做一件事的指令：赋值、`if`、`for`、函数定义。
- **函数调用** `name(...)` 是表达式：把参数交给函数，函数返回一个值。
- `print(...)` 是函数调用，作用是把值写到输出；它自身返回 `None`。

程序的可观察行为由三部分构成：输出、副作用与返回值。日志、指标与退出码都建立在这三者上。

```python run id="py.basics.hello"
print("Hello, world")
```

这一行是一条语句。`print` 是函数，`"Hello, world"` 是它的参数，一个字符串。执行后输出区出现 `Hello, world`。

```python run id="py.basics.expression-vs-text"
print(2 + 3)
print("2 + 3")
```

第一行的参数是表达式 `2 + 3`，先求值为整数 5 再打印。第二行的参数是字符串，内容就是 `2 + 3` 这几个字符，原样打印。引号决定一段文本是代码还是数据。

## 单元格的求值规则

本课程的代码单元格按交互式解释器的规则求值：执行全部语句，并显示最后一行表达式的值。这是单元格的求值语义；Python 脚本不会因为文件最后写了一个表达式就显示结果，脚本里的表达式只有被打印、赋值或返回才产生可见效果。

```python run id="py.basics.trailing-expression"
width = 3
height = 4
width * height
```

前两行是赋值语句，没有可显示的值；最后一行的表达式求值为 12，单元格把它作为结果值单独显示。把最后一行改成 `print(width * height)` 会得到打印输出。

`repr()` 给出一个值的可读表示，用于检查字符串里看不见的字符：

```python run id="py.basics.repr"
print(repr("two\nlines"))
print(repr("  padded  "))
```

`repr` 把换行显示为 `\n`，把空格留在引号内。检查字符串的真实内容用 `repr`，观察程序行为用 `print`。

## 边界与失败情形

- **引号是语法的一部分**：`"hello"` 是字符串，`hello` 是一个名字；后者在未赋值时抛 `NameError`。
- **名字区分大小写**：`Width` 与 `width` 是两个不同的名字。
- **`print` 的返回值是 `None`**：`x = print("hi")` 先输出 `hi`，再把 `None` 赋给 `x`。
- **缩进有语法含义**：行首多余的空格会改变代码块结构，或直接抛 `IndentationError`。
- **注释不执行**：`#` 之后的内容是注释，用于说明意图，不参与求值。

```python run id="py.basics.name-error"
print("before")
print(missing_name)
print("after")
```

执行在第二行停止，`NameError` 说明这个名字还没有被赋值。已经打印的内容留在输出区，最后一行不会执行。输出区同时给出异常类型、消息与出错位置。
