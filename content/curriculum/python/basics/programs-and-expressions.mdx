一段 Python 程序是一串语句，解释器从第一行往下执行。下面四行用两个量算出一个总数，并打印出来：

```python run id="py.basics.first-program"
price = 20
count = 3
total = price * count
print(total)
```

`price = 20` 把名称 `price` 绑定到对象 `20`。`price * count` 是一个表达式，它读取 `price` 与 `count` 当前绑定的对象，相乘，求值得到新对象 `60`。`total = price * count` 是赋值语句，把名称 `total` 绑定到刚求出的 `60`。`print(total)` 读取 `total` 的绑定，把 `60` 写到输出。运行这四行，输出是 `60`。

三个词各自指一件事。**表达式**（expression）是求值后得到一个对象的代码片段，例如 `price * count`、`20`、`total`。**语句**（statement）规定一个执行动作，例如 `price = 20` 是赋值语句。**名称绑定**（name binding）让名称指向一个对象。

## 对象的值与类型

求值的结果是对象，每个对象有值也有类型。类型决定它参与哪些运算，以及同一个符号在不同类型上的含义。`type` 返回一个对象的类型：

```python run id="py.types.overview"
print(type(1), type(1.5), type("text"), type(True), type(None))
print(1 + 1, "1" + "1", 1 + 1.5)
```

`int` 是整数，`float` 是小数，`str` 是字符串，`bool` 取 `True` 与 `False`。`None` 是 `NoneType` 的唯一实例，表示没有结果或状态缺失；它与 `0`、空字符串、`False` 都不相等，判断「没有值」用 `is None`（<CrossRef id="python.conditionals" />）。

`+` 对两个整数求和，对两个字符串拼接；整数与小数相加得到小数。字符串与整数之间没有这种加法定义：

```python run id="py.types.mismatch"
print("abc" + 1)
```

这一行抛 `TypeError`。修法取决于意图：`str(1)` 得到文本 `"1"`，`int("1")` 得到整数 `1`。转换也可能失败：`int("abc")` 抛 `ValueError`，说明参数类型可接受而值不合法。数值与字符串的完整规则见 <CrossRef id="python.numbers-and-arithmetic" /> 与 <CrossRef id="python.strings" />。

## 赋值与重新绑定

`price = 20` 与 `total = price * count` 是同一形式：右侧表达式先求值，左侧名称再绑到结果对象。同一个名称可以先后指向不同类型的对象。

```python run id="py.names.reassignment"
x = 10
x = x + 5
print(x)

a = b = 0
a = a + 1
print(a, b)

x = "fifteen"
print(x, type(x))
```

`x = x + 5` 先读取 `x` 的旧绑定算出 `15`，再把 `x` 重新绑到 `15`。`a = b = 0` 把两个名称绑到同一个整数对象；`a = a + 1` 把 `a` 重新绑到 `1`，`b` 仍是 `0`。赋值绑定名称，不复制对象：多个名称指向同一个对象时，通过一个名称修改对象会被其余名称读到，这由 <CrossRef id="python.names-and-objects" /> 展开。

`x += 1` 与 `x = x + 1` 对整数结果相同；对可变对象，`+=` 可能原地更新（<CrossRef id="python.mutability-and-copy" />）。名称区分大小写，`Width` 与 `width` 不同，且不能以数字开头或使用关键字。函数中绑定的名称通常是局部名称，作用域规则由 <CrossRef id="python.scope-and-closure" /> 处理。

读到没有绑定过的名称会失败：

```python run id="py.basics.name-error"
print("before")
print(missing_name)
print("after")
```

`missing_name` 没有绑定，第二行抛 `NameError`，执行在此停止。已经打印的 `before` 保留，第三行不运行；异常类型与出错行是定位失败的证据。

## 单元格显示最后结果

页面上的单元格执行全部语句，并单独显示末行表达式的结果。这是单元格的显示规则，普通脚本不会自动显示末行表达式的值。

```python run id="py.basics.trailing-expression"
width = 3
height = 4
width * height
```

两条赋值建立绑定，末行 `width * height` 求值为 `12`，单元格把它单独显示为一个结果。末行换成 `print(width * height)` 时，乘积以打印输出的形式出现，单元格不再显示额外结果。

```python run id="py.basics.repr"
total = 42
print("value is", total)
print("value is " + str(total))
print(repr("two\nlines"))
print(repr("  padded  "))
```

`print` 接受多个参数，默认用空格分隔，并把每个值转成文本；用 `+` 拼接字符串与数字时，要先用 `str()` 转换数字。`repr` 给出便于检查的表示：换行写作 `\n`，首尾空格保留在引号内。
