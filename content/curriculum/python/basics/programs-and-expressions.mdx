一段 Python 程序是一串语句，解释器从第一行往下执行。下面四行用两个量算出一个总数，并打印出来：

```python run id="py.basics.first-program"
price = 20
count = 3
total = price * count
print(total)
```

`price = 20` 把名称 `price` 绑定到值 `20`。`price * count` 是一个表达式，它读取 `price` 与 `count` 当前绑定到的值，相乘，求值得到 `60`。`total = price * count` 是赋值语句，把名称 `total` 绑定到刚求出的 `60`。`print(total)` 读取 `total` 的绑定，把 `60` 写到输出。

三个词各自指一件事。**表达式**（expression）是求值后得到一个值的代码片段，例如 `price * count`、`20`、`total`。**语句**（statement）规定一个执行动作，例如 `price = 20` 是赋值语句。**名称绑定**（name binding）让名称关联到一个值。

## 值与类型

求值得到一个值，每个值有类型。类型决定它参与哪些运算，以及同一个符号在不同类型上的含义。`type` 返回一个值的类型：

```python run id="py.types.overview"
print(type(1), type(1.5), type("text"), type(True), type(None))
print(1 + 1, "1" + "1", 1 + 1.5)
```

`int` 是整数，`float` 是浮点数，`str` 是字符串，`bool` 取 `True` 与 `False`。`None` 的类型是 `NoneType`，表示没有结果或状态缺失；它与 `0`、空字符串、`False` 都不相等。

`+` 对两个整数求和，对两个字符串拼接；整数与浮点数相加得到浮点数。字符串与整数之间没有这种加法定义：

```python run id="py.types.mismatch"
print("abc" + 1)
```

这一行抛 `TypeError`。修法取决于意图：`str(1)` 得到文本 `"1"`，`int("1")` 得到整数 `1`。转换也可能失败：`int("abc")` 抛 `ValueError`，说明参数类型可接受而值不合法。数值与字符串的完整规则见 <CrossRef id="python.numbers-and-arithmetic" /> 与 <CrossRef id="python.strings" />。

## 赋值与重新绑定

`price = 20` 与 `total = price * count` 是同一形式：右侧表达式先求值，左侧名称再绑到结果值。同一个名称可以先后指向不同类型的值。

```python run id="py.names.reassignment"
x = 10
x = x + 5
print(x)

a = b = 0
a = a + 1
print(a, b)

x = "fifteen"
print(x, type(x))
```

`x = x + 5` 先读取 `x` 的旧绑定算出 `15`，再把 `x` 重新绑到 `15`。`a = b = 0` 把两个名称都绑到 `0`；`a = a + 1` 把 `a` 重新绑到 `1`，`b` 仍是 `0`。

名称区分大小写，`Width` 与 `width` 不同，且不能以数字开头或使用关键字。

读到没有绑定过的名称会失败：

```python run id="py.basics.name-error"
print("before")
print(missing_name)
print("after")
```

`missing_name` 没有绑定，第二行抛 `NameError`，执行在此停止。已经打印的 `before` 保留，第三行不运行；异常类型与出错行是定位失败的证据。

## 打印与表示

```python run id="py.basics.repr"
total = 42
print("value is", total)
print("value is " + str(total))
print(repr("two\nlines"))
print(repr("  padded  "))
```

`print` 接受多个参数，默认用空格分隔，并把每个值转成文本；用 `+` 拼接字符串与数字时，要先用 `str()` 转换数字。`repr` 给出便于检查的表示：换行写作 `\n`，首尾空格保留在引号内。
