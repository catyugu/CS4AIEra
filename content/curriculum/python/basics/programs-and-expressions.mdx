Python 程序由语句组成，语句中的表达式求值得到对象，赋值语句可以把名称绑定到对象。后续表达式通过名称取得对象，再进行运算。第一套可复用的模型是：

```text
源码中的表达式 → 求值 → 得到对象（具有值与类型）
                            ↓ 赋值
                         名称绑定
                            ↓ 后续表达式读取名称
                         取得对象
```

## 表达式与语句

**表达式**（expression）是求值后得到对象的代码片段，如 `2 + 3`、`"a" + "b"`、`len("hello")`。**语句**（statement）规定执行动作，如赋值、条件、循环与函数定义。函数调用也是表达式：调用有返回值，并且可以产生副作用。

```python run id="py.basics.expression-vs-text"
print(2 + 3)
print("2 + 3")
result = print("output")
print("return value:", result)
```

第一行先求值 `2 + 3` 得到整数 5，再打印；第二行打印字符串里的字符。第三行产生输出并返回 `None`，赋值把 `result` 绑定到这个返回值。打印输出与表达式结果是两个不同的可观察量，不能从「打印了什么」推断「返回了什么」。

顺序执行的语句从上到下运行，条件、循环与调用会改变执行路径。缩进规定代码块结构，多余或缺失的缩进可能抛 `IndentationError`；`#` 引入行内注释，注释不参与求值。

## 对象的值与类型

每个对象有类型，类型决定可用的运算以及运算的含义。这里先用值与类型预测运算；对象身份、别名与可变性的后果由 <CrossRef id="python.names-and-objects" /> 展开。

```python run id="py.types.overview"
print(type(1), type(1.5), type("text"), type(True), type(None))
print(1 + 1, "1" + "1", 1 + 1.5)
print(isinstance(True, int), True + True)
```

`int` 表示整数，`float` 表示浮点数，`str` 表示字符串，`bool` 的值是 `True` 与 `False`。`None` 也是对象，是 `NoneType` 的唯一实例，用来表示没有结果或状态缺失；它与 `0`、空字符串、`False` 都不相等，判定「没有值」要用 `is None`（见 <CrossRef id="python.conditionals" />）。`bool` 是 `int` 的子类型，因此 `isinstance(True, int)` 为真，相加得到 2。

`+` 对整数做加法，对字符串做拼接，整数与浮点数相加得到浮点数。字符串与整数之间没有这种加法定义：

```python run id="py.types.mismatch"
print("abc" + 1)
```

这一行抛 `TypeError`。修法取决于意图：`str(1)` 得到文本，`int("1")` 得到整数。转换也可能失败：`int("abc")` 抛 `ValueError`，说明参数类型可接受但值不合法。详细的数字与字符串规则分别见后两课。

## 赋值与重新绑定

`name = expression` 分两步：先求值右侧表达式，再把左侧名称绑定到结果对象。名称是读取绑定的入口，类型属于对象；同一名称可以先后绑定到不同类型的对象。

```python run id="py.names.reassignment"
x = 10
x = x + 5
print(x)

a = b = 0
a = a + 1
print(a, b)

x = "fifteen"
print(x, type(x))
```

`x = x + 5` 先读取旧绑定，算出 15，再更新 `x`。`a = b = 0` 将两个名称绑定到同一个整数对象；`a = a + 1` 将 `a` 重新绑定到 1，`b` 仍绑定到 0。赋值不复制对象，详细的共享状态实验见 <CrossRef id="python.names-and-objects" />。

对本例的整数，`x += 1` 得到的值与 `x = x + 1` 相同。增强赋值一般不能简单替换为普通赋值：可变对象可能原地更新，目标的求值规则也有区别（<CrossRef id="python.mutability-and-copy" />）。

名称区分大小写，`Width` 与 `width` 不同；名称不能以数字开头，也不能使用关键字。函数中绑定的名称通常是局部名称，作用域规则由 <CrossRef id="python.scope-and-closure" /> 处理。

```python run id="py.basics.name-error"
print("before")
print(missing_name)
print("after")
```

第二行无法找到名称绑定，抛 `NameError`，执行在这里停止。已打印的 `before` 保留，第三行不运行。异常类型、消息与出错位置提供定位失败的证据。

## 单元格结果与输出表示

本课程的单元格执行全部语句，并显示末尾表达式的结果。这是交互式单元格的规则；普通 Python 脚本不会自动显示末尾表达式的值。表达式仍会被求值，也可能产生副作用或抛异常。

```python run id="py.basics.trailing-expression"
width = 3
height = 4
width * height
```

两条赋值语句建立绑定，最后的表达式读取绑定并求值为 12，单元格单独显示这个结果。把末行改为 `print(width * height)`，则得到打印输出，调用的返回值为 `None`。

```python run id="py.basics.repr"
total = 42
print("value is", total)
print("value is " + str(total))
print(repr("two\nlines"))
print(repr("  padded  "))
```

`print` 接受多个参数，默认用空格分隔并将值转为文本；用字符串 `+` 拼接时，需要显式转换数字。`repr` 给出便于检查的表示：换行显示为 `\n`，边界空格保留在引号内。

静态工具可以依据类型推断与标注提前发现部分不一致（<CrossRef id="python.typing" />），运行时则在实际执行到操作时检查。环境变量的值是文本，JSON 解析结果还可能是数字、列表或其他对象；进入业务计算前仍需按实际数据解析与校验。
