对一批数据里的每个元素做同一件事，是程序里最常见的重复。把 `[3, 1, 4]` 里三个数依次打印，可以写三行；数据长到一百个，就得抄一百行，还要逐个改下标。`for` 把这种重复交给语言：它从序列里依次取元素，每取一个就执行一次缩进的循环体。

## for 与 range

```python run id="py.loops.for-range"
for n in [3, 1, 4]:
    print(n)

for i in range(3):
    print("i =", i)

print(list(range(3)), list(range(2, 5)), list(range(0, 10, 3)))
```

`for name in sequence:` 每次把序列里的一个元素绑定到 `name`，执行一次循环体，直到元素取完；循环体靠缩进界定。要按固定次数重复时用 `range`：`range(stop)`、`range(start, stop)`、`range(start, stop, step)` 描述一个不含 `stop` 的整数区间，`range(3)` 覆盖 0、1、2，`range(0, 10, 3)` 覆盖 0、3、6、9。`list()` 把区间展开成列表，用来查看它覆盖了哪些整数。

## 遍历序列

```python run id="py.loops.iterate"
for ch in "abc":
    print(ch)

for index, item in enumerate(["x", "y"]):
    print(index, item)

for name, value in [("a", 1), ("b", 2)]:
    print(name, value)

for letter, number in zip("ab", range(1, 4)):
    print(letter, number)
```

`for` 直接遍历元素。需要下标时用 `enumerate`，它每次给出 `(下标, 元素)`；需要并行遍历多个序列时用 `zip`，它每次从各序列各取一个，结果也是元组，因此同样可以直接解包到多个名字。`zip` 在最短的序列耗尽时停止，其余序列多出的元素被忽略；列表里存放的元组也能直接解包。

## 累加模式

```python run id="py.loops.accumulate"
total = 0
for n in [1, 2, 3, 4]:
    total += n
print("total:", total)

numbers = [4, 1, 7]
largest = numbers[0]
for n in numbers[1:]:
    if n > largest:
        largest = n
print("largest:", largest)
```

累加需要三部分：初值、每次迭代的更新、循环结束后的使用。求最大值时初值取 `numbers[0]`，取 0 会让全是负数时结果出错。

## 内建聚合

```python run id="py.loops.builtins"
numbers = [1, 2, 3]
print(sum(numbers), max(numbers), min(numbers), len(numbers))
```

`sum`、`max`、`min`、`len` 覆盖多数聚合需求，比手写循环更短。手写循环用于需要额外状态或多步判断的场景。

## while 与终止

```python run id="py.loops.while"
n = 3
while n > 0:
    print("n =", n)
    n -= 1
```

`while condition:` 在条件为真时重复执行循环体。迭代次数事先不确定时用它，代价是要自己保证条件最终为假：这里靠 `n -= 1`。漏掉这一步循环永不结束，页面上的**停止**按钮会终止这次执行，**恢复代码**把单元格还原为作者源码。

```python run id="py.loops.break-continue"
for i in range(5):
    if i == 2:
        continue
    if i == 4:
        break
    print("kept", i)
```

`break` 结束整个循环，`continue` 跳过本次迭代的剩余部分：`continue` 让 `i == 2` 不打印，`break` 在 `i == 4` 结束循环，因此输出 0、1、3。

## 列表、字典与集合推导式

```python run id="py.loops.comprehension"
numbers = [1, 2, 3, 4, 5, 6]
print([n * n for n in numbers if n % 2 == 0])
print({n: n * n for n in numbers if n % 3 == 0})
print({n % 3 for n in numbers})
```

推导式从一个序列构造新容器，把 `for` 与可选的 `if` 写进一对括号里：方括号构造列表，花括号配合 `键: 值` 构造字典、不写冒号则构造集合。三者共用同一套语法。

| 结构 | 写法 |
| --- | --- |
| 列表 | `[表达式 for 元素 in 序列 if 条件]` |
| 字典 | `{键: 值 for 元素 in 序列 if 条件}` |
| 集合 | `{表达式 for 元素 in 序列 if 条件}` |

它比循环加 `append` 更紧凑，是构造容器的惯用写法。

**实现边界**：在循环里增删正在遍历的序列会跳过或重复元素，原因在迭代器的状态上（见 <CrossRef id="python.iteration-protocol" />）。循环结束后循环变量仍然存在，值是最后一次迭代的值，`for` 不创建新的作用域（见 <CrossRef id="python.scope-and-closure" />）。
