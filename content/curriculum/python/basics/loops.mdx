对一批数据做同样的处理需要循环。循环的正确性依赖两件事：终止条件与每次迭代累积的状态。

## for 与 while

- `for name in sequence:` 依次把序列中的每个元素绑定到 `name`，对每个元素执行一次循环体。
- `range(stop)`、`range(start, stop)`、`range(start, stop, step)` 描述一个不含 `stop` 的整数区间。`range` 对象是惰性、不可变的：它按需产生元素，写成 `list(range(...))` 才会把区间展开成列表。
- `while condition:` 在条件为真时重复执行循环体。循环体必须改变条件涉及的值，否则循环不终止。
- 循环体靠缩进界定。
- `break` 结束整个循环，`continue` 跳过本次迭代的剩余部分。

```python run id="py.loops.for-range"
for i in range(3):
    print("i =", i)

print(list(range(3)), list(range(2, 5)), list(range(0, 10, 3)))
```

`range(3)` 覆盖 0、1、2，不含 3；`range(0, 10, 3)` 覆盖 0、3、6、9。`list()` 把区间展开成列表，用于检查范围。

## 遍历序列

```python run id="py.loops.iterate"
for ch in "abc":
    print(ch)

for index, item in enumerate(["x", "y"]):
    print(index, item)

for name, value in [("a", 1), ("b", 2)]:
    print(name, value)
```

`for` 直接遍历元素。需要下标时用 `enumerate`，需要并行遍历多个序列时用 `zip`。列表里的元组可以直接解包到多个名字。空序列不执行循环体；在循环里增删正在遍历的列表会跳过或重复元素，原因在迭代器的状态上（见 <CrossRef id="python.iteration-protocol" />）。循环结束后循环变量仍然存在，值是最后一次迭代的值，`for` 不创建新的作用域（见 <CrossRef id="python.scope-and-closure" />）。

## 累加模式

```python run id="py.loops.accumulate"
total = 0
for n in [1, 2, 3, 4]:
    total += n
print("total:", total)

numbers = [4, 1, 7]
largest = numbers[0]
for n in numbers[1:]:
    if n > largest:
        largest = n
print("largest:", largest)
```

累加需要三部分：初值、每次迭代的更新、循环结束后的使用。初值取错（求最大值时用 0）会让结果在全是负数时出错。

## while 与终止

```python run id="py.loops.while"
n = 3
while n > 0:
    print("n =", n)
    n -= 1
```

`while` 适合迭代次数事先不确定的场景，代价是要自己保证终止：这里靠 `n -= 1` 让条件最终为假。漏掉这一步循环永不结束，页面上的**停止**按钮会终止这次执行，**恢复代码**把单元格还原为作者源码。

```python run id="py.loops.break-continue"
for i in range(5):
    if i == 2:
        continue
    if i == 4:
        break
    print("kept", i)
```

`continue` 跳过 `i == 2`，`break` 在 `i == 4` 结束循环，因此输出 0、1、3。

## 内建聚合

```python run id="py.loops.builtins"
numbers = [1, 2, 3]
print(sum(numbers), max(numbers), min(numbers), len(numbers))
```

`sum`、`max`、`min`、`len` 覆盖多数聚合需求，比手写循环更短也更难写错。手写循环用于需要额外状态或多步判断的场景。
