一段能跑通的程序需要被另一个文件复用时，把其中可复用的部分移进单独的 `.py` 文件，再用 `import` 取回，是 Python 组织代码的第一种办法。`import` 在当前文件绑定一个名字，被导入文件顶层的语句在导入时执行一次；同一个文件作为程序启动时执行的是另一套逻辑，两种角色用 `__name__` 区分。程序还要把字节解码成字符串，读写文本文件要处理路径、编码与关闭。

## 导入一个模块

`import math` 在当前文件新增一个名字 `math`，它指向 math 模块对象；`from math import sqrt` 把模块里的一个属性直接绑到当前名字上：

```python run id="py.mod.import-forms"
import math
import math as shorthand
from math import sqrt

print("module object:", math)
print("two names, one object:", shorthand is math)
print("attribute access:", math.pi, round(math.pi, 3))
print("imported directly:", sqrt(9))
```

三种写法的区别只在绑定了哪个名字：

| 写法 | 绑定的名字 | 值 |
| --- | --- | --- |
| `import math` | `math` | 模块对象 |
| `import math as m` | `m` | 同一个模块对象 |
| `from math import sqrt` | `sqrt` | 模块里的一个属性 |

`shorthand is math` 为真：`import math as shorthand` 没有复制模块，两个名字指向同一个对象，`math.pi` 与 `shorthand.pi` 取出同样的值。`from ... import` 省掉前缀，读代码时就看不出 `sqrt` 来自哪个模块。导入失败会让程序停在导入这一句，导入语句的位置也声明了这个文件对另一个文件的依赖。

## 把代码拆到另一个文件

把 `add` 移进 `calculator.py`；`main()` 与末尾的守卫让这个文件也能直接运行。`main.py` 只 `import` 它：

```python
# calculator.py
print("calculator loaded")


def add(left, right):
    return left + right


def main():
    print("2 + 3 =", add(2, 3))


if __name__ == "__main__":
    main()
```

```python
# main.py
import calculator

print("3 + 4 =", calculator.add(3, 4))
```

运行 `python main.py` 打印 `calculator loaded` 与 `3 + 4 = 7`：`import calculator` 找到文件、执行它的顶层语句、把产生的模块对象绑到名字 `calculator`；`calculator loaded` 来自顶层语句里的 `print`，在 `3 + 4 = 7` 之前出现。运行 `python calculator.py` 打印 `calculator loaded` 与 `2 + 3 = 5`：这个文件是程序本身，末尾的守卫成立，`main()` 执行。

`__name__` 是每个模块都有的属性：被导入时它的值是模块名，作为程序启动的那个文件取 `"__main__"`。守卫 `if __name__ == "__main__":` 把只应在直接运行时执行的代码——命令行入口、示例调用——与可复用的定义分开，导入时不执行入口。

模块是一个独立命名空间：`calculator.py` 里定义的名字属于 `calculator`，`main.py` 里定义的名字属于 `main.py`，两边通过 `calculator.名字` 或参数互相访问。Python 按模块名缓存已导入的模块，同一个程序里再次 `import calculator` 拿到的是第一次留下的模块对象，顶层语句不再执行；模块体只在第一次导入时运行一次。

## 读写一个文本文件

`open(path, "r", encoding="utf-8")` 在字节之上加一层解码，读出来是 `str`；写进去的 `str` 按同一编码编成字节。文件对象用完要关闭，`with` 在块结束时关闭它：

```python run id="py.files.text"
text = "first line\nsecond line\n"

with open("notes.txt", "w", encoding="utf-8") as handle:
    written = handle.write(text)

with open("notes.txt", "r", encoding="utf-8") as handle:
    content = handle.read()

print("write returned the number of characters:", written)
print("closed after the block:", handle.closed)
print("read back:", repr(content))
```

`write` 返回写入的字符数；文本模式读出的是 `str`，内容与写入的字符串一致，`repr` 让换行在输出里可见。`with` 在块结束时关闭文件，块内抛出异常时同样关闭；文件与编码的完整模型见 <CrossRef id="python.text-and-bytes" />，`with` 的进入与退出协议见 <CrossRef id="python.context-managers" />。`read()` 不带参数会读入整个文件，大文件按行迭代或分批读。

## 失败情形

三类失败各自报一个异常类型与一条消息：

```python run id="py.mod.failures"
try:
    import module_that_does_not_exist
except ModuleNotFoundError as failure:
    print("missing module:", type(failure).__name__, "-", failure)

import math

try:
    math.no_such_function
except AttributeError as failure:
    print("missing attribute:", type(failure).__name__, "-", failure)

try:
    open("missing-file.txt", "r", encoding="utf-8")
except FileNotFoundError as failure:
    print("missing file:", type(failure).__name__, "-", failure)
```

三类错误指向三个不同的原因：模块不在搜索路径上、模块里没有这个名字、文件不在这个路径上。前两类在导入或取属性时抛出，第三类在打开文件时抛出。
