矩形的面积是宽乘高，同一段乘法在程序里反复出现。`def` 把这段计算命名，之后换一组宽高调用它，不必每次重写公式。

## 定义与调用

```python run id="py.functions.define-call"
def area(width, height):
    return width * height


print(area(3, 4))
print(area(5, 2))
```

`def area(width, height):` 定义函数，函数体靠缩进界定。调用 `area(3, 4)` 时，实参按书写顺序求值，再绑定到形参 `width` 与 `height`；函数体执行，`return` 的值成为整个调用表达式的值。实参个数与形参不匹配抛 `TypeError`。函数体是一个新的作用域：函数内赋值的名字默认只属于函数内部。形参与实参的完整绑定规则见 <CrossRef id="python.call-semantics" />。

## 返回值与 None

```python run id="py.functions.return-none"
def log(message):
    print("[log]", message)


result = log("hi")
print("returns:", result)
```

`log` 把消息打印出来，这是副作用；它没有 `return`，因此返回 `None`。打印只在屏幕上留下文字，返回值才是调用表达式的结果，能被后续计算使用。对 `None` 做运算抛 `TypeError`；`return` 立即结束函数，它之后的语句不再执行。

多个值用元组返回，调用方可以直接解包：

```python run id="py.functions.multiple-returns"
def divide(left, right):
    quotient = left // right
    remainder = left % right
    return quotient, remainder


q, r = divide(7, 3)
print(q, r)
print(divide(7, 3))
```

`divide` 返回一个元组；`q, r = divide(7, 3)` 用解包把两个元素分别绑定到两个名字。

## 默认参数与关键字参数

```python run id="py.functions.defaults"
def add(left, right=1):
    return left + right


print(add(2), add(2, 5), add(2, right=10))
```

`right` 有默认值，调用时可以省略。`add(2, right=10)` 用 `name=value` 指定参数名，顺序不再重要，长参数列表里也更难写错。

## 文档字符串

```python run id="py.functions.docstring"
def area(width, height):
    """Return the area of a rectangle."""
    return width * height


print(area(3, 4), area(height=4, width=3))
print(area.__doc__)
```

函数体的第一个字符串是文档字符串，`__doc__` 可以取出。它记录函数的接口约定：参数含义、返回值、边界条件。

`lambda parameters: expression` 是另一种写函数的方式：它求值得到一个函数对象，函数体只能是这一个表达式，这个函数对象没有定义时的名字，`__name__` 是 `"<lambda>"`。它适合作为一次性传入的小函数；需要多行逻辑、文档字符串或注解时用 `def`。实参绑定与 `def` 相同（见 <CrossRef id="python.call-semantics" />）。
