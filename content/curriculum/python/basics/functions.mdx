函数把一段可重复使用的计算命名，也是划分程序结构的最小单位：接口由参数与返回值构成。形参与实参之间的完整绑定规则由 <CrossRef id="python.call-semantics" /> 建立，这里只保留读懂调用语法所需的部分。

## 模型

- `def name(parameters):` 定义函数，函数体靠缩进界定。
- 调用 `name(arguments)` 时，每个实参先求值得到一个对象，形参名称绑定到该对象；函数体执行，`return` 的值成为调用的结果。实参个数与形参不匹配抛 `TypeError`，消息里给出函数签名。形参指向的对象被原地修改时，调用方看见的是同一个对象（见 <CrossRef id="python.names-and-objects" />）。
- 没有 `return`，或 `return` 不带值，函数返回 `None`。
- 参数可以有默认值，调用时可以省略；调用时用 `name=value` 形式指定参数名，顺序不再重要。
- 函数体是一个新的作用域：函数内赋值的名字默认只属于函数内部。

```python run id="py.functions.define-call"
def greet(name):
    return "Hello, " + name


print(greet("Ada"))
```

## 默认参数与关键字参数

```python run id="py.functions.defaults"
def add(left, right=1):
    return left + right


print(add(2), add(2, 5), add(2, right=10))
```

`right` 有默认值，调用时可以省略。`add(2, right=10)` 指定参数名，读起来更清楚，也避免长参数列表中的位置错误。

## 返回值与副作用

```python run id="py.functions.return-none"
def log(message):
    print("[log]", message)


result = log("hi")
print("returns:", result)
```

`log` 把消息打印出来，这是副作用；它没有 `return`，因此返回 `None`。区分「打印」与「返回」是读代码的基本功：返回值的函数可以组合，只打印的函数不能。对返回的 `None` 做运算会抛 `TypeError`；`return` 立即结束函数，它之后的语句不再执行。

多个值用元组返回，调用方可以直接解包：

```python run id="py.functions.multiple-returns"
def divide(left, right):
    quotient = left // right
    remainder = left % right
    return quotient, remainder


q, r = divide(7, 3)
print(q, r)
print(divide(7, 3))
```

## 文档字符串

```python run id="py.functions.docstring"
def area(width, height):
    """Return the area of a rectangle."""
    return width * height


print(area(3, 4), area(height=4, width=3))
print(area.__doc__)
```

函数体的第一个字符串是文档字符串，`__doc__` 可以取出。它记录函数的契约：参数含义、返回值、边界条件。
