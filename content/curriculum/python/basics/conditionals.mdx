一份分数要换成不同的等级：90 分以上记 A，70 分以上记 B，其余记 C。程序用条件语句在几条路径里选一条执行，选择依据是一个真值。

## 条件语句

```python run id="py.cond.grades"
score = 72

if score >= 90:
    grade = "A"
elif score >= 70:
    grade = "B"
else:
    grade = "C"

print(grade)
```

`if` 后面跟一个条件，条件为真就执行它下面缩进的代码块，否则依次检查后续的 `elif`，全部不成立才执行 `else`。分支从上到下判断，第一个为真的分支执行，其余跳过，因此 `elif` 的顺序决定结果：把 `>= 70` 写在 `>= 90` 之前，90 分以上也会落进 `B`。条件行末尾的 `:` 不能省，分支靠缩进界定。相等判断写 `==`，条件里写 `if x = 1` 抛 `SyntaxError`。

条件表达式把同样的选择写成一行：

```python run id="py.cond.expression"
print("yes" if 2 < 3 else "no")
```

## 真值测试

条件只关心一个值是真还是假。`bool(x)` 给出任意对象的真值：空容器、空字符串、`0`、`None` 是假值，其余对象通常为真。

```python run id="py.cond.truthiness"
print(bool(0), bool(1), bool(""), bool("x"))
print(bool([]), bool([0]), bool({}), bool(None))
print(bool("False"), bool("0"))
```

`bool([0])` 为真，因为列表非空，元素是什么无关。`"False"` 与 `"0"` 是非空文本，也都为真——文本不按内容解释真假，非空即为真。配置文件里读到 `"false"` 却当作真值，是这条规则上最常见的错误；要把这类文本当假值用，得先解析成布尔值。

## 比较运算

比较运算 `==`、`!=`、`<`、`<=`、`>`、`>=` 的结果是 `bool`，取值 `True` 或 `False`。`==` 判断两个值是否相等，`<` 一类给出顺序关系。链式比较 `a < b < c` 为真的条件是 `a < b` 与 `b < c` 同时成立，含义与 `a < b and b < c` 相同。

```python run id="py.cond.comparisons"
print(1 == 1.0, 1 != 2)
print(3 > 2 > 1)
print(3 >= 3, 2 <= 1)
print("a" == "a", [1, 2] == [1, 2])
```

`3 > 2 > 1` 依次比较相邻两项，结果为 `True`。判断一个值是不是「没有值」用 `is None`——`None` 是 `NoneType` 的唯一实例。

## 布尔运算

布尔运算 `and`、`or`、`not` 把真值组合起来。`and` 两边都为真才为真，`or` 有一边为真就为真，`not` 取反。

```python run id="py.cond.boolean-ops"
print(True and False, True or False, not True)

x = 0
print(x != 0 and 10 // x > 1)
```

`and` 在左侧为假时不再求值右侧，`or` 在左侧为真时不再求值右侧，这个性质叫短路求值。上面 `x` 为 0 时 `x != 0` 已经为假，`10 // x` 不执行，除法不报错；利用短路可以把先决条件放在前面，`if x is not None and x > 0:` 这类判空写法也因此安全。

## 实现边界

- `bool` 是 `int` 的子类型，`True == 1` 与 `0 == False` 都为真，数值零与逻辑假只在类型上区分。
- `==` 比较值，`is` 判断是否为同一个对象，两者彼此独立，一方为真不蕴含另一方（展开见 <CrossRef id="python.names-and-objects" />）。对小整数与短字符串，`is` 的结果依赖 CPython 的缓存，不是语言保证（见 <CrossRef id="python.runtime-vs-language" />）；`None` 是全局唯一的单例，判断「没有值」用 `is None` 可靠。
- 链式比较与手写的 `and` 形式真值相同，求值次数不同：链式只对中间表达式求值一次，手写形式可能求值两次，中间表达式带副作用时两者结果不同。
- `and` 与 `or` 返回的是操作数本身，不总是 `bool`：`2 < 3 and "yes"` 得到 `"yes"`。
