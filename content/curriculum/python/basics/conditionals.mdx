程序需要根据数据选择不同的路径，这个能力由布尔值与条件语句提供。

## 布尔值与比较

- 比较运算（`==`、`!=`、`<`、`<=`、`>`、`>=`）返回 `bool`，取值 `True` 或 `False`。`bool` 是 `int` 的子类型：`True == 1` 与 `0 == False` 都为真，数值零与逻辑假只在类型上区分。
- `==` 比较值是否相等，`is` 判断是否为同一个对象。对不可变值两者通常一致，区别由 <CrossRef id="python.names-and-objects" /> 处理；对小整数与短字符串，`is` 的结果依赖实现中的缓存，不是语言保证（见 <CrossRef id="python.runtime-vs-language" />）。
- 链式比较 `a < b < c` 的真值条件与 `a < b and b < c` 相同，区别在求值次数：链式形式只对中间表达式求值一次，手写的 `and` 形式可能求值两次。中间表达式带副作用时，两者不等价。
- 布尔运算 `and`、`or`、`not`。`and` 在左侧为假时返回左侧操作数，`or` 在左侧为真时返回左侧操作数，因此它们返回操作数本身，不总是返回 `bool`。

```python run id="py.cond.comparisons"
print(1 == 1.0, 1 != 2)
print(3 > 2 > 1)
print(3 >= 3, 2 <= 1)
print("a" == "a", [1, 2] == [1, 2])
```

## 真值测试

`if` 与 `while` 要判断一个值是真还是假。空容器、空字符串、`0`、`None` 都是假值。

```python run id="py.cond.truthiness"
print(bool(0), bool(1), bool(""), bool("x"))
print(bool([]), bool([0]), bool({}), bool(None))
print(0 == False, "" == False, bool("False"))
```

`bool([0])` 为真，因为列表非空，元素是什么无关。`"False"` 是非空文本，也为真——这是解析配置文件时的常见陷阱。

## 条件语句

```python run id="py.cond.grades"
score = 72

if score >= 90:
    grade = "A"
elif score >= 70:
    grade = "B"
else:
    grade = "C"

print(grade)
```

分支从上到下判断，第一个为真的分支执行，其余跳过。`elif` 的顺序决定结果：把 `>= 70` 放在 `>= 90` 之前，90 分以上也会落到 `B`。分支靠缩进界定，条件行末尾的 `:` 不能省；比较要用 `==`，条件里写 `if x = 1` 抛 `SyntaxError`。边界值落在哪一支由 `>` 与 `>=` 的选择和分支顺序共同决定，边界值要逐个确认。

条件表达式把同样的选择写成一行：

```python run id="py.cond.expression"
print("yes" if 2 < 3 else "no")
```

## match 语句

Python 3.10 起多了一条分支写法：它按**结构**匹配，而不只是比较值。

```python run id="py.cond.match"
def describe_shape(shape):
    match shape:
        case ("circle", radius):
            return f"circle of radius {radius}"
        case ("rect", width, height) if width == height:
            return f"square of side {width}"
        case ["point", x, y]:
            return f"point at ({x}, {y})"
        case {"kind": "line", "ends": (start, end)}:
            return f"line from {start} to {end}"
        case _:
            return "not a known shape"


for shape in (
    ("circle", 2),
    ("rect", 3, 3),
    ("rect", 3, 4),
    ["point", 1, 2],
    {"kind": "line", "ends": ("a", "b")},
    ("other", 1, 2, 3),
):
    print(shape, "->", describe_shape(shape))
```

`case ("circle", radius)` 同时做两件事：检查这个元组有两个元素、且第一个是 `"circle"`，然后把第二个绑到 `radius`——这是它比 `if` 链更强的地方。**模式里的名字是新的绑定，不是与已有变量比较**：要与已有值比较，用守卫条件（`case radius if radius == limit`）或点号限定的名字（`case Color.RED`，按值比较）。`if` 后缀是守卫，模式匹配成功后还要满足它才选中这一支；`case _` 匹配一切，因此写在最后。没有分支匹配且没有 `case _` 时，整个语句什么都不做，不抛异常——这一点与 `if` 链相同。

## 布尔运算的组合

```python run id="py.cond.boolean-ops"
print(True and False, True or False, not True)
print(2 < 3 and "yes" or "no")
print(None == 0, None is None)
```

`and` 与 `or` 返回操作数本身，`2 < 3 and "yes"` 得到 `"yes"`。短路求值指 `and` 在左侧为假时不再求值右侧，`or` 在左侧为真时不再求值右侧；依赖这一点时要注意副作用。

`None == 0` 为 `False`，`None is None` 为 `True`。判断「没有值」用 `is None`。
