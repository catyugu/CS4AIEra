  - 区分各实例独立的状态与所有实例共享的状态

当一组数据和围绕这组数据的操作需要一起使用时，把它们放进一个边界里比散落在多个函数里更容易推理。要判断的是：这个实例的状态保存在哪里、哪个操作会修改它、多个实例之间是否共享了不该共享的东西。
