计算几个矩形的面积，每次都需要长乘以宽。可以把这个计算写成一个函数，再用不同的参数调用它。

## 定义函数，再调用它

```python run id="program-logic-and-state.functions-and-side-effects.return"
def area(width, height):
    return width * height


small = area(3, 2)
large = area(5, 4)
print(small, large)
```

`def area(width, height):` 定义函数，下面缩进的语句是函数体。定义时创建函数并绑定到名字 `area`，乘法还没有执行。调用 `area(3, 2)` 时，3 和 2 分别绑定到参数名 `width` 和 `height`；`return` 算出 6，将它交回调用处，再赋给 `small`。

`area(5, 4)` 是另一次调用，有自己的参数绑定，返回 20。函数体中的局部名字只用于这次调用，不会变成调用方的名字。

定义中的名字与调用时的值分别称为<Term id="parameter-and-argument">形参与实参</Term>。

## return 结束当前调用

函数可以根据条件提前返回。下面找出列表中第一个超过上限的数：

```python run id="program-logic-and-state.functions-and-side-effects.find"
def first_above(numbers, limit):
    for number in numbers:
        if number > limit:
            return number
    return None


print(first_above([3, 8, 12], 5))
print(first_above([3, 8, 12], 20))
print(first_above([], 5))
```

找到 8 时，`return` 结束整个调用，12 不再检查。没有找到时返回 `None`，这是 Python 表示没有结果或缺失的特殊值；它与数值 0 和空列表不同。`return None` 和 `return number` 使用相同的返回机制，只是返回的值不同。

返回值和输出不同。`area(3, 2)` 返回 6，但自己不打印；`print(6)` 写出文字，它的返回值则是 `None`。函数执行到末尾而没有 `return`，也会返回 `None`。因此看见输出，不能据此判断函数返回了什么。

不带值的 `return` 也返回 `None`。检查结果是否为这个值，通常写作 `result is None`；`result is not None` 则检查它不是 `None`。

## 修改参数对象会影响调用方

调用时绑定参数名，并不复制参数对象。下面将一句笔记加入列表：

```python run id="program-logic-and-state.functions-and-side-effects.binding"
def add_note(items, text):
    items.append(text)


def replace_notes(items, text):
    items = [text]


notes = ["first idea"]
returned = add_note(notes, "another idea")
print("notes:", notes)
print("returned:", returned)
replace_notes(notes, "replacement")
print("after replacement:", notes)
```

调用 `add_note` 时，函数里的 `items` 与调用方的 `notes` 指向同一个列表，`append` 修改了它。这个函数没有 `return`，所以调用结果为 `None`。

调用 `replace_notes` 时，`items = [text]` 新建列表，只改变局部参数名 `items` 的绑定。调用方的 `notes` 仍指向原列表。两个参数名都只在各自的调用中使用。修改与重新赋值的区别见 <CrossRef id="program-logic-and-state.names-objects-and-state" />。

## 返回新列表，还是修改原列表

另一种做法是保留输入，返回加上新笔记的列表：

```python run id="program-logic-and-state.functions-and-side-effects.new-list"
def with_note(notes, text):
    result = list(notes)
    result.append(text)
    return result


notes = ["first idea"]
updated = with_note(notes, "another idea")
print("original:", notes)
print("updated:", updated)
```

`add_note` 和 `with_note` 都能添加内容，但调用方式不同：`add_note` 修改原列表，调用方直接使用原来的名字；`with_note` 保留原列表，调用方需要把返回的新列表赋给一个名字。

修改传入对象、写入输出、改变外部共享数据，这些对函数外部的影响叫<Term id="side-effect">副作用</Term>。函数返回什么、产生什么副作用，要分别读清楚。

| 调用 | 原列表是否改变 | 返回值 |
| --- | --- | --- |
| `add_note(notes, text)` | 是，追加一条笔记 | `None` |
| `with_note(notes, text)` | 否 | 追加后的新列表 |

## 调用陌生函数前的四个问题

- 它接受什么输入？
- 返回什么？
- 会修改什么？
- 什么情况下失败？

函数的<Term id="specification">规约</Term>应写清这些约定。例如 `with_note` 接收字符串列表与一个字符串，返回追加后的新列表，不修改输入。调用前输入必须满足的要求称为<Term id="precondition">前置条件</Term>。还要确认输入不符合要求时，是由调用方事先检查，还是由函数检测并报告失败；只看成功样例无法知道这个约定。

## 练习

两份函数都“加入一条笔记”。哪一份适合保留原稿、生成修改稿的需求，哪一份适合让所有使用原列表的代码看到追加结果？分别写出输入、返回值和副作用的约定。如果调用方忽略返回值，会有什么后果？

```python run id="program-logic-and-state.functions-and-side-effects.exercise-contracts"
def append_note(notes, text):
    notes.append(text)


def with_note(notes, text):
    updated = list(notes)
    updated.append(text)
    return updated


draft = ["first idea"]
result = with_note(draft, "revision")
print("draft:", draft)
print("result:", result)
returned = append_note(draft, "shared addition")
print("draft after append:", draft)
print("returned:", returned)
```
