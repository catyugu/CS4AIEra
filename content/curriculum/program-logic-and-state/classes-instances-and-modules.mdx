一本笔记本保存名称和若干条笔记。用列表保存笔记、用函数追加内容，已经能完成这些操作。如果要管理多本笔记本，还可以把每本的状态与操作组织成一个对象。

类定义这种对象怎样初始化、提供哪些操作；根据类创建的具体对象称为实例。下面只定义一种笔记本，然后创建两本，观察它们的笔记是否独立。

## 一个类可以创建多个实例

```python run id="program-logic-and-state.classes-instances-and-modules.instance-state"
class Notebook:
    def __init__(self, name):
        self.name = name
        self.notes = []

    def add(self, text):
        self.notes.append(text)


first = Notebook("draft")
second = Notebook("release")
first.add("first idea")
second.add("another idea")
print(first.name, first.notes)
print(second.name, second.notes)
print("same list:", first.notes is second.notes)
```

`class Notebook:` 定义一个类，绑定到名字 `Notebook`。类体里的 `def` 定义它提供的方法，缩进表示这些方法属于这个类。`__init__` 是 Python 约定的初始化方法名，两边各有两个下划线。

`Notebook("draft")` 创建这个类的一个实例，并调用 `__init__` 初始化它。`self` 接收到这个新实例，`name` 接收到字符串 `"draft"`。

`self.name = name` 在实例上建立属性 `name`，`self.notes = []` 建立属性 `notes`。每次初始化都新建列表，因此两个笔记本各有自己的笔记列表，最后一行打印 `False`。用点号访问属性，例如 `first.notes`，就能取得实例保存的对象。

## 方法接收到哪个实例

`add` 是定义在类里的函数，作为实例的方法调用。`first.add("first idea")` 把 `first` 作为第一个参数传入，函数体中的 `self.notes` 因而访问第一个笔记本。`Notebook.add(first, "first idea")` 也能表达这个调用。

`self` 是约定的参数名，不是一个特殊的全局对象。对第二个笔记本调用方法时，这次调用中的 `self` 就是 `second`。

## 类上的列表可能被多个实例共用

把 `notes = []` 移到类体，含义会变：

```python run id="program-logic-and-state.classes-instances-and-modules.class-body-state"
class Notebook:
    notes = []

    def __init__(self, name):
        self.name = name

    def add(self, text):
        self.notes.append(text)


first = Notebook("draft")
second = Notebook("release")
first.add("first idea")
print("first:", first.notes)
print("second:", second.notes)
print("same list:", first.notes is second.notes)
```

类体中的 `notes = []` 在创建类时执行一次，列表保存在类对象上，这叫<Term id="class-attribute">类属性</Term>。两个实例都没有自己的 `notes` 属性，读取时就找到类上的同一个列表。一次追加使两个笔记本都看到 `first idea`。

如果笔记列表属于各个笔记本，就在 `__init__` 中为每个实例新建列表；如果所有笔记本确实要共同维护一份笔记列表，才使用共享对象。判断依据是笔记列表应该由谁保存和修改。

## 练习

给第一个版本的 `Notebook` 增加 `count()` 方法，返回笔记数。创建两个实例，只给第一个加笔记，先预测两次调用的结果，再运行。然后把笔记列表移到类体，确认哪些结果改变，并说明原因。
