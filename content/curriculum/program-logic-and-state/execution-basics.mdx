程序是一组用编程语言写下的指令。计算机执行这些指令，读取数据、做运算，也可能显示结果、修改文件或与其他程序通信。网页、计算器和图片编辑器的功能，都是程序执行的结果。

人给出数据与处理规则，计算机按规则执行。例如算三个数的平均值：先相加，再除以 3。用 Python 可以写成：

```python run id="program-logic-and-state.execution-basics.first-program"
print((12.5 + 11.5 + 12.0) / 3)
```

点击这段代码旁的“运行”，下面会出现 `12.0`。括号里的加法先计算，`/` 表示除法，`print` 将结果显示在输出区。你可以修改一个数再运行，用“恢复代码”取回原来的写法。

代码是程序的文字形式，需要由能理解这种语言的工具执行。这里使用浏览器内的 Python 运行环境，每个单元格都可以独立运行，不需要先安装软件。这一章用 Python 观察执行过程，重点是读懂程序怎样处理数据。

## 给中间结果取名

写出所有数字适合一次计算；步骤变多时，可以给数据和结果取名：

```python
a = 12.5
b = 11.5
c = 12.0
total = a + b + c
mean = total / 3
print(mean)
```

这段程序从第一行开始，逐条执行语句。语句是程序中的一个执行步骤。在这里，前五条都是赋值，最后一条调用 `print` 输出结果。

`a = 12.5` 让名字 `a` 关联到值 `12.5`。这叫给变量赋值；在 Python 中，名字与值建立的这种关联也叫绑定。`=` 表示赋值，判断两个值是否相等要用 `==`。

执行 `total = a + b + c` 时，先取出三个名字当前的值，相加得到 `36.0`，再把 `total` 绑定到结果。随后读取 `total`，除以 3，得到 `mean`。名字的拼写由我们选择，`mean` 表示平均值；改名时，同一名字的所有使用位置也要一致。

## 赋值使用当时的值

`12.5`、`a`、`a + b + c` 都是表达式：它们可以计算出一个值。这个计算过程叫求值。赋值先求右边的值，再改变左边名字的绑定。

```python run id="program-logic-and-state.execution-basics.rebinding"
a = 10
b = a + 2
a = 20
print("a:", a)
print("b:", b)
```

第二行执行时，`a` 是 10，因而 `b` 得到 12。第三行改变 `a`，不会重新执行第二行，`b` 仍是 12。程序中的赋值不会自动建立“以后一直跟着更新”的关系。

`a = a + 1` 也遵循这个顺序：先用旧值计算，再把结果赋给 `a`。如果在建立 `a` 的绑定之前就读取它，会出现 `NameError`，表示这个名字尚未定义。

## 调用已有的函数

函数是可以调用的一段程序。Python 提供了 `print`、`round` 等已有函数，调用时在函数名后写括号，括号中放交给它处理的数据，称为参数。

```python
value = 11.87
rounded = round(value)
print("original:", value)
print("rounded:", rounded)
```

`round(value)` 对这里的数取整，返回 12。“返回”表示将结果交回调用处，所以可以把它赋给 `rounded`。`print` 将数据写到输出区，也可以一次打印多个值，用逗号隔开。

第二行计算并保存结果，直到第四行才显示它。后面定义自己的函数时，也会分别看它返回什么、输出什么。

## 数值和文本不同

`12` 是整数，Python 的类型名是 `int`；`12.5` 是浮点数，类型名是 `float`。带引号的 `"12"` 是字符串，类型名是 `str`，其中保存的是文本字符。引号决定了写下的是数值还是文本。

类型说明这个值能做哪些操作。同一个 `+` 对数值做加法，对字符串做拼接：

```python run id="program-logic-and-state.execution-basics.types"
print(2 + 3)
print("2" + "3")
print(type(12), type(12.5), type("12"))
print(1 + "2")
```

先输出 5，再输出 23，后者是两个字符串拼接的结果。`type` 返回值的类型。最后一行要求整数与字符串相加，Python 没有定义这种操作，报出 `TypeError`，也就是类型错误。

错误结束这次执行，后面的语句不再运行，已经输出的文字仍保留。`b = "11.5"` 本身是合法赋值；若把平均值程序里的 `b` 改成这个字符串，会在加法处失败，尚未执行到 `print(mean)`。如何处理这样的异常，见 <CrossRef id="program-logic-and-state.exceptions-and-cleanup" />。
