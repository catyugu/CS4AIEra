程序是一组用编程语言写下的指令。计算机执行这些指令，读取数据、做运算，也可能显示结果、修改文件或与其他程序通信。网页、计算器和图片编辑器的功能，都是程序执行的结果。

人给出数据与处理规则，计算机按规则执行。例如算三个数的平均值：先相加，再除以 3。用 Python 可以写成：

```python run id="program-logic-and-state.execution-basics.first-program"
print((12.5 + 11.5 + 12.0) / 3)
```

点击这段代码旁的“运行”，下面会出现 `12.0`。你可以修改一个数再运行，用“恢复代码”取回原来的写法。

这行代码由几种不同的部分组成：

| 写法 | 含义 |
| --- | --- |
| `12.5`、`11.5`、`12.0`、`3` | 直接写出数值，这样的写法称为<Term id="literal">字面量</Term> |
| `+`、`/` | 运算符，分别表示加法和除法 |
| `(12.5 + 11.5 + 12.0)` | 用括号把加法分组，使它先于外面的除法计算 |
| `print(...)` | 调用 Python 提供的输出函数，将括号中的计算结果显示出来 |

这里两对括号的用途不同：里面的一对把加法括起来；`print` 后面的一对表示调用函数，把要输出的值交给它。执行时先算出平均值，再由 `print` 输出。

代码是程序的文字形式，需要由能理解这种语言的工具执行。这里使用浏览器内的 Python 运行环境，每个单元格都可以独立运行，不需要先安装软件。代码块带有“运行”按钮时能直接执行；其他代码块供阅读。这一章用 Python 观察执行过程，重点是读懂程序怎样处理数据。

## 给中间结果取名

写出所有数字适合一次计算；步骤变多时，可以给数据和结果取名：

```python run id="program-logic-and-state.execution-basics.named-steps"
a = 12.5
b = 11.5
c = 12.0
# 计算总和与平均值
total = a + b + c
mean = total / 3
print(mean)
```

这段程序从第一行开始，逐条执行语句。语句指定程序要执行的动作：这里前五条语句给名字赋值，最后一条调用 `print` 输出结果。以 `#` 开始的部分是注释，供人阅读，不参与计算；空行也不执行动作。

`a = 12.5` 让名字 `a` 关联到值 `12.5`。这叫给变量赋值；在 Python 中，名字与值建立的这种关联也叫绑定。`=` 表示赋值，判断两个值是否相等要用 `==`。

执行 `total = a + b + c` 时，先取出三个名字当前的值，相加得到 `36.0`，再把 `total` 绑定到结果。随后读取 `total`，除以 3，得到 `mean`。名字的拼写由我们选择，`mean` 表示平均值；改名时，同一名字的所有使用位置也要一致。

把 `b` 改成另一个数，平均值会怎样变化？也可以在计算总和之后加入 `print(total)`，观察中间结果。打印放在赋值之前时，这个名字还没有得到值。

`12.5`、`a`、`a + b + c` 都能计算出一个值，这样的代码称为表达式。计算表达式的值叫求值。赋值语句先计算右边，再把结果绑定到左边的名字。

## 变量名与字符串字面量不同

程序里的名字由字母等字符写成，但读取名字时，得到的是它关联的值。例如 `mean` 读取平均值，`"mean"` 则直接表示四个字符组成的文本。带引号写出的文本称为字符串字面量，求值得到的文本值称为字符串。

```python run id="program-logic-and-state.execution-basics.names-and-strings"
mean = 12.0
message = "mean"
print(mean)
print("mean")
print(message)
```

第一个 `print` 读取变量名 `mean`，输出 `12.0`。第二个直接使用字符串字面量，输出 `mean`，不会查找同名变量。第三个读取变量名 `message`，它关联的是字符串，因此也输出 `mean`。变量名可以关联数值，也可以关联字符串。

引号是代码中标出字符串的符号，不属于这里的字符串内容，所以输出不包含引号。简单字符串可以用双引号 `"mean"`，也可以用单引号 `'mean'`；前后使用同一种引号。

`print("a:", a)` 可以一次输出多个值，用逗号隔开：`"a:"` 提供用于辨认结果的文字，`a` 提供变量当前的值。若读取一个尚未赋值的名字，会出现 `NameError`；把同样的拼写放在引号里，则只是字符串，不要求存在这个名字。

## 赋值使用当时的值

读取名字使用的是执行到这一刻时它关联的值：

```python run id="program-logic-and-state.execution-basics.rebinding"
a = 10
b = a + 2
a = 20
print("a:", a)
print("b:", b)
```

第二行执行时，`a` 是 10，因而 `b` 得到 12。第三行改变 `a`，不会重新执行第二行，`b` 仍是 12。程序中的赋值不会自动建立“以后一直跟着更新”的关系。

`a = a + 1` 也遵循这个顺序：先用旧值计算，再把结果赋给 `a`。

## 值的类型决定可以做哪些运算

字面量 `12` 给出整数，Python 的类型名是 `int`；`12.5` 给出浮点数，类型名是 `float`；`"12"` 给出字符串，类型名是 `str`。字符串里的字符即使都是数字，也不会自动成为数值。

类型说明这个值能做哪些操作。同一个 `+` 对数值做加法，对字符串做拼接：

```python run id="program-logic-and-state.execution-basics.types"
number = 12
text = "12"
print(type(number), type(12.5), type(text))
print(number + 3)
print(text + "3")
print(number + text)
```

`type` 返回传入值的类型，第一行输出依次显示 `int`、`float` 和 `str`。随后输出数值相加的结果 `15`，再输出字符串拼接的结果 `123`。最后一行虽然两边都是变量名，读到的却分别是整数和字符串；Python 没有定义这两种值相加的操作，报出 `TypeError`，也就是类型错误。

错误结束这次执行，后面的语句不再运行，已经输出的文字仍保留。`b = "11.5"` 本身是合法赋值；若把平均值程序里的 `b` 改成这个字符串，会在加法处失败，尚未执行到 `print(mean)`。如何处理这样的异常，见 <CrossRef id="program-logic-and-state.exceptions-and-cleanup" />。
