快速排序按一个主元（pivot）把当前区间分成两小段，其余交给递归。主元最终停在哪个位置，决定一段递归是摊成 $\Theta(\log n)$ 层、还是塌成一条 $\Theta(n)$ 的链，最坏成本与期望成本因此是两个不同的阶，同一个算法在两种输入上就能分别取到它们。

## 分区：一条循环不变量

快速排序的核心是一个<Term id="in-place">原地</Term>划分过程：把区间里的元素按「小于主元」与「不小于主元」分成两段，并让主元落在两段之间的最终位置上。用区间 `items[low .. high]` 与末元素作主元，扫描过程把已经处理好的那一段分成相邻的两块，$j$ 是下一个待检查的位置，$boundary$ 是两块的分界：

1. `items[low .. boundary)` 里的元素都 `< 主元`
2. `items[boundary .. j)` 里的元素都 `>= 主元`
3. `items[high]` 仍是主元本身，尚未移动

**初始化**：$j = low$、$boundary = low$，两块都为空，三条同时成立，现在只需要证明每一轮之后它们仍然成立。

**维护步**：每轮检查 `items[j]`，它不小于主元时留在原地，第二块右端扩展一格；它小于主元时是整段扫描里唯一需要动作的地方——把 `items[j]` 与 `items[boundary]` 交换，再让 $boundary$ 前进一格。交换前 `items[boundary]` 属于第二块、因此不小于主元，交换后它落到位置 $j$ 补进第二块，而小于主元的当前元素进入第一块；当 $boundary = j$ 时这次交换只是自交换。两种情况在处理完位置 $j$ 之后都重新得到 `items[low .. boundary) < 主元` 与 `items[boundary .. j+1) >= 主元`。这一步用到的前提是分界只在 $boundary$ 处移动，两块因此始终相邻、不重叠。

**终止与后置条件**：$j$ 每轮加 1，上界是 $high$，循环必然结束；结束时 $j = high$，两块覆盖了整个 $[low, high)$。把主元与 `items[boundary]` 处的元素交换，后置条件就是「`items[boundary]` 等于主元，且左侧全小于、右侧全不小于它」——主元已落在最终位置，不再参与后续排序，递归因此可以继续。存在等键元素时，这个位置未必是等键记录之间唯一可能的最终位置。

## 从子问题规模推导

分区把主元放到一个最终位置上，这个位置把区间切成两半，而主元自己不再参与递归——每递归一层，待排区间至少少掉一个元素，递归因此一定会停。设当前区间含 $n$ 个元素，主元最终落在下标 $p$，并令 $k = p - low$ 表示左侧子问题的元素个数，则右侧有 $n - k - 1$ 个元素，递归式为

$$T(n) = T(k) + T(n - k - 1) + \Theta(n).$$

这里的 $k$ 量的是左侧子问题含有多少个元素，$p$ 才是数组中的绝对下标。对长度为 $n$ 的区间，一次分区把另外 $n-1$ 个元素各与主元比较一次，因此分区成本是 $n-1 = \Theta(n)$。递归式本身不给答案，答案取决于 $k$ 随输入怎么变：

- **平衡情形**：如果每次分区都落在中间附近，比如两侧规模都不超过 $c n$（$c < 1$），递归树每一层合计仍是 $\Theta(n)$，层数是 $\Theta(\log n)$，于是 $\Theta(n \log n)$。
- **极端不平衡**：如果每次 $k = 0$ 或 $k = n-1$，就是 $T(n) = T(n-1) + \Theta(n) = \Theta(n^2)$。取末元素作主元时，已排序或逆序的输入每次都把主元留在端点，是最坏情形，由输入顺序决定。

这两条说的都是「给定主元选择的后果」。对固定取末元素作主元的实现，如果进一步假设输入是**键两两不同**的均匀随机排列，也可以得到期望 $\Theta(n \log n)$；但这是关于输入分布的假设，任意给定输入并不享有这项保证。

随机主元换了概率来源：算法自己掷随机数，每次递归都从当前区间中独立、均匀地选择一个位置作主元，于是主元的秩在当前子问题里均匀分布，与输入原本怎样排列无关——这一条对任意固定的输入都成立。**期望分析用到的假设只有两条**：各次主元的选择相互独立且均匀，且排序键两两不同。有了独立均匀的主元，每个子问题的规模在期望意义上按常数比例缩小，期望比较次数因此是 $\Theta(n \log n)$。

二路 `<` / `>=` 分区在大量重复键上可能退化：所有键都相等时，每次分区仍只缩小一个元素，随机主元也避免不了 $\Theta(n^2)$。重复键需要专门的分区策略。

```python run id="alg.quicksort.partition"
def partition(items, low, high, rounds):
    """Postcondition: returns the pivot's final index, with items[low..index) < pivot <= items[index..high]."""
    pivot = items[high]
    boundary = low
    for j in range(low, high):
        if items[j] < pivot:
            items[boundary], items[j] = items[j], items[boundary]
            boundary += 1
        rounds.append((j, boundary))
    items[boundary], items[high] = items[high], items[boundary]
    return boundary


sample = [3, 8, 2, 5, 6, 4]
rounds = []
position = partition(sample, 0, len(sample) - 1, rounds)
for j, boundary in rounds:
    print("round", j, "| boundary", boundary)
print("pivot index:", position, "| pivot value:", sample[position])
```

在这个分区上，$j$ 从 0 走到 4，$boundary$ 只在 $j = 0$ 与 $j = 2$ 两处前进，正是 `items[j]` 小于主元的两轮；其余三轮把元素留在第二块，分界不动。循环结束后主元落到下标 2，值 4 的左侧都小于 4、右侧都不小于 4，正是上面写的后置条件。

```python run id="alg.quicksort.cases"
from random import Random


def quicksort(items, low, high, pivot_of, comparisons):
    """Postcondition: items[low..high] is non-decreasing; comparisons[0] counts element comparisons."""
    if low >= high:
        return
    chosen = pivot_of(low, high)
    items[chosen], items[high] = items[high], items[chosen]
    pivot = items[high]
    boundary = low
    for j in range(low, high):
        comparisons[0] += 1
        if items[j] < pivot:
            items[boundary], items[j] = items[j], items[boundary]
            boundary += 1
    items[boundary], items[high] = items[high], items[boundary]
    quicksort(items, low, boundary - 1, pivot_of, comparisons)
    quicksort(items, boundary + 1, high, pivot_of, comparisons)


size = 64
rng = Random(20261013)
last_element = lambda low, high: high
random_element = lambda low, high: rng.randrange(low, high + 1)
for name, case in (("sorted", list(range(size))), ("reversed", list(range(size, 0, -1)))):
    truth = sorted(case)
    for label, pivot_of in (("last element", last_element), ("random", random_element)):
        data, comparisons = list(case), [0]
        quicksort(data, 0, size - 1, pivot_of, comparisons)
        print(f"{name:>8} | pivot {label:>12} | comparisons {comparisons[0]:>5} | sorted: {data == truth}")
worst = size * (size - 1) // 2
print(f"worst n(n-1)/2 = {worst}")
```

末元素主元下，已排序与逆序两种输入都达到 $n(n-1)/2$ 次比较，落进 $\Theta(n^2)$ 那一支。把同一个输入上的主元换成随机选择，比较次数回到与期望值同一量级，输入顺序不再决定成本；各用例排出的结果都与输入的多重集一致。

确定性的 $\Theta(n \log n)$ 最坏界需要别的机制，例如限制递归深度并在退化时切换策略，或用一个线性时间的选取过程来挑主元。后者建立在「选择」这一操作上，属于 <CrossRef id="algorithms.selection-and-top-k" />。
