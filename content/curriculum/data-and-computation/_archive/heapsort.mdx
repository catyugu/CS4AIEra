最大堆的堆顶是整个数组的最大值。取出它、恢复剩下部分的堆序、再取新的堆顶，取出的次序从大到小；把每次取出的元素从数组末端往里放，同一个数组最终就是升序的。堆排序是这个动作的原地实现，全程不需要第二块缓冲区。它复用 <CrossRef id="algorithms.heaps" /> 建立的两条不变量——完全二叉树的形状，以及父子之间的顺序。形状不变量固定，可以取反的只是父子顺序的方向：默认的小顶堆保证父不大于子、堆顶是当前最小值，取反得到最大堆、堆顶是当前最大值，形状不变量与建堆的线性论证都不变。

## 两个阶段：建堆与取出

建堆从最后一个有孩子的下标往前扫，对每个下标做一次向下调整。能向下走很多层的节点足够少：按「节点还能下降多少层」分层计数，总和收敛到 $\Theta(n)$，而不是让 $n$ 个节点各自向下走满 $\log n$ 层——完整推导在 <CrossRef id="algorithms.heaps" />。建堆结束时整段数组是最大堆；取出阶段从 $e = n$ 开始。

取出阶段每步做两件事：把堆顶——前缀的最大值——与前缀的最后一个槽位交换，再令前缀缩短一号，对新的堆顶做一次向下调整。换到后缀最前的那个值原来就是前缀的最大值，不小于前缀里的任何元素，也不大于后缀里已有的元素，后缀因此仍然非降序；前缀里可能被破坏的只有新堆顶这一处父子关系，沿一条路径向下调整就能修好。

每一步之后两条不变量同时成立：

- 前缀 $[0, e)$ 是最大堆；
- 后缀 $[e, n)$ 非降序，且每个后缀元素都不小于每个前缀元素。

初始 $e = n$ 时后缀为空，第二条空洞地成立，第一条正是刚建成的整堆。每步把前缀最大值送进后缀最前再令 $e \leftarrow e - 1$：该值不小于所有前缀元素、不大于所有后缀元素，新后缀仍非降序、仍整体不小于前缀；缩短后的前缀只在新堆顶处可能违反堆序，一次向下调整把它恢复。取到 $e = 1$ 为止，前缀只剩一个元素，它自然是堆，后缀已覆盖整个数组。

取出共 $n-1$ 次，每次向下调整最多走 $\lfloor \log_2 n \rfloor$ 层，与输入的具体排列无关，合计 $\Theta(n \log n)$；建堆的 $\Theta(n)$ 被这一项吸收。交换与下沉都发生在原数组内，`sift_down` 只持有 `root`、`end`、`child` 三个下标，不分配随 $n$ 增长的缓冲，辅助空间是 $O(1)$。

```python run id="alg.heapsort.in-place"
def sift_down(heap, root, end):
    """Move heap[root] down until heap[root:end] is a max-heap again."""
    while True:
        child = 2 * root + 1
        if child >= end:
            return
        if child + 1 < end and heap[child + 1] > heap[child]:
            child += 1
        if heap[root] >= heap[child]:
            return
        heap[root], heap[child] = heap[child], heap[root]
        root = child


def heapsort(items, trace=False):
    """Sort in place: build a max-heap over the whole array, then swap the top
    into a growing suffix and shrink the prefix."""
    n = len(items)
    for root in range(n // 2 - 1, -1, -1):
        sift_down(items, root, n)
    if trace:
        print("heap  :", items, "  sorted", [])
    for end in range(n - 1, 0, -1):
        items[0], items[end] = items[end], items[0]
        sift_down(items, 0, end)
        if trace:
            print(f"end {end}: heap {items[:end]}  sorted {items[end:]}")


data = [7, 3, 9, 1, 5, 3, 8]
print("before:", data)
heapsort(data, trace=True)
print("after :", data)
```

单元格把每次取出后的数组按两段分开打印：右端 `sorted` 后缀逐行变长并保持非降序，左端 `heap` 前缀逐行缩小且始终是最大堆，重复键各占一位；`heapsort` 只在传入的 `data` 上交换槽位，没有构造第二个列表。堆顶交换把一个元素直接送到数组的另一端，会越过等键记录，所以堆排序不保证等键记录之间的相对次序（<CrossRef id="algorithms.sorting" /> 把稳定性列为排序输出的后置条件之一）。
