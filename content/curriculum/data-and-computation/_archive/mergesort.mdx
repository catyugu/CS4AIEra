把两个已经排好的序列合成一个有序序列，只需要同时读两个序列的首元素，每次取走更小的那个；某一个读空后，把另一个余下的部分整体接上。合并长度为 $n_1$、$n_2$ 的两个有序序列时，每个元素被写进结果一次，成本是 $\Theta(n_1 + n_2)$。

归并排序反复使用这条规则：把区间按中点切成两半，两半各自排好，再合并。切分只看长度、不看键的分布，调用树每一层所有合并合计处理 $\Theta(n)$ 个元素；<CrossRef id="algorithms.divide-and-conquer" /> 把这条规则当作分治的样板，逐步记录了合并的轨迹。

当 $n$ 是 2 的幂时，递归式可以直接写成 $T(n) = 2T(n/2) + \Theta(n)$；对一般的 $n$，更精确的形式是 $T(n) = T(\lfloor n/2 \rfloor) + T(\lceil n/2 \rceil) + \Theta(n)$。两者都解为 $\Theta(n \log n)$：递归树有 $\Theta(\log n)$ 层，每层合计处理 $\Theta(n)$ 个元素（见 <CrossRef id="algorithms.recurrences-and-call-trees" />）。成本由长度决定，不依赖键的分布，所以最好与最坏落在同一阶。

```python run id="alg.mergesort.trace"
from random import Random


def merge_sort(records, key, counters):
    """Postcondition: non-decreasing by key, stable, and a permutation of the input."""
    if len(records) <= 1:
        return list(records)
    middle = len(records) // 2
    left = merge_sort(records[:middle], key, counters)
    right = merge_sort(records[middle:], key, counters)
    merged = []
    i = 0
    j = 0
    while i < len(left) and j < len(right):
        counters["comparisons"] += 1
        if key(left[i]) <= key(right[j]):
            merged.append(left[i])
            i += 1
        else:
            merged.append(right[j])
            j += 1
    merged.extend(left[i:])
    merged.extend(right[j:])
    return merged


print(f"{'n':>6} {'comparisons':>12} {'n log2 n':>9} {'ratio':>6}")
for size in (8, 64):
    records = [(index % 4, index) for index in range(size)]
    Random(20261003).shuffle(records)
    counters = {"comparisons": 0}
    merge_sort(records, key=lambda record: record[0], counters=counters)
    reference = size * (size.bit_length() - 1)
    print(f"{size:>6} {counters['comparisons']:>12} {reference:>9} "
          f"{counters['comparisons'] / reference:>6.2f}")

tiny = [(1, "a"), (0, "x"), (1, "b")]
print("equal keys keep their order:", merge_sort(tiny, key=lambda record: record[0], counters={"comparisons": 0}))
```

比较次数与同规模的 $n \log_2 n$ 同阶，输入包含重复键时也不改变这个量级。

## 稳定性来自取左侧

稳定与否取决于合并时相等键的取用方向：两侧键相等就取左侧，相等键不会因为合并而换位，输出里它们的相对次序与输入一致。上例里 `a` 排在 `b` 前面、两条记录键都为 1，输出仍是 `a` 在前。

## 辅助空间是线性的

合并每一步都要一块能放下当层结果的缓冲，顶层缓冲的长度达到 $n$；常见的数组实现显式复用一个长度 $n$ 的工作缓冲，再加 $O(\log n)$ 的递归栈，辅助空间因此是 $\Theta(n)$。原地合并存在，代价是移动次数上升。
