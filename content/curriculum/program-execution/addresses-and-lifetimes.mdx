把一个列表传给两个函数，它们会看到同一份可变内容。机器执行这些访问时，需要找到对象存放的位置。地址（address）提供位置，类型提供怎样解读那里内容的规则，而生命周期决定这个对象此时还能不能访问。

## 指针保存位置，解引用访问对象

内存可以按地址定位字节，一个对象可能占据连续的多个字节。在 C 中，`int` 是整数类型；`int *` 是指向整数对象的指针类型。`&x` 取得对象 `x` 的地址，`*p` 访问指针 `p` 指向的对象：

```c
int x = 7;
int y = 20;
int *p = &x;
int *q = p;
*q = 9;
p = &y;
*p = 21;
```

| 执行结束的位置 | x | y | p 指向 | q 指向 |
| --- | --- | --- | --- | --- |
| `int *q = p` | 7 | 20 | x | x |
| `*q = 9` | 9 | 20 | x | x |
| `p = &y` | 9 | 20 | y | x |
| `*p = 21` | 9 | 21 | y | x |

复制指针只复制地址。重新给 `p` 赋值不改变 `q`，也不移动 `x`。这与 Python 的<Term id="alias">别名</Term>模型可以对照，但 Python 的名字绑定并不提供 C 那样的直接指针运算。

地址必须与有效对象及访问类型一起判断。把一个整数当成地址，不会自动在那里创建整数对象；地址看起来非零，也不能证明它可用。

## 连续数组与结构体

`int a[3] = {10, 20, 30};` 声明三个连续的整数对象。若此平台的 `sizeof(int)` 为 4，且数组起始地址记为 $A$，三项的位置分别为 $A,A+4,A+8$。`sizeof` 查询对象或类型占据的字节数。

`a[i]` 访问第 `i` 项，`a + i` 定位第 `i` 项，步长由元素类型决定。因此 `a + 1` 跨过一个整数对象，并非只前进一个字节。索引 3 定位到数组结束处，可以用作遍历终点，却不能解引用为第四个元素。C 的下标操作不会自动执行 Python 列表那样的边界检查。

结构体把多个字段组成一个对象。以下 `struct Sample` 定义一个由标记和整数值组成的类型，点号访问字段：

```c
struct Sample {
    char tag;
    int value;
};

struct Sample sample = {'A', 10};
sample.value = 12;
```

编译器可能在字段之间及对象末尾添加填充，以满足地址对齐要求。因而 `sizeof(struct Sample)` 可能大于两个字段大小之和，见 [WG14 C 工作草案 N3096 的结构体与 sizeof 规则](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n3096.pdf)。按“字段大小相加”猜测外部数据格式会把这些填充也带进去；外部格式应明确规定各字段位置。

## 对象结束后，旧指针不能延长它的生命

函数中的普通局部对象随所属块的执行结束而结束生命周期。下面的函数返回了一个地址，但调用方得到地址时，地址原来指向的局部对象已经失效：

```c
int *make_value(void) {
    int value = 42;
    return &value;
}
```

`int *` 写在函数名前表示返回整数指针，`void` 表示没有参数，花括号围住函数体。危险来自生命周期，而非整数 42 的大小。即使随后的一次访问看起来仍得到 42，也不能据此认为合法。

需要让对象跨越这次调用，可以动态申请空间，并明确由谁释放：

```c
#include <stdlib.h>

int *make_value(void) {
    int *p = malloc(sizeof *p);
    if (p == NULL) {
        return NULL;
    }
    *p = 42;
    return p;
}
```

`malloc` 按字节申请空间，失败返回 `NULL`，它表示空指针。`sizeof *p` 取得整数对象的大小，不在这里读取 `p` 指向的内容。调用方使用完后调用 `free(p)`，结束所申请空间的生命周期；分配和释放的规范见 [WG14 N3096 的内存管理函数](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n3096.pdf#page=381)。

忘记释放，会持续占用空间。释放后，指向该对象的所有旧指针都失去合法访问依据；只把其中一个指针设为 `NULL`，不会改变其他副本。重复释放或访问已释放对象属于<Term id="undefined-behavior">未定义行为</Term>，故障可能立即出现，也可能在以后覆盖其他对象时才出现。
