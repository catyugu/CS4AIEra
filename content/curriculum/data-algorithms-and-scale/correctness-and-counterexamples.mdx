一份清单中，同一个标识可能出现多次。要求按标识去重，保留它第一次出现时的标题，各项按首次出现的顺序排列。

下面的代码把标识与标题放进字典：

```python run id="data-algorithms-and-scale.correctness-and-counterexamples.dedupe-keys"
tasks = [("a", "old title"), ("b", "other title"), ("a", "new title")]
first = {}
for task_id, title in tasks:
    first[task_id] = title
print(list(first.items()))
```

两个标识各出现一次，顺序也正确，但 `a` 的标题被后一次覆盖了。“已经去重”不足以说明满足了全部要求。

## 先写清正确的含义

<Term id="specification">规约</Term>规定允许哪些输入、必须得到哪些结果。本例允许输入一个有限列表，每项是 `(标识, 标题)`，两项都是字符串；重复标识的标题可以不同。输出要求是：

- 每个出现过的标识恰好保留一项；
- 标题取该标识第一次出现时的标题；
- 各项按标识首次出现的顺序排列。

空输入对应空输出。重复项的标题相同或不同，都由这份规约覆盖。它没有规定必须用字典实现，列表加集合等写法也可以满足要求。

## 一个反例已经足够

开头的三个输入项证明了那段代码不满足规约。还可以缩成两项：`[("a", "old"), ("a", "new")]`。没有别的标识和排序干扰，只剩下“取第一次还是最后一次”这个区别。

这种满足输入要求、却使结果违反保证的输入叫反例。一个反例就能推翻“对所有允许输入都正确”的主张。

反过来，若干输入测试通过，只说明那些输入上没有发现问题。要说明一般情况，需要解释程序为何始终遵守规则。

## 循环不变量

修正办法是只在标识尚未出现时写入。这里用 `while` 把处理到哪一项明确写出来：

```python run id="data-algorithms-and-scale.correctness-and-counterexamples.loop-state"
def dedupe(tasks):
    first = {}
    i = 0
    while i < len(tasks):
        print("processed:", i, "saved:", first)
        task_id, title = tasks[i]
        if task_id not in first:
            first[task_id] = title
        i += 1
    return list(first.items())


tasks = [("a", "old title"), ("b", "other title"), ("a", "new title")]
print("result:", dedupe(tasks))
```

每轮开始时，已经处理的是前 `i` 项。字典保存了这段前缀里每个标识的第一次标题，并按首次出现的顺序排列。这就是<Term id="invariant">循环不变量</Term>：在每轮相同的检查位置都成立的性质。

要证明它成立，需要三个步骤：

1. **开始时成立。** `i = 0`，已处理前缀为空，字典也为空。
2. **一轮后仍成立。** 新标识第一次出现，就在末尾加入它的标题；旧标识再次出现，就保持已有值。然后 `i` 增加 1，字典恰好描述扩大了一项的前缀。
3. **结束时得到所需结果。** 循环结束时 `i` 等于输入长度，前缀就是全部输入。不变量于是给出规约要求的标题和次序。

这里的次序依赖 [Python 字典保持插入顺序](https://docs.python.org/3/library/stdtypes.html#mapping-types-dict)的保证。`list(first.items())` 将键值二元组按这个顺序转成列表。

## 还要证明会结束

不变量告诉我们循环结束时结果怎样，但还需要说明它确实会结束。本例输入有限，`i` 从 0 开始，每轮增加 1。未处理项数 `len(tasks) - i` 是非负整数，每轮减少 1，最多经过输入长度那么多轮就到 0。

如果漏掉 `i += 1`，非空输入上循环就不能推进。不变量可以依然成立，程序却无法返回结果。正确性既要检查结果，也要检查终止。

## 练习

下面按整对二元组去重。它是否满足按标识去重、保留第一次标题的规约？先用不同标识、完全重复项、同标识不同标题三类输入判断，再运行核对。

```python run id="data-algorithms-and-scale.correctness-and-counterexamples.exercise-dedupe"
def dedupe(tasks):
    result = []
    for task in tasks:
        if task not in result:
            result.append(task)
    return result


tasks = [("a", "old"), ("b", "other"), ("a", "new")]
print(dedupe(tasks))
```
