一张无向图，边一条一条地加进来，每加一条就问一次「$u$ 和 $v$ 现在还连通吗」。最直接的做法是重新遍历一遍图：单次回答是对的，代价是每次查询都重扫全图。

这一课把这类查询改写成「维护顶点集合上的一个划分」，给出并查集的契约、两种合并策略与摊还成本。最小生成树用同一份划分回答另一个问题，见 <CrossRef id="algorithms.connectivity-and-spanning-trees" />。

## 从静态连通性到增量连通性

遍历那一节已经证明：无向图遍历森林的每棵树恰好是一个连通分量。那是一个**静态快照**上的结论：图给定，跑一次 BFS/DFS，连通性就全部知道了。

换一个操作模型，问题就变了。假设边是一条一条加入的（$E_0 \subseteq E_1 \subseteq \cdots$），中间要反复回答同一个问题：「$u$ 和 $v$ 现在连通吗？」设一共问 $q$ 次，第 $j$ 次问的时候图里已经有 $E_{i_j}$，那么每问一次就重跑一遍遍历，总成本是

$$\Theta\left(\sum_{j = 1}^{q} \big(|V| + |E_{i_j}|\big)\right).$$

最自然的用法是每加入一条边就问一次：此时 $q$ 与最终边数同阶，记最终边数为 $M = |E|$，总成本就是 $\Theta(M|V| + M^2)$——平方级。这正是需要一种能**增量维护**连通关系的结构的原因。

## 并查集：维护一个划分

并查集的抽象状态是**顶点集合上的一个划分**：若干个两两不交的块，每个块就是当前图的一个连通分量。`parent`、`size`、`rank` 都只是这个划分的一种表示，不是它的定义。

| 操作 | 契约 |
| --- | --- |
| `find(v)` | 返回 `v` 所在块中的某个代表元；不指定是哪一个，只要求同一块内返回值相同 |
| `union(u, v)` | 把 `u` 与 `v` 所在的两个块合并成一个块 |

契约是：处理完边前缀 $E_i$ 之后，对任意 $u, v$，`find(u) == find(v)` 当且仅当 $u, v$ 在 $(V, E_i)$ 中连通。

这条充要条件才是并查集的契约。它按加入的边数归纳：$E_0 = \varnothing$ 时每个顶点自成一个块，契约平凡成立；加入边 $(u, v)$ 时，如果 $u, v$ 原本同块，那么图与划分都没有变化，契约保持不变；如果原本异块，新边恰好把这两个连通分量合成一个，而 `union` 也恰好合并这两个块，其余块不受影响，契约同样保持。所以每个前缀 $E_i$ 之后契约都成立。

两个方向在这里都用了：同一块说明它们之间已经有路径；不同块说明它们还没有被任何已加入的边连起来。单元格 A 是对这条归纳的实例验证，不代替证明。

```python run id="alg.graphs.dsu-partition"
from collections import deque


def connected_in(vertices, edges, u, v):
    """Independent oracle: plain BFS over the current edge set."""
    adjacency = {vertex: [] for vertex in vertices}
    for a, b in edges:
        adjacency[a].append(b)
        adjacency[b].append(a)
    seen = {u}
    queue = deque([u])
    while queue:
        current = queue.popleft()
        for neighbour in adjacency[current]:
            if neighbour not in seen:
                seen.add(neighbour)
                queue.append(neighbour)
    return v in seen


class DisjointSet:
    """The abstract state is a partition; parent/size are only its representation."""

    def __init__(self, vertices, compress=True, by_size=True):
        self.parent = {vertex: vertex for vertex in vertices}
        self.size = {vertex: 1 for vertex in vertices}
        self.compress = compress
        self.by_size = by_size
        self.find_steps = 0

    def find(self, vertex):
        root = vertex
        while self.parent[root] != root:
            root = self.parent[root]
            self.find_steps += 1
        if self.compress:
            while self.parent[vertex] != root:
                self.parent[vertex], vertex = root, self.parent[vertex]
        return root

    def union(self, u, v):
        root_u, root_v = self.find(u), self.find(v)
        if root_u == root_v:
            return False
        if self.by_size and self.size[root_u] < self.size[root_v]:
            root_u, root_v = root_v, root_u
        self.parent[root_v] = root_u
        self.size[root_u] += self.size[root_v]
        return True


vertices = ["a", "b", "c", "d", "e", "f"]
edge_sequence = [("a", "b"), ("c", "d"), ("b", "c"), ("e", "f"), ("d", "e"), ("a", "f")]
structure = DisjointSet(vertices)
prefix = []
contract_holds = True
for edge in edge_sequence:
    prefix.append(edge)
    structure.union(*edge)
    for u in vertices:
        for v in vertices:
            if (structure.find(u) == structure.find(v)) != connected_in(vertices, prefix, u, v):
                contract_holds = False
print("edge list must contain each undirected edge once; |E| =", len(edge_sequence))
print("find(u) == find(v)  <=>  u, v connected in (V, E_i) after every prefix:", contract_holds)
roots = {structure.find(vertex) for vertex in vertices}
print("components after all edges:", len(roots), "| the partition has one block per component")

naive = DisjointSet(vertices, compress=False, by_size=False)
amortised = DisjointSet(vertices, compress=True, by_size=True)
for vertex in vertices[:-1]:
    naive.union(vertex, vertices[-1])
    amortised.union(vertex, vertices[-1])
print()
print("adversarial chain of unions into one hub")
print("  find steps, no compression / no union by size:", naive.find_steps)
print("  find steps, compression + union by size:      ", amortised.find_steps)
print("  amortised O((n + m) alpha(n)) is a statement about the whole sequence, not one find")
print("  the structure answers same/different only: it never returns an actual path")
```

单元格 A 把契约逐前缀核对：每加一条边，就对全部顶点两两比较「并查集说同块吗」与「独立 BFS 说连通吗」，两者必须在每个前缀上一致。后半段用同一条对抗性的合并链比较了两种实现的代价，也顺便说明了「摊还」这个词的对象是整串操作。
## 成本与能力边界

能力边界同样要写清：

- 支持：反复做「加入一条边」与 `union` 两个块，查询两个顶点是否同块；
- 不支持：一般的删边——把一条边去掉后重新分裂块，不是这个结构能做的；
- 不给路径：`find` 只回答「是不是同一块」，不给出连接它们的实际路径；
- 不是有向工具：它不回答有向可达，也不是强连通分量算法。

**复杂度必须写成摊还的**。按大小合并配上路径压缩，$m$ 次操作的整串成本是 $O((n + m)\alpha(n))$，其中 $n$ 是顶点数、$\alpha$ 是增长极慢的反阿克曼函数。这不是说单次 find 最坏也是 $O(\alpha(n))$：按大小合并已经把树高限制在 $O(\log n)$，所以某一次 find 仍可能花 $O(\log n)$；路径压缩保证的是这种昂贵的结构不会持续出现，摊还到整串操作上才得到那个 $\alpha(n)$。


## 森林、树与成分数

有限无向森林的边数由成分数唯一决定：

**定理。** 若有限无向图 $(V, E)$ 是森林，其连通分量数为 $c$，则 $|E| = |V| - c$。$c = 1$ 就是树，于是非空树的边数恰好是 $|V| - 1$；空图有 $|E| = 0 = |V| - c$（$c = 0$）。

证明按连通分量逐个算：树的边数是顶点数减一（对 $|V|$ 归纳，每次删一个叶子），把 $c$ 棵树加起来就是 $|V| - c$。

这条等式直接给出并查集里成分数的变化：**每一次成功的 union 都让成分数减一**，因为它合并的是两个不同的块。返回假的那次 union 不改变划分——它接下的那条边在已加入的边里形成了一个环。这条判据正是最小生成树要用的：连通输入下森林的边数恰好是 $|V| - 1$。
