把松弛原语留到边上，每一轮按同一个边序列把全部边扫一遍，重复若干轮，每个顶点的距离就在这些扫描之间往前传播。这条路线不给顶点排处理顺序，也就不依赖「某个顶点一旦确定就永不改写」这种结构，负边可以留在图里而不破坏它。这一课要问两件事：这样的反复扫描需要多少轮，才能让每个有限距离收敛到真正的最优值；以及当某类顶点根本不存在有限最优值时，算法怎样把它识别出来。

## 反复扫描全部边

松弛操作沿用 <CrossRef id="algorithms.shortest-paths" /> 的定义：若 $distance[u] + w(u, v) < distance[v]$，就用这个值更新 $distance[v]$。Bellman–Ford 每一轮按 <CrossRef id="algorithms.graph-representation" /> 的边列表接口把全部边依次松弛一遍，步骤如下：

1. $distance[s] = 0$，其余为 $+\infty$。
2. 重复 $|V| - 1$ 轮：每一轮按边序列顺序尝试松弛每一条边。
3. 再做一轮扫描：若能松弛某条边且其尾点距离有限，则回报「存在源点可达的负环」。

## 轮次不变量

这一节真正要证的只有一句话：**第 $i$ 轮之后，每条至多含 $i$ 条边的 $s \rightsquigarrow v$ 路径，其权重都已经传播到 $distance[v]$（$distance[v] \le$ 该路径的权重）；配合安全性不变量，凡是「最优值能由一条至多 $i$ 条边的路径取到」的顶点 $v$，此刻的 $distance[v]$ 就是它的最终值。** 两个结论都从这里长出来：无源点可达负环时最短行走可取成至多 $|V| - 1$ 条边的简单路径，于是 $|V| - 1$ 轮之后每个有限距离都已是真实最优值；负环检测把它复查的时机定在 $|V| - 1$ 轮之后，靠的也是同一个界。

**为什么这一点成立**：对轮数 $i$ 归纳。设 $P$ 是一条 $s \rightsquigarrow v$、至多 $i$ 条边的路径，末边为 $(u, v, w)$，$P$ 去掉末边得到一条到 $u$ 的、至多 $i - 1$ 条边的路径。按归纳假设，$distance[u]$ 在第 $i - 1$ 轮结束时已不超过这段前缀的权重；$distance$ 只降不升，这个上界进入第 $i$ 轮时仍然成立。这一轮按边序列扫到 $(u, v, w)$ 时，松弛比较 $distance[u] + w$ 与 $distance[v]$，得到 $distance[v] \le distance[u] + w \le P$ 的权重。$i = 0$ 时 $P$ 只含源点，$distance[s] = 0$ 平凡。

**这一步用到哪条假设**：只有「一轮扫遍全部边」与「按 $distance[u] + w < distance[v]$ 取较小者」两条。它不要求 $w \ge 0$——$distance[u]$ 可以比 $distance[v]$ 更晚、更小地被改善，$w$ 取负也照常参与比较。这正是撤掉非负假设后正确性的来源：<CrossRef id="algorithms.dijkstra" /> 的 settle 论证必须在 $w \ge 0$ 下才成立，轮次论证不碰这条条件。

**安全性**是配套的下界：任何时刻每个有限的 $distance[v]$ 都是某条真实 $s \rightsquigarrow v$ 行走的权重——松弛只把标签换成一条真实边的延伸，逐次归纳即得。它与上面的上界夹紧，给出 $distance[v] = \delta(s, v)$，**终止性**随之成立：没有源点可达负环时，$|V| - 1$ 轮之后每个有限距离都达到真实最短距离。

对**原地**扫描（每一轮直接使用本轮已更新的值），上界写成「$distance[v] \le$ 该路径的权重」，措辞是「有机会传播」：原地扫描在同一轮里可以连续传播多条边，所以 $distance[v]$ 可能已经好于「至多 $i$ 条边」这个界。改用**上一轮距离的副本**做同步松弛，才能写成「第 $i$ 轮后 $distance[v]$ 恰等于至多 $i$ 条边的最优值」——那是一个不同的算法（DP），不能拿原地版的代码去证明同步版的陈述。同步教学版每轮复制整张距离表（$\Theta(|V|)$）再逐边松弛，它自己的成本是 $\Theta(|V|^2 + |V| \cdot |E|)$，在 $|E| = 0$ 这样的小边数上也不会退化成 $\Theta(|V|)$。下面正文给出的 $\Theta(|V| + |V| \cdot |E|)$ 指的是原地版本以及负环检测与闭包。单元格把两者并排跑：同一个四段链上，原地版第一轮就把值推到最远处，同步版第一轮只走了一条边。

## 负环检测

判据是：第 $|V| - 1$ 轮之后再扫一遍全部边，若存在边 $(u, v, weight)$ 满足 $distance[u]$ 有限且 $distance[u] + weight < distance[v]$，则存在一条从 $s$ 可达的负环。要证的是这条判据两个方向都成立，而两边都落在同一个前提上：$distance[u]$ 必须有限。

条件里的「$distance[u]$ 有限」不能省。图里可能存在一个从 $s$ 根本走不到的分量，里面装着负环，此时所有从 $s$ 可达的距离都已经是最优值，算法**不应该**报警。这一条把检测的范围钉死在源点可达的负环上，否则会把它读成「检测整张图里有没有负环」。

**（可达负环 $\Rightarrow$ 有可松弛边）** 设 $C$ 是源点可达的负环，$w(C) < 0$。$C$ 上每个顶点在 $|V| - 1$ 轮之后都有有限的 label（它们都从 $s$ 可达）。反设环上没有任何边还能松弛，则每条环边都满足 $distance[v_{i+1}] \le distance[v_i] + w_i$。沿整个环相加，$distance$ 项两两消掉，得到 $0 \le w(C)$，与 $w(C) < 0$ 矛盾。

**（有可松弛边 $\Rightarrow$ 可达负环）** 反设不存在源点可达的负环。那么每个从 $s$ 可达的顶点 $v$ 都有最短路径，并可取成至多 $|V| - 1$ 条边的简单路径。由轮次不变量，$|V| - 1$ 轮之后 $distance[v] \le \delta(s, v)$；安全性不变量给出 $distance[v] \ge \delta(s, v)$，两边夹紧即 $distance[v] = \delta(s, v)$。取任意一条尾点 $u$ 可达的边 $(u, v, w)$，最短距离的三角不等式给出 $distance[v] = \delta(s, v) \le \delta(s, u) + w = distance[u] + w$，所以这条边不能松弛；每一条尾点有限的边都如此，与「有可松弛边」矛盾。

**检测给出的是存在性结论**：它只报告一个布尔值，$\delta$ 就仍是三值的——算法只对「可达且不受负环影响」的顶点给出正确值；受可达负环影响的顶点沿环多绕几圈就有任意轻的行走，**距离无界下降**，$\delta = -\infty$。要拿到每个顶点的三值答案，再补一步：

1. $|V| - 1$ 轮结束时，把所有「尾点距离有限、却仍能松弛」的边的头点收集起来。
2. 从这些头点出发沿出边做一次可达性遍历；被覆盖到的顶点全部标为 $-\infty$。
3. 不可达顶点仍是 $+\infty$，其余顶点保留 rounds 结束时的有限距离。

这一步就是邻接表遍历：构造邻接表一次，再从全部头点出发做一次多源 BFS，合计 $O(|V| + |E|)$，与前面用过的成本口径一致。

负环可以从可达顶点「扩散」出去，所以标记必须取闭包，不能只标环上的顶点。闭包为什么恰好是 $-\infty$ 的顶点集合，也分三条说清：

**头点**：某条边 $(u, v, w)$ 在 $|V| - 1$ 轮之后仍可松弛，且 $u$ 可达。若 $v$ 不受任何可达负环影响，它的有限最短距离早已收敛，不可能再被改善——矛盾。

**扩散**：从头点沿出边能走到的顶点，都落在同一个可达负环的影响范围内。

**反过来**：每个受可达负环影响的顶点都从某个负环可达；负环上按前一段至少有一条仍可松弛的边，因此它一定从某个头点被遍历到。

单元格把这一版和原地/同步两版并排跑：一边是最终收敛到的最优值，一边是 $\delta = -\infty$ 的顶点集合。

成本是 $|V| - 1$ 轮各扫一遍全部边，再加一次检测扫描，即 $\Theta(|V| + |V| \cdot |E|)$；只有在 $|E| \ge 1$ 时才能简化成 $\Theta(|V| \cdot |E|)$（$|E| = 0$ 时它是 $\Theta(|V|)$）。

```python run id="alg.graphs.shortest-paths-bellman-ford"
from collections import deque

INF = float("inf")


def build_weighted(vertices, arcs):
    adjacency = {vertex: [] for vertex in vertices}
    for u, v, weight in arcs:
        adjacency[u].append((v, weight))
    return adjacency


def bellman_ford(vertices, arcs, source, synchronous=False):
    """|V| - 1 rounds over the edge list; synchronous uses a copy per round."""
    distance = {vertex: INF for vertex in vertices}
    predecessor = {vertex: None for vertex in vertices}
    rounds = 0
    distance[source] = 0
    history = [dict(distance)]
    for _ in range(len(vertices) - 1):
        rounds += 1
        if synchronous:
            previous = dict(distance)
            for u, v, weight in arcs:
                if previous[u] != INF and previous[u] + weight < distance[v]:
                    distance[v] = previous[u] + weight
                    predecessor[v] = u
        else:
            for u, v, weight in arcs:
                if distance[u] != INF and distance[u] + weight < distance[v]:
                    distance[v] = distance[u] + weight
                    predecessor[v] = u
        history.append(dict(distance))
    return distance, predecessor, history, rounds


def relaxing_edges(distance, arcs):
    return [(u, v, w) for u, v, w in arcs if distance[u] != INF and distance[u] + w < distance[v]]


def reachable_from_arcs(arcs, starts):
    """Multi-source BFS over an adjacency built once: O(V + E), no full rescans."""
    adjacency = {}
    for u, v, _ in arcs:
        adjacency.setdefault(u, []).append(v)
    reached = set(starts)
    queue = deque(starts)
    while queue:
        u = queue.popleft()
        for v in adjacency.get(u, []):
            if v not in reached:
                reached.add(v)
                queue.append(v)
    return reached


def per_vertex_delta(vertices, arcs, source):
    """Extend Bellman-Ford to the full three-valued delta of every vertex."""
    distance, predecessor, history, rounds = bellman_ford(vertices, arcs, source)
    heads = {v for _, v, _ in relaxing_edges(distance, arcs)}
    affected = reachable_from_arcs(arcs, heads) if heads else set()
    delta = {}
    for vertex in vertices:
        if vertex in affected:
            delta[vertex] = -INF
        else:
            delta[vertex] = distance[vertex]
    return delta, distance, predecessor, affected, rounds


def walk_weight(predecessor, source, vertex, arcs):
    """Final-state check only: rebuild the walk for one vertex of one instance."""
    chain = [vertex]
    while chain[-1] != source:
        chain.append(predecessor[chain[-1]])
    chain.reverse()
    weight = 0
    for u, v in zip(chain, chain[1:]):
        weight += next(w for a, b, w in arcs if (a, b) == (u, v))
    return chain, weight


def lightest_path_by_enumeration(adjacency, source):
    best = {source: 0}

    def walk(vertex, weight_so_far, seen):
        for neighbour, weight in adjacency[vertex]:
            if neighbour in seen:
                continue
            candidate = weight_so_far + weight
            if neighbour not in best or candidate < best[neighbour]:
                best[neighbour] = candidate
            walk(neighbour, candidate, seen | {neighbour})

    walk(source, 0, {source})
    return best


chain_vertices = ["s", "a", "b", "c", "d"]
chain_arcs = [("s", "a", 1), ("a", "b", 1), ("b", "c", 1), ("c", "d", 1)]
in_place = bellman_ford(chain_vertices, chain_arcs, "s")
sync = bellman_ford(chain_vertices, chain_arcs, "s", synchronous=True)
print("four-arc chain, one round each")
print("  in-place    after round 1:", {v: in_place[2][1][v] for v in chain_vertices})
print("  synchronous after round 1:", {v: sync[2][1][v] for v in chain_vertices})
print("  in-place propagates several edges inside one round, so it is never worse:",
      all(in_place[2][i][v] <= sync[2][i][v] for i in range(len(chain_vertices)) for v in chain_vertices))
oracle_chain = lightest_path_by_enumeration(build_weighted(chain_vertices, chain_arcs), "s")
agrees = all(in_place[0][v] == oracle_chain[v] for v in oracle_chain) and all(
    in_place[0][v] == INF for v in chain_vertices if v not in oracle_chain)
print("  after |V| - 1 =", in_place[3], "rounds both agree with the oracle:", in_place[0] == sync[0] and agrees)

weighted_vertices = ["s", "a", "b", "c", "x", "y"]
weighted_arcs = [("s", "a", 3), ("s", "b", 5), ("a", "b", -1), ("b", "c", 2),
                 ("x", "y", -5), ("y", "x", 1)]
distance, predecessor, _, rounds = bellman_ford(weighted_vertices, weighted_arcs, "s")
print()
print("no negative cycle reachable from s: rounds =", rounds, "= |V| - 1")
print("  reachable part:", {v: distance[v] for v in ("s", "a", "b", "c")})
print("  unreachable part stays +inf:", {v: distance[v] for v in ("x", "y")})
print("  no edge can be relaxed after the last round:", relaxing_edges(distance, weighted_arcs) == [])
print("  final-state witness check (this instance only):")
for vertex in ("a", "b", "c"):
    chain, weight = walk_weight(predecessor, "s", vertex, weighted_arcs)
    print(f"    {vertex}: walk {' -> '.join(chain)} has weight {weight} == distance {distance[vertex]}:",
          weight == distance[vertex])
print("  the negative cycle x -> y -> x sits in an unreachable component, so it is not reported")

reachable_cycle_vertices = ["s", "a", "b"]
reachable_cycle_arcs = [("s", "a", 1), ("a", "b", -2), ("b", "a", 1)]
delta, raw, _, affected, _ = per_vertex_delta(reachable_cycle_vertices, reachable_cycle_arcs, "s")
print()
print("negative cycle a -> b -> a (weight -1) reachable from s")
print("  still relaxable after |V| - 1 rounds:", relaxing_edges(raw, reachable_cycle_arcs))
print("  per-vertex delta:", {v: delta[v] for v in sorted(delta)})
print("  the cycle makes a and b -inf, not the source:", affected == {"a", "b"})

tail_vertices = ["s", "a", "b", "z", "w"]
tail_arcs = [("s", "a", 1), ("a", "b", -2), ("b", "a", 1), ("b", "z", 1), ("s", "w", 4)]
delta_tail, raw_tail, _, affected_tail, _ = per_vertex_delta(tail_vertices, tail_arcs, "s")
print()
print("with z reachable from the cycle, z is -inf as well:", {v: delta_tail[v] for v in sorted(delta_tail)})
print("  but w, reachable from s without touching the cycle, keeps its finite value:",
      delta_tail["w"] == 4 and delta_tail["w"] == raw_tail["w"])
```

单元格里最后两段就是这个「取闭包」的实测：可达负环把 $a$ 与 $b$ 变成 $-\infty$，从环上可达的 $z$ 也是 $-\infty$，而从 $s$ 出发不经过环的 $w$ 保持有限值 4；不可达分量里的负环则完全没有出现在结果里。单元格里从 predecessor 重建行走的检查只用于算法的最终状态，不当作通用不变量。

**实现边界**：$+\infty$ 在单元格里用 `float("inf")` 表示，权重全部取整数，加法与比较按精确算术进行；这些是表示层的选择，不改变上面的轮数与判据结论。

## 算法选择表

| 输入条件 | 算法 | 要证明的核心性质 | 成本 |
| --- | --- | --- | --- |
| 单位权（$w(e) = 1$） | BFS | 层号恰为最少边数 | $\Theta(\lvert V_R \rvert + \lvert E_R \rvert)$，邻接表 |
| 加权且 $w(e) \ge 0$ | Dijkstra | settle 即最终距离（settle 不变量） | 取决于优先队列实现：教科书 decrease-key 为 $O((\lvert V \rvert + \lvert E \rvert) \log \lvert V \rvert)$；`heapq` 版按实际压入条目计 |
| 允许负边 | Bellman–Ford | 轮次不变量、源点可达负环检测、按闭包标记 $-\infty$ | 最坏 $\Theta(\lvert V \rvert + \lvert V \rvert \cdot \lvert E \rvert)$ |

表中三行的「输入条件」是硬前置：Dijkstra 在负边上没有正确性保证，BFS 在非单位权上算的是另一件事。

还有一条必须说清：「Bellman–Ford 支持负权」不等于「存在源点可达负环时它仍能给出有限的普通最短距离」。负环恰恰是让某些 $\delta(s, v)$ 不再是有限值的情形，此时正确的输出是 $-\infty$ 类的结果。要给出「每个顶点各自是哪一类」的答案，检测之后还要沿出边把 $-\infty$ 取一次闭包。

本节的边界：不涉及所有点对最短路（Floyd–Warshall）、稀疏图上的重标号（Johnson）、启发式搜索（A*）、0-1 权重的双端队列优化，也不利用 <CrossRef id="algorithms.dags-and-topological-order" /> 的拓扑序做 DAG 专用最短路；这些都不在本批次范围。
