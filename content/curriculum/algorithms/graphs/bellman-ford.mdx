把松弛原语留到边上，每一轮按同一个边序列把全部边扫一遍，重复若干轮，每个顶点的距离就在这些扫描之间往前传播。这条路线不给顶点排处理顺序，也就不依赖「某个顶点一旦确定就永不改写」这种结构，负边可以留在图里而不破坏它。剩下的两个问题是：这样的反复扫描需要多少轮，才能让每个有限距离收敛到真正的最优值；当某类顶点根本不存在有限最优值时，算法又怎样把它识别出来。

## 反复扫描全部边

松弛操作沿用 <CrossRef id="algorithms.shortest-paths" /> 的定义：若 $distance[u] + w(u, v) < distance[v]$，就用这个值更新 $distance[v]$。Bellman–Ford 每一轮按 <CrossRef id="algorithms.graph-representation" /> 的边列表接口把全部边依次松弛一遍，步骤如下：

1. $distance[s] = 0$，其余为 $+\infty$。
2. 重复 $|V| - 1$ 轮：每一轮按边序列顺序尝试松弛每一条边。
3. 再做一轮扫描：若能松弛某条边且其尾点距离有限，则回报「存在源点可达的负环」。

## 轮次不变量

要证的只有一句话：**第 $i$ 轮之后，每条至多含 $i$ 条边的 $s \rightsquigarrow v$ 路径，其权重都已经传播到 $distance[v]$（$distance[v] \le$ 该路径的权重）；配合安全性不变量，凡是「最优值能由一条至多 $i$ 条边的路径取到」的顶点 $v$，此刻的 $distance[v]$ 就是它的最终值。** 两个结论都从这里长出来：无源点可达负环时最短游走可取成至多 $|V| - 1$ 条边的简单路径，于是 $|V| - 1$ 轮之后每个有限距离都已是真实最优值；负环检测把它复查的时机定在 $|V| - 1$ 轮之后，靠的也是同一个界。

**为什么这一点成立**：对轮数 $i$ 归纳。设 $P$ 是一条 $s \rightsquigarrow v$、至多 $i$ 条边的路径，末边为 $(u, v, w)$，$P$ 去掉末边得到一条到 $u$ 的、至多 $i - 1$ 条边的路径。按归纳假设，$distance[u]$ 在第 $i - 1$ 轮结束时已不超过这段前缀的权重；$distance$ 只降不升，这个上界进入第 $i$ 轮时仍然成立。这一轮按边序列扫到 $(u, v, w)$ 时，松弛比较 $distance[u] + w$ 与 $distance[v]$，得到 $distance[v] \le distance[u] + w \le P$ 的权重。$i = 0$ 时 $P$ 只含源点，$distance[s] = 0$ 平凡。

**这一步用到哪条假设**：只有「一轮扫遍全部边」与「按 $distance[u] + w < distance[v]$ 取较小者」两条。它不要求 $w \ge 0$——$distance[u]$ 可以比 $distance[v]$ 更晚、更小地被改善，$w$ 取负也照常参与比较。这正是撤掉非负假设后正确性的来源：<CrossRef id="algorithms.dijkstra" /> 的确定论证必须在 $w \ge 0$ 下才成立，轮次论证不碰这条条件。

**安全性**是配套的下界：任何时刻每个有限的 $distance[v]$ 都是某条真实 $s \rightsquigarrow v$ 游走的权重——松弛只把标签换成一条真实边的延伸，逐次归纳即得。它与上面的上界夹紧，给出 $distance[v] = \delta(s, v)$，**终止性**随之成立：没有源点可达负环时，$|V| - 1$ 轮之后每个有限距离都达到真实最短距离。

对**原地**扫描（每一轮直接使用本轮已更新的值），上界写成「$distance[v] \le$ 该路径的权重」，措辞是「有机会传播」：原地扫描在同一轮里可以连续传播多条边，所以 $distance[v]$ 可能已经好于「至多 $i$ 条边」这个界。改用**上一轮距离的副本**做同步松弛，才写成「第 $i$ 轮后 $distance[v]$ 恰等于至多 $i$ 条边的最优值」——那是一个不同的算法（按边数的 DP）。下面正文与单元格都用原地版。

## 负环检测

判据是：第 $|V| - 1$ 轮之后再扫一遍全部边，若存在边 $(u, v, weight)$ 满足 $distance[u]$ 有限且 $distance[u] + weight < distance[v]$，则存在一条从 $s$ 可达的负环。要证的是这条判据两个方向都成立，而两边都落在同一个前提上：$distance[u]$ 必须有限。

条件里的「$distance[u]$ 有限」不能省。图里可能存在一个从 $s$ 根本走不到的分量，里面装着负环，此时所有从 $s$ 可达的距离都已经是最优值，算法**不应该**报警。这一条把检测的范围钉死在源点可达的负环上，否则会把它读成「检测整张图里有没有负环」。

**（可达负环 $\Rightarrow$ 有可松弛边）** 设 $C$ 是源点可达的负环，$w(C) < 0$。$C$ 上每个顶点在 $|V| - 1$ 轮之后都有有限的 label（它们都从 $s$ 可达）。反设环上没有任何边还能松弛，则每条环边都满足 $distance[v_{i+1}] \le distance[v_i] + w_i$。沿整个环相加，$distance$ 项两两消掉，得到 $0 \le w(C)$，与 $w(C) < 0$ 矛盾。

**（有可松弛边 $\Rightarrow$ 可达负环）** 反设不存在源点可达的负环。那么每个从 $s$ 可达的顶点 $v$ 都有最短路径，并可取成至多 $|V| - 1$ 条边的简单路径。由轮次不变量，$|V| - 1$ 轮之后 $distance[v] \le \delta(s, v)$；安全性不变量给出 $distance[v] \ge \delta(s, v)$，两边夹紧即 $distance[v] = \delta(s, v)$。取任意一条尾点 $u$ 可达的边 $(u, v, w)$，最短距离的三角不等式给出 $distance[v] = \delta(s, v) \le \delta(s, u) + w = distance[u] + w$，所以这条边不能松弛；每一条尾点有限的边都如此，与「有可松弛边」矛盾。

**检测给出的是存在性结论**：它只报告一个布尔值——存在一条源点可达的负环，而不报告环上有哪些顶点，也不区分哪些顶点受环影响。环本身可以取出来：第 $|V|$ 轮的扫描不再只是复查，它真的执行松弛，每改善一条边就同步更新 $distance$ 与 $parent$ 并记下被改善的顶点；这一轮结束时若没有任何顶点被改善，就不存在源点可达的负环，否则取最后被改善的那个顶点，从它沿 predecessor 走 $|V|$ 步一定落进环里，再从落点沿 predecessor 走回它自己就得到环的顶点序列。受可达负环影响的顶点 $v$ 满足 $\delta(s, v) = -\infty$——沿环多绕几圈就有任意轻的游走；这个三值取值分类见 <CrossRef id="algorithms.shortest-paths" />。

成本是 $|V| - 1$ 轮各扫一遍全部边，再加一次检测扫描，即 $\Theta(|V| + |V| \cdot |E|)$；只有在 $|E| \ge 1$ 时才能简化成 $\Theta(|V| \cdot |E|)$（$|E| = 0$ 时它是 $\Theta(|V|)$）。

```python run id="alg.graphs.shortest-paths-bellman-ford"
def bellman_ford(nodes, edges, source):
    """|V| - 1 rounds, then one relaxing pass that locates a reachable negative cycle."""
    distance = {v: float("inf") for v in nodes}
    parent = {v: None for v in nodes}
    distance[source] = 0
    for _ in range(len(nodes) - 1):
        for u, v, w in edges:
            if distance[u] + w < distance[v]:
                distance[v] = distance[u] + w
                parent[v] = u
    improved = None
    for u, v, w in edges:
        if distance[u] + w < distance[v]:
            distance[v] = distance[u] + w
            parent[v] = u
            improved = v
    if improved is None:
        return distance, None
    for _ in range(len(nodes)):
        improved = parent[improved]
    cycle, node = [improved], parent[improved]
    while node != improved:
        cycle.append(node)
        node = parent[node]
    return distance, cycle[::-1]


plain_nodes = ["s", "a", "b", "c"]
plain_edges = [("s", "a", 3), ("s", "b", 5), ("a", "b", -1), ("b", "c", 2)]
distance, cycle = bellman_ford(plain_nodes, plain_edges, "s")
print("no negative cycle: distances", {v: distance[v] for v in plain_nodes}, "| cycle", cycle)
loop_nodes = ["s", "a", "b"]
loop_edges = [("s", "a", 1), ("a", "b", -2), ("b", "a", 1)]
_, cycle = bellman_ford(loop_nodes, loop_edges, "s")
print("negative cycle reachable from s: vertices", cycle)
trap_nodes = [0, 1, 2]
trap_edges = [(2, 0, 1), (2, 1, -2), (1, 2, -2), (0, 2, -1)]
_, cycle = bellman_ford(trap_nodes, trap_edges, 0)
print("first improvable edge's head has no predecessor: vertices", cycle)
```

单元格三段都把结果打印出来。没有源点可达负环的图上，$|V| - 1$ 轮之后每条边都松不动了，距离收敛到 $s = 0$、$a = 3$、$b = 2$、$c = 4$。换成 $s \to a = 1$、$a \to b = -2$、$b \to a = 1$ 的图，第 $|V|$ 轮仍能改善边，算法记下这一轮最后被改善的顶点，从它沿 predecessor 走 $|V|$ 步落回环里，报告的环顶点是 $a \to b \to a$，环上两条边合计 $-2 + 1 = -1$。第三个图 $2 \to 0 = 1$、$2 \to 1 = -2$、$1 \to 2 = -2$、$0 \to 2 = -1$、源点 $0$，边按此顺序扫描：第一条仍可松弛的边是 $2 \to 0$，它的头点 $0$ 在前 $|V| - 1$ 轮里从未被改善，没有 predecessor；第 $|V|$ 轮真正执行的那次松弛把最后一个改善落在顶点 $2$ 上，从它走 $|V|$ 步落回环 $2 \leftrightarrow 1$，报告的环顶点是 $2 \to 1 \to 2$，两条边合计 $-2 + (-2) = -4$。

**实现边界**：$+\infty$ 在单元格里用 `float("inf")` 表示，权重全部取整数，加法与比较按精确算术进行；这些是表示层的选择，不改变上面的轮数与判据结论。

## 算法选择表

| 输入条件 | 算法 | 要证明的核心性质 | 成本 |
| --- | --- | --- | --- |
| 单位权（$w(e) = 1$） | BFS | 层号恰为最少边数 | $\Theta(\lvert V_R \rvert + \lvert E_R \rvert)$，邻接表 |
| 加权且 $w(e) \ge 0$ | Dijkstra | 确定即最终距离（确定不变量） | 取决于优先队列实现：教科书 decrease-key 为 $O((\lvert V \rvert + \lvert E \rvert) \log \lvert V \rvert)$；`heapq` 版按实际压入条目计 |
| 允许负边 | Bellman–Ford | 轮次不变量、源点可达负环检测并报告环 | 最坏 $\Theta(\lvert V \rvert + \lvert V \rvert \cdot \lvert E \rvert)$ |

表中三行的「输入条件」是硬前置：Dijkstra 在负边上没有正确性保证，BFS 在非单位权上算的是另一件事。

还有一条必须说清：「Bellman–Ford 支持负权」不等于「存在源点可达负环时它仍能给出有限的普通最短距离」。负环恰恰是让某些 $\delta(s, v)$ 不再是有限值的情形，此时受影响的顶点取 $-\infty$，取值分类见 <CrossRef id="algorithms.shortest-paths" />。

本节的边界：不涉及所有点对最短路（Floyd–Warshall）、稀疏图上的重标号（Johnson）、启发式搜索（A*）、0-1 权重的双端队列优化，也不利用 <CrossRef id="algorithms.dags-and-topological-order" /> 的拓扑序做 DAG 专用最短路；这些都不在本课范围。
