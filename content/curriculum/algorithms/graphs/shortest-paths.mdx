一条边带一个代价，从源点 $s$ 出发到每个顶点最少要花多少代价，这是单源最短路问题。同一张图上答案可能有限，也可能没有下界：有的顶点根本走不到，有的顶点可以绕一个「越绕越便宜」的环把代价压到任意低。本节把这三类回答收进同一个量——距离函数——再给出逼近它的共同原语。

先看一张具体的加权有向图。顶点是 $s, a, b, c, f, g$，边只有六条：$s \to a$ 权 2，$a \to b$ 权 $-3$，$b \to a$ 权 1，$s \to f$ 权 3，$s \to g$ 权 1，$g \to f$ 权 1。这张图就是本节的问题设置：有向加权图 $G = (V, E, w)$ 连同一个源点 $s \in V$，$V$ 与 $E$ 有限，$|E|$ 用「边序列长度」计数；$a \to b$ 与 $b \to a$ 成对出现构成圈，无向边按同样的一对反向有向边处理。权重由函数 $w \colon E \to R$ 给出，$R$ 表示实数集；**表示层不限制权重的正负**，哪一类算法允许多大范围的权重，是算法契约自己的事。<CrossRef id="algorithms.graph-representation" /> 把权重定义在边上，并给出「全部边构成一个连续可迭代序列」的边列表接口。

从 $s$ 出发问「到每个顶点最少花多少」，同一张图给出三种不同的回答：

```python run id="alg.graphs.shortest-paths-three-outcomes"
arcs = [
    ("s", "a", 2), ("a", "b", -3), ("b", "a", 1),
    ("s", "f", 3), ("s", "g", 1), ("g", "f", 1),
]
weight = {(u, v): w for u, v, w in arcs}

print("fewest cost to f:", min(weight[("s", "f")], weight[("s", "g")] + weight[("g", "f")]))
print("some edge enters c:", any(v == "c" for _, v, _ in arcs))
print("cycle a -> b -> a costs:", weight[("a", "b")] + weight[("b", "a")])
```

到 $f$ 的答案有限：$s \to f$ 花 3，$s \to g \to f$ 花 2，最少是 2。到 $c$ 的答案是 $+\infty$：没有任何边指向 $c$，从 $s$ 根本走不到它。到 $a$ 的答案是 $-\infty$：走到 $a$ 之后可以绕 $a \to b \to a$ 反反复复地走，这一圈合计 $-3 + 1 = -2$，每绕一次净减 2，绕得越多越便宜，没有下界。三种回答的差别，落在从 $s$ 出发能走出哪些权重上。

## 一个统一的问题

把「从 $s$ 出发按边走」这件事叫做 <Term id="walk">行走</Term>（walk）：一列顶点 $s = u_0, u_1, \dots, u_k = v$，其中每一对相邻顶点都构成一条边；它的权重是各边权重之和。$s \to a \to b \to a$ 是一条绕了 $a \to b \to a$ 一圈的行走，多绕几圈，权重一次次减去 2。行走允许重复顶点，**路径**（path）要求顶点互不重复：$s \to a \to b \to a$ 是行走，删掉末尾那个重复的 $a$ 得到的 $s \to a \to b$ 才是路径。

把所有行走的权重收成一个数，就是**距离**。记 $W(s, v)$ 为所有从 $s$ 到 $v$ 的行走的集合，$w(W)$ 为行走 $W$ 的权重（各边权重之和），单源最短路径问的是同一个量。

$$\delta(s, v) = \inf \lbrace \, w(W) \;\colon\; W \in W(s, v) \, \rbrace$$

用下确界而不用最小值，是因为三种回答里只有有限的那一种由集合里的元素取到，$+\infty$ 与 $-\infty$ 都不是某条具体行走的权重。$v$ 从 $s$ 不可达时 $W(s, v)$ 是空集，按约定 $\inf(\text{空集}) = +\infty$。

$-\infty$ 这类回答来自环。**环**（cycle）是一列顶点 $v_0, v_1, \dots, v_k = v_0$，其中 $v_0, \dots, v_{k-1}$ 两两不同，且每一对相邻顶点都是边；它的权重是各边权重之和，权重之和小于 0 的环叫**负环**。小图里的 $a \to b \to a$ 就是这样一个负环（合计 $-2 < 0$）。负环要把 $\delta$ 压到 $-\infty$，还需要一条可达性：它必须**从 $s$ 可达、并且从它出发还能走到 $v$**——只能从 $s$ 走到、却走不到 $v$ 的负环不改变 $\delta(s, v)$。

三种回答到这里合成一张表：

| $\delta(s, v)$ 的取值 | 条件 |
| --- | --- |
| $+\infty$ | $v$ 从 $s$ 不可达 |
| $-\infty$ | 存在一条从 $s$ 可达、并且从它出发还能走到 $v$ 的负环 |
| 有限值 | 其它情况，此时它是某个具体行走的权重 |

这三行接下来被证明成定理：不可达、有可达负环两条各自只需一句话，最后一条才是论证真正做功的地方。论证从**任意**一条 $s \to v$ 行走出发——此时还不能假定「最优行走」存在，因为下确界未必由集合中的元素取得。

**不可达**：$W(s, v)$ 是空集，按 $\inf(\text{空集}) = +\infty$ 立即得到 $\delta(s, v) = +\infty$。这一步只用到「$v$ 从 $s$ 不可达」这一前提。

**有可达负环**：设 $C$ 是一条从 $s$ 可达、并且从它出发还能走到 $v$ 的负环。把 $C$ 重复任意多次，得到一条比一条轻的 $s \to v$ 行走，权重没有下界，于是 $\delta(s, v) = -\infty$。这一步用到的是负环权重之和为负。

**转折点**：假设不存在这样的负环，要证明 $\delta(s, v)$ 有限、并且被真正取到。任取一条 $s \rightsquigarrow v$ 行走，它可能重复顶点。它出现的每个环都从 $s$ 可达，也都能走到 $v$（行走的前半段把环连到 $s$，后半段连到 $v$），所以按假设这些环的权重都不可能是负数——这是本节证明里唯一用到关键假设的地方。若行走重复了顶点，在所有「同一顶点的两次出现」里选间隔最短的一对：它们之间没有别的重复顶点，所以这一段的内部顶点两两不同，按环的定义（$v_k = v_0$，$v_0 \dots v_{k-1}$ 两两不同）它就是一个环。这个环不可能为负，删掉它之后权重不会增加。对剩下的行走重复这一步，最终得到一条权重不会更大的简单路径。有限图只有有限条简单路径，因此这些简单路径的权重集合有最小值；它同时就是所有行走权重的下确界，并且被一条简单路径真正取到。

第三类里最优值总可以取到一条**简单路径**，而简单路径至多含 $|V| - 1$ 条边；这个界会给基于轮次的最短路径算法提供轮数上界。

**实现边界**：上面的论证假定加法与比较是精确的；单元格里的权重全部取整数，以免把浮点舍入混进正确性讨论。

## 松弛与见证

把距离算出来需要一个共同原语：

<Term id="relaxation">松弛边</Term> $(u, v, weight)$：若 $distance[u] + weight < distance[v]$，则用这个值更新 $distance[v]$，并记下 <Term id="predecessor">前驱</Term> `predecessor[v] = u`。

**安全性不变量**：任何时刻，每个有限的 $distance[v]$ 都是某条真实 $s \rightsquigarrow v$ 行走的权重。

这条不变量是「上界性质」：算法给出的数永远不会低于真实最优值，只会逐渐逼近它。

**它是存在性陈述**：它断言某个真实行走取到该权重；`predecessor[v] = u` 只记录「最后一次改善 $v$ 时用的是边 $(u, v)$」，并不保存历史版本。看一个反例，边按 $s \to u: 10$、$u \to v: 0$、$s \to x: 1$、$x \to u: 1$ 的顺序扫描，现场扫描一轮后：

$$
\begin{aligned}
distance[u] &= 2, & predecessor[u] &= x \\
distance[v] &= 10, & predecessor[v] &= u \\
distance[x] &= 1, & predecessor[x] &= s
\end{aligned}
$$

当前 predecessor 链 $s \to x \to u \to v$ 的权重是 2，而 $distance[v]$ 是 10：$v$ 是在 $u$ 还是 10 的时候被改善的，那条历史没有留下来。

所以三件事要分开：安全性不变量说的是「有限标签是某条真实行走的权重」（存在性）；`predecessor[v]` 只记录最后一条改善边；只有在具体算法的**最终条件**下（例如没有相关负环），才能另外证明最终的 predecessor 指针可以还原出一条最短路径。

存在多条等长最短路时 predecessor 并不唯一（哪一条取决于边的处理顺序），因此不能把 predecessor 形成的树写成算法的输出契约。

## 单位权下的 BFS

当 $w(e) = 1$ 对所有边成立时，「最轻的行走」恰是「边数最少的行走」，BFS 直接给出答案；<CrossRef id="algorithms.graph-traversal" /> 用队列不变量给出 BFS 的层次结构。

「所有边权重相同」不能笼统地化成「不妨取 1」：公共权重 $c > 0$ 时最小权重等价于最少边数，而且 $\delta = c \cdot level$；$c = 0$ 时所有可达顶点的距离都是 0，与层号无关；$c < 0$ 时更长的行走反而更轻（有相关环时甚至得到 $-\infty$）。所以本节的前提写成单位权。

**定理**：BFS 的层号等于最少边数，即 $level[v] = $「$(s, v)$ 的最少边数」。

**（上界）** parent 链 $v \to parent[v] \to \dots \to s$ 每一步都是一条边，长度恰为 $level[v]$，所以存在一条 $level[v]$ 条边的行走，最少边数 $\le level[v]$。

**（下界）** 对任意一条 $s = u_0 \to \dots \to u_k = v$ 的行走沿 $i$ 归纳可得 $level[u_i] \le i$。源点 $i = 0$ 平凡。设 $level[u_i] = l \le i$，来处理 $u_i$ 的邻居 $u_{i+1}$：若 $u_{i+1}$ 尚未发现，它被发现的层号就是 $l + 1 \le i + 1$；若 $u_{i+1}$ 已经发现：它若尚未 `finished`，则 BFS 的队列不变量（队列按非递减层号处理，且只含当前层 $l$ 与下一层 $l + 1$）给出 $level[u_{i+1}] \le l + 1$；它若已经 `finished`，则按层号非递减的出队顺序，它的层号更早确定且不超过 $l$。两种情况都有 $level[u_{i+1}] \le l + 1 \le i + 1$。取 $i = k$ 得 $level[v] \le k$。由于任意行走都满足这条，最少边数 $\ge level[v]$。

两方向合起来 $level[v] = $ 最少边数。证明只用到 BFS 的队列不变量与 $level[v] = level[parent[v]] + 1$，没有用到权重——这正是问题所在：**BFS 不能推广成非负权最短路**。

```python run id="alg.graphs.shortest-paths-unit-weight"
from collections import deque


def levels(adjacency, source):
    """BFS over an adjacency dict; the weights on the edges are never read."""
    level = {source: 0}
    queue = deque([source])
    while queue:
        u = queue.popleft()
        for v in adjacency[u]:
            if v not in level:
                level[v] = level[u] + 1
                queue.append(v)
    return level


unit = {"s": ["a", "b"], "a": ["c"], "b": ["c"], "c": ["d"], "d": []}
print("unit weights: level = fewest edges:", levels(unit, "s"))

weighted = {"s": ["a", "b"], "a": [], "b": ["a"]}
cost = {("s", "a"): 5, ("s", "b"): 1, ("b", "a"): 1}
level = levels(weighted, "s")
print("weights: level[a] =", level["a"], "| lightest walk to a costs", cost[("s", "b")] + cost[("b", "a")])
```

带权的那张图是反例：$s \to a$ 的权重是 5，但 $s \to b \to a$ 只要 2。BFS 说 $a$ 是 1 条边之外，这个结论在「边数」问题里正确，在「权重」问题里错误。

权重统一的假设一旦撤掉，层号与最轻权重就分道扬镳：$level$ 计量边数，$distance$ 计量权重。把权重真正计入距离的推进方式要对权重加一条约束，才能重新获得可以证明的确定结构——这条约束就是非负性 $w(e) \ge 0$。
