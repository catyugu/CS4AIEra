快速排序把待排区间按一个 pivot 分成两段，pivot 最终停在区间里的哪个位置，两段就各有多少元素。把 pivot 从末元素改成从区间里随机挑一个，同一份输入上两次运行的划分不再相同：一次分得均匀，递归深度是 $\Theta(\log n)$；一次每次都只切下一个元素，递归塌成一条 $\Theta(n)$ 的链。算法内部一旦有随机位，同一份输入上每次运行的路径就可能不同（随机选择 pivot 的快速排序的期望分析在 <CrossRef id="algorithms.quicksort" />）。

路径随随机位变化之后，契约比确定性版本多出两个问题。答案还保证正确吗——同一份输入两次运行的路径不同，输出会不会也跟着不同？运行时间又该怎么描述，它不再是输入的函数，两次运行给出两个数。对这两个问题的不同回答，给出两类契约。

## 两类契约：Las Vegas 与 Monte Carlo

随机 pivot 的快速排序对这两个问题的回答是：无论 pivot 落在哪里，递归结束时数组总是排好序的，随机性只改变到达排序所用的比较次数；运行时间因此是随机变量，契约写成它的期望或高概率界。另一些算法把随机性用在答案上：运行时间有确定上界，代价是答案可能出错，契约报出错误概率。两类契约并排写出来：

| | 输出 | 时间 | 保证 |
| --- | --- | --- | --- |
| Las Vegas | 总是正确 | 随机变量 | 期望时间，或高概率时间 |
| Monte Carlo | 可能出错 | 确定，或有界 | 错误概率的上界 |

量词落在算法随机位 $R$ 上：输入 $x$ 固定，只在算法可读的随机位上取概率（把输入与随机位分开处理的角度见 <CrossRef id="algorithms.average-and-randomized" />）。Las Vegas 的「总是正确」按这条量词写，就是对每个固定输入、每次抽样的 $R$，返回的结果都正确；它的运行时间 $T(x, R)$ 随 $R$ 取值，有限期望还推出算法以概率 $1$ 终止。

## 一个 Monte Carlo 例子：验证矩阵乘积

给定 $n \times n$ 矩阵 $A$、$B$ 与候选乘积 $C$，要判断 $C = AB$ 是否成立。把 $C$ 再乘一遍需要 $O(n^3)$ 次乘法；随机位换来的检查更快。抽一个均匀随机的 $0/1$ 向量 $x$，比较 $A(Bx)$ 与 $Cx$：$C = AB$ 时两者对每个 $x$ 都相等；$C \neq AB$ 时 $D = AB - C$ 非零，取它的一行非零 $d$。固定 $x$ 除某个 $d_j \neq 0$ 的分量外的所有取值，只有一个 $x_j$ 的取值能让 $d \cdot x = 0$，于是 $d \cdot x = 0$ 的 $x$ 不超过全部 $0/1$ 向量的一半；$Dx = 0$ 蕴含 $d \cdot x = 0$，一次检查误判的概率因此不超过 $1/2$。运行时间是确定的（一次矩阵向量乘法），代价是可能接受一个错的乘积——错误只出在「接受」这一侧，正确结果在任何一轮都不会被拒绝。

```python run id="alg.rand.amplify"
import random


def verify_product(a, b, c, rng):
    """Freivalds' check: multiply by a random 0/1 vector on the right.
    A correct product is never rejected; a wrong one is rejected with
    probability at least 1/2 per vector."""
    n = len(a)
    x = [rng.randint(0, 1) for _ in range(n)]
    bx = [sum(b[i][j] * x[j] for j in range(n)) for i in range(n)]
    abx = [sum(a[i][j] * bx[j] for j in range(n)) for i in range(n)]
    cx = [sum(c[i][j] * x[j] for j in range(n)) for i in range(n)]
    return abx == cx


def verify_repeated(a, b, c, rng, rounds):
    """Accept only when every round accepts: the one-sided amplification."""
    return all(verify_product(a, b, c, rng) for _ in range(rounds))


rng = random.Random(20260603)
n = 12
a = [[rng.randint(0, 9) for _ in range(n)] for _ in range(n)]
b = [[rng.randint(0, 9) for _ in range(n)] for _ in range(n)]
product = [[sum(a[i][t] * b[t][j] for t in range(n)) for j in range(n)] for i in range(n)]
wrong = [row[:] for row in product]
wrong[n // 2][n // 2] += 1

trials = 200
print("correct product accepted:", verify_repeated(a, b, product, rng, 5))
for rounds in (1, 3, 5):
    accepted = sum(1 for _ in range(trials) if verify_repeated(a, b, wrong, rng, rounds))
    print(f"  rounds = {rounds:>2}: false accept rate {accepted / trials:.4f} "
          f"(bound 2^-k = {2 ** -rounds:.5f})")
```

## 独立重复

单轮检查的误判概率上界是 $1/2$。把 $k$ 轮独立重复按「每一轮都接受才算接受」组合起来：接受一个错的乘积，要求每一轮都恰好把 $A(Bx)$ 与 $Cx$ 判成相等。每轮抽自己的随机向量，这些事件互相独立，概率相乘，错误概率降到 $2^{-k}$；正确结果在任何一轮都不会被拒绝，这条规则只压低「接受错答案」的概率，不会引入新的错误方向。上面单元格对同一个错乘积跑 $1$、$3$、$5$ 轮，假接受频率随轮数下降。

独立性是这条推导的前提。各轮共用同一批随机位时，同一个 $x$ 会让所有轮次同时成功或同时失败，概率不再相乘，重复不再降低错误概率。
