上一课确定了规模与一次操作的含义。这一课把这些计数写成函数并比较它们：$O$、$\Omega$、$\Theta$ 是函数之间的关系，回答增长多快，不回答当前快不快。

## 三条定义

设 $f$、$g$ 是定义在自然数上的非负函数。

$$
\begin{aligned}
f(n) = O(g(n)) &\iff \exists\, c > 0,\ n_0 : \forall n \ge n_0,\ f(n) \le c\,g(n) \\
f(n) = \Omega(g(n)) &\iff \exists\, c > 0,\ n_0 : \forall n \ge n_0,\ f(n) \ge c\,g(n) \\
f(n) = \Theta(g(n)) &\iff f(n) = O(g(n)) \wedge f(n) = \Omega(g(n))
\end{aligned}
$$

三条定义都带「存在常数与存在起点」，说的是足够大之后的形状。$\Theta$ 也可以写成双侧夹逼的形式，注意两个常数彼此独立：

$$
f(n) = \Theta(g(n)) \iff \exists\, c_1, c_2 > 0,\ n_0 : \forall n \ge n_0,\ c_1\,g(n) \le f(n) \le c_2\,g(n)
$$

$3n^2 + 5n$ 同时是 $O(n^2)$、$\Omega(n)$、$\Theta(n^2)$，也是 $O(n^3)$：上界不排除更松的界，所以 $O$ 不表示紧确的渐进量级。要断言「同一个渐进量级」只能用 $\Theta$，但 $\Theta$ 仍然允许相差常数因子：$n$ 与 $1000n$ 都是 $\Theta(n)$，它也不要求 $f(n)/g(n)$ 收敛。$\Theta$ 给出的是紧确的渐进界，不是精确值。一个 $\Theta(1)$ 的成本函数当然也是 $O(n)$，只是这个上界很松。同一个算法可以有最佳情形 $\Theta(1)$ 与最坏情形 $\Theta(n)$，那时讨论的是两个不同的成本函数，各自有自己的界。

记号允许把常数因子与低阶项排除在结论之外，代价是结论不再说明当前的 $n$ 上谁快（见最后一节），换来的是结论不随常数级差异改变：如果两台机器或两套成本模型对所研究的基本操作只相差与输入规模无关的固定常数因子，$\Theta$ 类不变。实现换掉算法而改变增长量级时，结论当然会变——渐进结论依赖成本模型，只是不区分同一个模型内的常数差异。

## 常见增长族

| 函数 | 规模翻倍后的变化 | 典型来源 |
| --- | --- | --- |
| $1$ | $1$ | 固定次数的基本操作（在已声明的成本模型下） |
| $\log n$ | 只增加一个常数 | 二分、平衡树的深度 |
| $n$ | $2$ | 一次遍历 |
| $n \log n$ | 略多于 $2$ | 归并排序、堆排序等最优比较排序 |
| $n^2$ | $4$ | 两两层 |
| $n^3$ | $8$ | 三层枚举 |
| $2^n$ | 变成平方 | 子集枚举 |
| $n!$ | 变成 $(2n)! / n!$ | 全排列枚举 |

表中 $\log$ 的底固定且大于 1；换底只改变常数因子，不影响所在增长族。

这个顺序不能被常数因子推翻：无论常数 $c$ 多大，都存在 $n_0$，使 $n \ge n_0$ 之后 $c\,\log n < n$、$c\,n^2 < 2^n$ 成立。增长族的差别是最终会被放大到任意倍数的差别。

## 和、积与嵌套循环

- 顺序执行的两段代码，成本是两者之和。对非负成本函数恒有 $f + g = \Theta(\max\{f, g\})$；只有进一步知道 $f = O(g)$ 时，才能把它化简成 $f + g = \Theta(g)$。「只保留较大的那一项」需要这额外前提，参数只有一个并不自动满足它。
- 嵌套循环的循环体执行次数是各层迭代次数的乘积，前提是各层的范围基数不依赖外层索引：外层 $n$ 次、内层 $m$ 次，得到 $n \cdot m$ 次；如果循环体成本是 $\Theta(1)$，由此得到对应的 $\Theta$ 成本。
- 内层范围依赖外层大小时代入乘积不成立。`for i in range(n): for j in range(i):` 的总次数是对 $i$ 从 0 到 $n - 1$ 求和，化简为 $n(n - 1)/2$，量级是 $\Theta(n^2)$；把内层每次都按 $n$ 次代入会得到错误的精确计数，两个结果却仍在同一个 $\Theta(n^2)$ 量级——精确计数与渐进量级是两回事。
- 循环体内如果还有一次规模为 $k$ 的扫描，且这一步与前面各层独立，乘积再乘一次，写成 $n \cdot m \cdot k$。

```python run id="alg.asymptotic.growth"
def count_pairs(values):
    """Count every ordered pair; an intentionally quadratic body."""
    operations = 0
    for left in values:
        for right in values:
            operations += 1
    return operations


def count_scans(values):
    """Two linear passes over the same input."""
    operations = 0
    for _ in range(2):
        for _ in values:
            operations += 1
    return operations


print("pairs / scans, by size:")
for size in (50, 100, 200, 400):
    pairs = count_pairs(range(size))
    scans = count_scans(range(size))
    print(f"n={size:4d}  pairs={pairs:7d}  scans={scans:4d}  pairs/n^2={pairs / size**2:.3f}  scans/n={scans / size:.3f}")
```

$\text{pairs} / n^2$ 稳定在 1 附近，$\text{scans} / n$ 稳定在 2 附近：在这两个多项式例子里，固定常数因子不改变 $\Theta$ 类，$n$ 与 $n^2$ 的幂次区分了增长量级。比率因此可以当作判断候选增长族的经验诊断：在不断扩大的实验区间里 $T(n)/g(n)$ 保持在非零常数量级，这与 $T = \Theta(g)$ 相容，但有限实验不能证明渐进归属；正式的 $\Theta$ 论断仍然要按定义给出常数与起点。

## 一个以上的参数

规模不是一个数时，先把界的作用域写清楚。设 $D \subseteq \mathbb{N}^k$ 是合法参数域，$f = O(g)$ 表示存在 $c > 0$ 与 $N$，使所有 $\mathbf{n} \in D$ 且 $n_1 + \cdots + n_k \ge N$ 时都有 $f(\mathbf{n}) \le c\,g(\mathbf{n})$；$\Omega$ 与 $\Theta$ 同理。这样定义的界对所有合法参数组合统一成立，孤立顶点（$E = 0$ 而 $V \to \infty$）也在量词覆盖范围内。

记号里要保留每一个参数。图的存储与遍历常常写成 $O(V + E)$，它不能被等价地化成 $O(E)$：孤立顶点很多时这个界仍然要由 $V$ 支撑。对简单图可以进一步推出 $O(V^2)$，但那是更松的界，不是等价化简，而且丢掉了稀疏图的信息。朴素字符串匹配同时依赖文本长度 $n$ 与模式长度 $m$，写作 $O(n \cdot m)$，因为内层循环的代价由 $m$ 决定。

多参数还取消了「可以把某一个符号项直接丢掉」这条便利：$V$ 与 $E$ 在整个合法输入域上谁也不统一支配谁——孤立顶点很多时 $V$ 占主导，稠密图里 $E$ 占主导，因此两项都要留着。

保留参数的写法也让结论对输入类别说得更清楚：若某个成本本身是 $T(V, E) = \Theta(V + E)$，那么在 $E = \Theta(V)$ 与 $E = \Theta(V^2)$ 两类输入上，它分别落在 $\Theta(V)$ 与 $\Theta(V^2)$，相差 $\Theta(V)$ 倍。前提必须是 $\Theta(V + E)$；只知道一个 $O(V + E)$ 的上界推不出这些量级。

## 情形不是界

最坏、平均、摊还规定怎样从逐次成本形成要研究的成本函数；$O$、$\Omega$、$\Theta$ 描述这个成本函数与另一个函数之间的渐进关系。两者是独立的坐标：最坏情形既可以用 $\Theta$ 陈述，也可以只用 $O$；平均情形必须先把输入分布写出来才有意义，见 <CrossRef id="algorithms.average-and-randomized" />；摊还则要声明操作序列与分摊对象，见 <CrossRef id="algorithms.amortized" />。把「平均情况是 $O(n)$」读成「最坏情况也是 $O(n)$」，是两处独立错误的叠加。

## 空间

空间成本也有增长率，并且要说清度量的是什么：算法自身占用的额外空间，还是包含输入在内的总空间。递归算法要把调用栈算进去：递归深度为 $n$ 的实现，即使每层只用常数空间，总空间也是 $\Theta(n)$。以空间换时间的做法在这里陈述两边：时间下降多少、空间上升多少，各自依赖哪个规模。

## 渐进优势与小区间

渐进结论只在足够大时成立，而足够大由常数因子决定。设两个实现的工作量分别是 $100n + 1000$ 与 $n^2 / 2$：前者是 $\Theta(n)$，后者是 $\Theta(n^2)$，但 $n \le 209$ 时后者更小；两式的交点约为 $n = 209.54$，对整数输入就是从 $n = 210$ 起前者更小。渐进上更优的实现，在小输入上可能更慢。

要在给定规模上判断谁快，需要计数或测量，见上一课的计数与计时分工；引用增长率回答不了这个问题。渐进结论的价值在于它不随规模变化：对这两个具体函数，从整数 $n = 210$ 起线性式一直更小。一般的渐进记号只保证足够大之后的关系，不保证只有一个交叉点，也不给出交叉位置。

## 小结

- $O$ 是上界、$\Omega$ 是下界、$\Theta$ 是紧确界，三者都是足够大之后的函数关系；$\Theta$ 允许相差常数因子，不是精确值。
- 常见增长族可以按最终增长速度比较，固定常数因子不会改变它们的 $\Theta$ 类。
- 和按 $f + g = \Theta(\max\{f, g\})$ 处理，只在 $f = O(g)$ 时才化简为 $\Theta(g)$；嵌套相乘；规模有多个参数时，界要对所有合法参数组合成立。
- 成本函数怎样形成（最坏、平均、摊还）与用哪种界描述它，是两个独立的坐标；空间成本同样需要模型、规模与量化方式。
- 渐进优势不保证小输入更快，交叉点由常数因子决定；渐进记号只描述足够大之后的关系。
