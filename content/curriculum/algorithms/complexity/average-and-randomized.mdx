在一张长度 $n$ 的表里顺序查找一个目标，成本是比较次数。给这个实现一条确定的输入，成本就是一个确定的值：目标在第 $k$ 个位置要比较 $k$ 次，目标不在表里要比较 $n$ 次。追问「它平均比较多少次」时，得先说明变化的究竟是什么——表的选取服从某个输入分布，或者算法在运行时自己掷硬币。两种来源都把成本变成随机变量，它们对「平均」的承诺形状却不同：一个对整族输入负责，一个对每一条固定输入负责。

## 两种随机性来源

**平均情形**先固定规模，再对输入分布取平均。规模为 $n$ 时用一族分布 $D_n$ 描述输入，平均成本是一个以规模为自变量的函数：

$$
C_{\text{avg}}(n) = E_{X \sim D_n}[C(X)] = \sum_{x : \lvert x \rvert = n} D_n(x) \cdot C(x)
$$

没有分布就没有结论；换掉分布后，原来的结论必须重新验证，结果可能改变。

**随机化算法**把随机性放进算法内部：输入固定，算法自己掷硬币。用 $R$ 表示算法这一次的随机选择，对固定输入 $x$ 有 $E_R[C(x, R)]$；量词位置不同——前者是「对这个分布平均」，后者是「对这个输入、对算法的随机选择平均」。

「随机化算法有对每个输入都成立的期望界」是一条要另行证明的论断。要证明的东西写成量词是这样的形状：

$$
\exists\, c > 0,\ n_0,\quad \forall x:\ \lvert x \rvert \ge n_0 \ \Rightarrow\ E_R[C(x, R)] \le c \cdot f(\lvert x \rvert)
$$

常数 $c$ 与规模门槛 $n_0$ 不许依赖 $x$，「统一」指的就是这一点。把每个 $x$ 各自的常数收进 $O$ 记号里，这条界就退化成逐点的记号，统一常数这一内容随之消失。

这一步成立依赖一条假设：随机位在对手选定输入之后才产生。确定性算法的对手能在运行之前挑出让最坏情形发生的输入；输入固定之后算法才掷硬币，对手就无从预知这次会走哪条路径。被挡住的是「在随机位之前固定输入」的对手；能在运行过程中观察并继续构造输入的适应性对手另当别论。

说「哈希表查找是 $O(1)$」时省略的是哈希函数把键分散开的假设，那是随机哈希下的期望（<CrossRef id="algorithms.hash-tables" />）；说「随机 pivot 快速排序是 $n \log n$」时省略的是随机基准点下、对每个输入成立的期望（<CrossRef id="algorithms.comparison-sorting" />）。

运行成本的期望只是随机算法契约的一栏：错误保证另有一栏，Las Vegas 与 Monte Carlo 的分类、单侧与双侧错误、概率放大在 <CrossRef id="algorithms.randomized-algorithms" /> 展开；本课只用「对固定输入、对随机位取期望」这一条量词规则。

## 随机变量与期望

一次运行的成本是随机变量 $T$，取值由随机性来源决定。取值有限时，期望是按概率的加权平均：$E[T] = \sum_t t \cdot P(T = t)$。

**指示器随机变量**把事件变成 0/1 计数。事件 $A$ 的指示器满足 $E[[A]] = P(A)$，于是一个总次数可以写成若干指示器之和，期望随之拆成若干概率之和：

$$
\begin{aligned}
\text{线性查找的比较次数} &= \sum_{i=0}^{n-1} [\text{第 } i \text{ 次比较发生}] \\
E[\text{比较次数}] &= \sum_{i=0}^{n-1} P(\text{第 } i \text{ 次比较发生})
\end{aligned}
$$

**期望的线性性**是这条拆分成立的依据：对本课讨论的、期望有限的随机变量，$E[X + Y] = E[X] + E[Y]$ 恒成立；更一般地，若 $T = T_1 + \cdots + T_k$，则 $E[T] = \sum_j E[T_j]$。各部分之间通常明显相关（第 $i + 1$ 次比较是否发生取决于第 $i$ 次的结果），线性性照样成立。独立性不是线性性的前提：只有当某一步明确依赖独立性——例如一般性地把联合概率分解为概率之积，或调用一个以独立性为前提的概率界——才需要证明独立性。若只是要让协方差项为零，零协方差本身已经足够，独立性只是更强的充分条件。

下面的例子故意取两个相关的指示器：第二个事件包含第一个事件，所以它们不独立。

```python run id="alg.avg.linearity"
size = 4
threshold = 2


def indicators(first, second):
    """Two dependent indicators, read off one draw of two values."""
    below_first = 1 if first < threshold else 0
    below_either = 1 if (first < threshold or second < threshold) else 0
    return below_first, below_either


outcomes = [indicators(a, b) for a in range(size) for b in range(size)]
weight = 1 / len(outcomes)

p = threshold / size
mean_first = sum(x for x, _ in outcomes) * weight
mean_either = sum(y for _, y in outcomes) * weight
mean_sum = sum(x + y for x, y in outcomes) * weight

print(f"E[X] exact={mean_first:.4f} closed form={p:.4f}")
print(f"E[Y] exact={mean_either:.4f} closed form={1 - (1 - p) ** 2:.4f}")
print(f"E[X + Y] exact={mean_sum:.4f} sum of closed forms={p + 1 - (1 - p) ** 2:.4f}")
print("joint outcomes:", sorted(set(outcomes)))
```

三行的精确值与闭式相符——恒等式本身来自期望的线性性，这一格只用来核对实现与模型。联合取值只有三种：$X = 1$ 时 $Y$ 必然是 1，所以 $P(Y = 0 \mid X = 1) = 0$，而 $P(Y = 0) > 0$——两者明显不独立。线性性不需要独立性，这正是它能作为主线工具的原因。

## 平均情形要先写分布

线性查找的成本取决于目标在序列中的位置。同一个实现，两种分布，两个结论。

```python run id="alg.avg.linear-search"
def search(items, target):
    """Return the number of comparisons the lookup costs."""
    for index, item in enumerate(items):
        if item == target:
            return index + 1
    return len(items)          # absent: the scan runs to the end


size = 100
items = list(range(size))
present = [items[0], items[24], items[74], items[99]]
absent = size + 1

for target in present:
    print(f"target at index {target:>3}: comparisons={search(items, target)}")
print(f"target absent          : comparisons={search(items, absent)}")

uniform_mean = sum(search(items, items[k]) for k in range(size)) / size
print(f"uniform over all positions: exact mean comparisons={uniform_mean}")
print(f"every target absent       : exact mean comparisons={size}")
print("closed form (n + 1) / 2 =", (size + 1) / 2)
```

两种分布给出不同的**精确**期望，渐进量级却都仍是 $\Theta(n)$。上面那几条输入已经把成本的结构摆出来：目标排在第 $k$ 个位置（从 1 数起）就要比较 $k$ 次，目标不存在要比较 $n$ 次。

要得到均匀分布下的 $(n + 1)/2$，只需要证明一件事：第 $i$ 次比较发生的概率。把第 $i$ 次比较写成指示器，等可能命中时它取 $1$ 当且仅当目标落在第 $i$ 个位置或更靠后——共 $n - i$ 个位置，于是概率是 $(n - i)/n$。对这些指示器取期望再求和，$\sum_{i=0}^{n-1}(n - i)/n$ 恰好化成 $(n + 1)/2$。这一步用到的假设只有期望的线性性，各指示器之间的相关性不进入计算。目标必然不存在时，每个位置的比较都发生，求和得 $n$。

**同一段代码，同一个规模，两个不同的结论**。换别的分布还可能改变量级——目标总在第一个位置是 $\Theta(1)$。这条 $(n + 1)/2$ 的推导采用的是「目标等可能地位于任意位置」的分布；只给出这个期望而不声明所采用的分布，论断是不完整的。

## 运行时间是随机变量

把一个随机化算法用在一个固定输入上，期望与单次运行的距离就现出来。目标固定在表尾、扫描方向固定从左到右时，每次运行的比较次数都是 $n$；改成先用一次确定性洗牌打乱扫描顺序，同一个输入上的比较次数就随种子变化：

```python run id="alg.avg.randomized-search"
import random


def scan(order, target):
    """Comparisons a scan of `order` spends before it reaches `target`."""
    for index, item in enumerate(order):
        if item == target:
            return index + 1
    return len(order)


size = 64
items = list(range(size))
target = size - 1          # fixed input: the target sits in the last slot

plain = scan(items, target)
generator = random.Random(20260604)
runs = []
for _ in range(6):
    order = items[:]
    generator.shuffle(order)
    runs.append(scan(order, target))

print(f"deterministic scan on this fixed input: {plain} comparisons")
print(f"randomized scan, six fixed-seed shuffles: {runs}")
print(f"sample mean of the six: {sum(runs) / len(runs):.2f}")
print(f"exact expectation on this input, (n + 1) / 2 = {(size + 1) / 2:.1f}")
```

确定性扫描在这个输入上每次都返回 $64$；换成随机化扫描后，六次运行分别返回 $7, 40, 40, 53, 43, 20$，取值随随机位变化。这个输入的精确期望是 $32.5$，六次运行只给出样本均值 $33.83$ 这样一个估计。期望界说的是 $E_R[C(x, R)] = 32.5$，它不阻止某一次运行跑到最坏情形的 $64$ 次比较。

期望界与高概率界是两条不同的保证。$E[T] = O(n \log n)$ 不排除某次运行成本更大，甚至达到算法的最坏情形；接口要求「每次运行都有硬上界」时用最坏情形分析，要求「超过某个阈值的概率很小」时还要另行证明尾概率界。只有期望值并不等价于高概率保证：对非负随机变量，期望经由 Markov 不等式只给出 $P[T \ge c\,E[T]] \le 1/c$ 这样的弱尾界。这与摊还界不等于硬延迟界是平行的两件事。

实验测出的样本均值只是对期望的估计，它用来核对实现是否符合模型；结论本身来自计数论证（见 <CrossRef id="algorithms.cost-model" />）。在独立同分布、单次成本方差为 $\sigma^2$ 时，$m$ 次运行的样本均值方差是 $\sigma^2 / m$，随 $1 / m$ 下降，但它始终是估计，不是期望本身。

期望与摊还是两个可以叠加、但必须分开陈述的维度：一个操作的期望成本与一串操作的摊还成本是两条独立论断（见 <CrossRef id="algorithms.amortized" />）。

实现边界：`random.Random(seed).shuffle` 产出的是伪随机置换，给定种子后完全可复现，序列本身由解释器的伪随机数生成器决定（CPython 的 [random 模块](https://docs.python.org/3/library/random.html)）；这是本页为了可复现而做的选择，不改变上面任何一条期望结论。
