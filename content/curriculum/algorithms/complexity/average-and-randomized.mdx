上一课用摊还分析处理了一串操作的总成本，其中不需要任何随机性假设。另一种「平均」把成本当成随机变量：随机性要么来自输入，要么来自算法内部。本课只建立这套分析语言。随机算法的契约、Las Vegas 与 Monte Carlo 的分类、单侧与双侧错误、概率放大属于 <CrossRef id="algorithms.randomized-algorithms" />；随机 pivot 快速排序的具体算法与期望成本在 <CrossRef id="algorithms.comparison-sorting" /> 处理；哈希表的概率模型在 <CrossRef id="algorithms.hash-tables" /> 处理。

## 两种随机性来源

**平均情形**先固定规模，再对输入分布取平均。规模为 $n$ 时用一族分布 $D_n$ 描述输入，平均成本是一个以规模为自变量的函数：

```text
C_avg(n) = E_{X ~ D_n}[C(X)] = Σ_{x: |x| = n} D_n(x) · C(x)
```

没有分布就没有结论；换掉分布后，原来的结论必须重新验证，结果可能改变。

**随机化算法**把随机性放进算法内部：输入固定，算法自己掷硬币。用 $R$ 表示算法这一次的随机选择，对固定输入 $x$ 有 $E_R[C(x, R)]$；量词位置不同——前者是「对这个分布平均」，后者是「对这个输入、对算法的随机选择平均」。

「随机化算法有对每个输入都成立的期望界」是一条需要另行证明的论断；写成量词就是存在常数 $c > 0$ 与规模门槛 $n_0$，使每个满足 $\lvert x \rvert \ge n_0$ 的输入都满足 $E_R[C(x, R)] \le c \cdot f(\lvert x \rvert)$——隐藏常数不许依赖 $x$，「统一」就是指这一点。它不是「算法自己掷硬币」这个事实的直接后果。确定性算法的对手可以在运行之前构造出让最坏情形发生的输入；随机位在输入之后才产生时，对手无法预知这一次会走哪条路径。这个保证也有条件：被挡住的是「在随机位之前固定输入」的对手，能在运行过程中观察并继续构造输入的适应性对手另当别论。

说「哈希表查找是 $O(1)$」或「快速排序是 $n \log n$」时省略的正是这两句假设：前者是哈希假设下的期望，后者是随机基准点下、对每个输入成立的期望。

## 随机变量与期望

一次运行的成本是随机变量 $T$，取值由随机性来源决定。取值有限时，期望是按概率的加权平均：$E[T] = \sum_t t \cdot P(T = t)$。

**指示器随机变量**把事件变成 0/1 计数。事件 $A$ 的指示器满足 $E[[A]] = P(A)$，于是一个总次数可以写成若干指示器之和，期望随之拆成若干概率之和：

```text
线性查找的比较次数 = Σ_{i=0}^{n-1} [第 i 次比较发生]
E[比较次数] = Σ_{i=0}^{n-1} P(第 i 次比较发生)
```

**期望的线性性**是这条拆分成立的依据：对本课讨论的、期望有限的随机变量，$E[X + Y] = E[X] + E[Y]$ 恒成立；更一般地，若 $T = T_1 + \cdots + T_k$，则 $E[T] = \sum_j E[T_j]$。各部分之间通常明显相关（第 $i + 1$ 次比较是否发生取决于第 $i$ 次的结果），线性性照样成立。独立性不是线性性的前提：只有当某一步明确依赖独立性——例如一般性地把联合概率分解为概率之积，或调用一个以独立性为前提的概率界——才需要证明独立性。若只是要让协方差项为零，零协方差本身已经足够，独立性只是更强的充分条件。

下面的例子故意取两个相关的指示器：第二个事件包含第一个事件，所以它们不独立。

```python run id="alg.avg.linearity"
import random

size = 100
threshold = 40
trials = 20000
generator = random.Random(4)


def draw():
    """Return two dependent indicators from one draw of two values."""
    first = generator.randrange(size)
    second = generator.randrange(size)
    below_first = 1 if first < threshold else 0
    below_either = 1 if (first < threshold or second < threshold) else 0
    return below_first, below_either


pairs = [draw() for _ in range(trials)]
mean_first = sum(x for x, _ in pairs) / trials
mean_either = sum(y for _, y in pairs) / trials
mean_sum = sum(x + y for x, y in pairs) / trials

p = threshold / size
print(f"E[X] estimate={mean_first:.4f} closed form={p:.4f}")
print(f"E[Y] estimate={mean_either:.4f} closed form={1 - (1 - p) ** 2:.4f}")
print(f"E[X + Y] estimate={mean_sum:.4f} sum of closed forms={p + 1 - (1 - p) ** 2:.4f}")
print("joint outcomes observed:", sorted({(x, y) for x, y in pairs}))
```

三行的样本均值都与闭式相符——恒等式本身来自期望的线性性，实验只用于核对实现与模型。而联合取值只有三种：$X = 1$ 时 $Y$ 必然是 1，所以 $P(Y = 0 \mid X = 1) = 0$，而 $P(Y = 0) > 0$——两者明显不独立。线性性不需要独立性，这正是它能作为主线工具的原因。估计与闭式之间的差距来自样本量，不是模型误差。

## 平均情形要先写分布

线性查找的成本取决于目标在序列中的位置。同一个实现，两种分布，两个结论。

```python run id="alg.avg.linear-search"
import random


def search(items, target):
    """Return the number of comparisons the lookup costs."""
    for index, item in enumerate(items):
        if item == target:
            return index + 1
    return len(items)          # absent: the scan runs to the end


size = 100
items = list(range(size))
generator = random.Random(0)

uniform_positions = [generator.randrange(size) for _ in range(2000)]
absent_keys = [size + offset for offset in range(2000)]

uniform_cost = [search(items, items[position]) for position in uniform_positions]
absent_cost = [search(items, key) for key in absent_keys]

print(f"uniform positions: mean comparisons={sum(uniform_cost) / len(uniform_cost):.1f} worst={max(uniform_cost)}")
print(f"keys that are absent: mean comparisons={sum(absent_cost) / len(absent_cost):.1f} worst={max(absent_cost)}")
print("closed forms: (n + 1) / 2 =", (size + 1) / 2, "| n =", size)
```

这两种分布给出不同的**精确**期望，渐进量级却都仍是 $\Theta(n)$：目标位置均匀时期望恰为 $(n + 1)/2$（这是精确值，实验均值只是它在有限样本上的估计），目标必然不存在时恰为 $n$。**同一段代码，同一个规模，两个不同的结论**。用指示器写出来就是：等可能命中时第 $i$ 次比较发生的概率是 $(n - i)/n$，求和得 $(n + 1)/2$；目标不存在时每个位置都发生，求和得 $n$。换别的分布还可能改变量级——目标总在第一个位置是 $\Theta(1)$，目标总不存在是 $\Theta(n)$。常见的 $(n + 1)/2$ 推导采用「目标等可能地位于任意位置」的分布；只给出这个期望而不声明所采用的分布，论断是不完整的。

## 运行时间是随机变量

期望界不提供确定性的单次运行保证：$E[T] = O(n \log n)$ 并不排除某次运行成本更大，甚至达到算法的最坏情形。接口要求「每次运行都有硬上界」时用最坏情形分析；要求「超过某个阈值的概率很小」时，还要另行证明尾概率界——只有期望值并不等价于高概率保证（对非负随机变量，期望经由 Markov 不等式给出的尾界通常很弱）。这与摊还界不等于硬延迟界是平行的两件事。

实验测出的样本均值只是对期望的估计，它用来核对实现是否符合模型；结论本身来自计数论证（见 <CrossRef id="algorithms.cost-model" />）。在独立同分布、单次成本方差为 $\sigma^2$ 时，$m$ 次运行的样本均值方差是 $\sigma^2 / m$，随 $1 / m$ 下降，但它始终是估计，不是期望本身。

期望与摊还是两个可以叠加、但必须分开陈述的维度：一个操作的期望成本与一串操作的摊还成本是两条独立论断（见 <CrossRef id="algorithms.amortized" />）。

## 小结

- 随机性来源决定成本是哪个随机变量：平均情形先固定规模、再对输入分布族 $D_n$ 取期望，随机化算法对固定输入取算法随机位 $R$ 上的期望。
- 平均情形必须先写分布；换掉分布后，原来的结论必须重新验证，结果可能改变。
- 指示器随机变量把总次数拆成 0/1 之和；期望的线性性对期望有限的随机变量恒成立，独立性不是它的前提。
- 期望界不提供确定性的单次运行保证；高概率保证是另一回事，需要另行证明尾概率界。
- 样本均值只是对期望的估计，复杂度结论来自计数论证。
- 期望与摊还是两个独立维度，可以叠加但要分开陈述。
- 本课留下的四个接口：$D_n$ 上的平均情形、固定输入上对随机位取期望、期望的线性性、高概率保证不同于期望保证。具体随机算法的契约与设计属于 <CrossRef id="algorithms.randomized-algorithms" />，随机 pivot 快速排序与哈希概率模型分别归属 <CrossRef id="algorithms.comparison-sorting" /> 与 <CrossRef id="algorithms.hash-tables" />。
