<CrossRef id="algorithms.heaps" /> 建立了两条不变量——完全二叉树的形状，以及父子之间的顺序——并给出了按「还能下降多少层」计数、总和收敛到 $\Theta(n)$ 的线性建堆论证。形状不变量固定，可以取反的只是父子顺序的方向：默认的小顶堆保证父不大于子、堆顶是当前最小值，取反得到最大堆、堆顶就是当前最大值，形状不变量与线性建堆的论证都不变。

## 复用两条不变量

堆排序复用这两条结论。它把数组看成最大堆的**前缀**加一段已经排好的**后缀**：初始时后缀为空，先就地建堆，代价 $\Theta(n)$；之后反复交换堆顶与紧挨前缀的那个元素，再对缩短一号的前缀做一次下沉恢复。每个元素一旦进入后缀就不再移动，后缀因此保持非降序，且其中任何元素都不小于前缀里的元素。

$n-1$ 次取出各付 $O(\log n)$，合起来是 $\Theta(n \log n)$；这个界对任何输入都成立，没有「平均」这一层。辅助空间是 $O(1)$：交换与下沉都发生在原数组内，只用常数个下标变量。

```python run id="alg.heapsort.drain"
import heapq


def drain(items):
    """Postcondition: repeatedly removes the heap top, yielding non-decreasing order."""
    heap = list(items)
    heapq.heapify(heap)
    out = []
    while heap:
        out.append(heapq.heappop(heap))
    return out


sample = [7, 3, 9, 1, 5, 3, 8]
print("input  :", sample, "| drained:", drain(sample))
```

标准库的 heapq 维护的就是小顶堆，反复取出堆顶因此得到非降序的 `[1, 3, 3, 5, 7, 8, 9]`，重复键 3 也照常各归一位。堆排序把方向取反成最大堆、以原地交换实现同一件事，辅助空间因此降到 $O(1)$；堆顶交换会越过等键记录，它和分区实现的快速排序一样不保证等键记录的相对次序（<CrossRef id="algorithms.sorting" /> 把稳定性作为输出的后置条件之一）。
