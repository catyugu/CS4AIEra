一份报表既可以从网页生成，也可以在命令行导出。把计数规则单独放在报表模块中，两处入口就能对同一批记录给出相同结果。例如，统计不同的记录编号时，报表模块可以使用一个专门管理编号的组件。

## 模块接口与信息隐藏

模块将相关定义与状态放在一起。报表模块用编号组件公开的操作加入编号和读取结果，编号组件自行选择用列表还是集合存放数据。导入与访问模块名字的方式见 <CrossRef id="program-logic-and-state.modules-and-imports" />。

<Term id="information-hiding">信息隐藏（information hiding）</Term>把内部表示、算法和资源管理等决定留在模块内部，只通过约定的操作使用它们。Python 中的前导下划线标明供内部使用的名字，见 [Python 教程中的约定](https://docs.python.org/3/tutorial/classes.html#private-variables)。调用方通过公开操作读写数据，内部结构的调整就可以限制在组件内部。

下面用一个类演示这个组件，公开操作包括 `add`、`contains` 和 `snapshot`。`snapshot` 返回按添加顺序排列的编号副本。`list(...)` 创建外层副本，复制规则见 <CrossRef id="program-logic-and-state.names-objects-and-state" />。

```python run id="program-composition.modules-and-boundaries.snapshot"
class IntegerSet:
    def __init__(self):
        self._values = []

    def add(self, value):
        if value not in self._values:
            self._values.append(value)

    def contains(self, value):
        return value in self._values

    def snapshot(self):
        return list(self._values)


values = IntegerSet()
values.add(3)
values.add(1)
values.add(3)
result = values.snapshot()
result.append(8)
print("caller:", result)
print("module:", values.snapshot())
```

先加入 3、1，再加入一个 3，组件仍按添加顺序保存 `[3, 1]`。调用方对副本追加 8 后，组件内部还是 `[3, 1]`。如果直接返回内部列表，追加也会写进组件，调用方就可以绕过 `add` 的去重规则。若后来用集合提高成员查找效率，还要另存添加顺序，才能让 `snapshot` 继续返回按约定排列的副本。

## 网页和命令行共用计算

网页入口从请求取得参数，命令行入口从参数或文件取得数据。两者把普通记录交给报表模块，拿到统计结果后分别生成网页或文件。

| 使用者 | 依赖的公开操作 |
| --- | --- |
| 网页入口 | 请求报表模块计算结果 |
| 命令行入口 | 请求同一个报表模块计算结果 |
| 报表模块 | 通过编号组件处理重复编号 |

依赖方向是使用者指向被调用的模块。这样安排后，改页面按钮和增加导出格式都可以从调用入口着手，统计规则在一处维护。如果报表模块反过来导入界面模块，命令行调用也可能需要加载界面相关代码。

## 模块、库与包

库是一组供其他程序使用的功能。包可以组织多个模块，也可以指可安装的发布单位；两种用法要根据上下文区分。在 Python 中，导入包用点分名称组织模块，安装的发行包则可能提供一个或多个导入包，名称也未必相同，见 [Python Packaging：发行包与导入包](https://packaging.python.org/en/latest/discussions/distribution-package-vs-import-package/)。

模块决定代码怎样组织，发布版本标识交给使用者的一份具体内容。包的安装和升级见 <CrossRef id="change-and-review.dependencies-and-reproducible-builds" />。

## 练习

缓存提供 `put` 和 `all_values`。需求是“调用方可以修改查询结果，但缓存中的记录只能通过 `put` 修改”。下面的实现满足这个要求吗？先比较修改列表长度与修改一条记录，再运行核对。如果调用方还保有交给 `put` 的原字典，应在哪些读写位置复制数据，才能兑现这项约定？

```python run id="program-composition.modules-and-boundaries.exercise-copy"
class Cache:
    def __init__(self):
        self._values = []

    def put(self, value):
        self._values.append(value)

    def all_values(self):
        return list(self._values)


cache = Cache()
cache.put({"count": 1})
result = cache.all_values()
result.append({"count": 2})
result[0]["count"] = 9
print("caller:", result)
print("cache:", cache.all_values())
```
