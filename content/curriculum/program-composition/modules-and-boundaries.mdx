一个组件需要保存一组不重复的整数，并提供“加入元素”和“判断成员”的操作。内部可以用列表，也可以用集合。调用方如果依赖内部列表的下标和遍历方式，改用集合就会影响它们；若调用方只依赖公开操作，就有机会在保持行为一致的前提下替换表示。

## 模块接口与信息隐藏

模块是组织相关定义与状态的单位。划分模块时，需要确定哪些实现决定可以在内部调整，哪些行为要继续向外保证。导入与访问模块名字的方式见 <CrossRef id="program-logic-and-state.modules-and-imports" />。

<Term id="information-hiding">信息隐藏（information hiding）</Term>把内部表示、算法和资源管理等决定留在模块内部，只通过约定的操作使用它们。一个前导下划线可以提示某个名字供内部使用，但 Python 不把这种约定变成访问权限，见 [Python 教程：私有变量](https://docs.python.org/3/tutorial/classes.html#private-variables)。如果调用方仍直接读取内部列表，把列表换成集合时，它们仍可能需要修改。

下面用一个类表示保存状态的组件，公开操作是 `add`、`contains` 与 `snapshot`。调用方按约定向它加入整数；`snapshot` 返回一份可以独立增删元素的列表。`list(...)` 创建外层副本，复制规则见 <CrossRef id="program-logic-and-state.names-objects-and-state" />。

```python run id="program-composition.modules-and-boundaries.snapshot"
class IntegerSet:
    def __init__(self):
        self._values = []

    def add(self, value):
        if value not in self._values:
            self._values.append(value)

    def contains(self, value):
        return value in self._values

    def snapshot(self):
        return list(self._values)


values = IntegerSet()
values.add(3)
result = values.snapshot()
result.append(8)
print("caller:", result)
print("module:", values.snapshot())
```

调用方对快照追加 8，组件内部仍只保存 3。若 `snapshot` 直接返回 `self._values`，调用方就能绕过 `add` 的去重规则，修改组件内部状态。这里通过类的方法演示组件接口；在独立模块中，也可以用函数和模块内部状态建立同样的边界。

这里的元素是整数，创建外层列表已经足以隔离增删。如果元素换成字典，复制外层列表仍会共享字典对象。还有一项接口约定需要说清：`snapshot` 是否保证元素顺序？当前列表会保留添加顺序，若换成集合，这项行为就需要重新决定。

## 依赖方向与模块耦合

报表要统计不同的记录编号，使用整数集合的“加入、判断成员、取出快照”这些行为。不论编号来自界面还是文件，这些计算规则相同。让报表模块导入界面模块，会让计算依赖按钮与显示组件；换一个调用入口也必须带上界面。

依赖方向可以直接画成“使用者指向所使用的定义”：

```text
command-line ──> report ──> integer-set
window-ui ─────> report
```

`report` 接收普通数据并返回结果，两种入口各自负责读取输入与展示输出。这样变更界面不会要求报表计算理解界面状态。若计算需要读取数据，可以把“读取函数”作为参数传入；依赖的是这个函数的输入输出约定。

依赖图里有环意味着多个模块互相需要，独立加载、替换与理解都更困难；图中环的含义见 <CrossRef id="data-algorithms-and-scale.trees-graphs-and-dependencies" />。检查依赖时也要追踪共享状态：两个模块即使没有互相导入，仍可能通过同一个全局对象影响彼此。

## 模块、库与包

库是一组供其他程序使用的功能。包可以组织多个模块，也可以指可安装的发布单位；两种用法要根据上下文区分。在 Python 中，导入包用点分名称组织模块，安装的发行包则可能提供一个或多个导入包，名称也未必相同，见 [Python Packaging：发行包与导入包](https://packaging.python.org/en/latest/discussions/distribution-package-vs-import-package/)。

模块决定代码怎样组织，发布版本标识交给使用者的一份具体内容。包的安装和升级见 <CrossRef id="change-and-review.dependencies-and-reproducible-builds" />。

## 练习

缓存提供 `put` 和 `all_values`。需求是“调用方可以修改查询结果，但缓存中的记录只能通过 `put` 修改”。下面的实现满足这个要求吗？先比较修改列表长度与修改一条记录，再运行核对。若缓存允许保存任意可变对象，独立结果应当怎样约定？

```python run id="program-composition.modules-and-boundaries.exercise-copy"
class Cache:
    def __init__(self):
        self._values = []

    def put(self, value):
        self._values.append(value)

    def all_values(self):
        return list(self._values)


cache = Cache()
cache.put({"count": 1})
result = cache.all_values()
result.append({"count": 2})
result[0]["count"] = 9
print("caller:", result)
print("cache:", cache.all_values())
```
