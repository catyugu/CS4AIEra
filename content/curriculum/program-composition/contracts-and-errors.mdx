报表应用允许保存一份空草稿。打开空草稿时，界面要显示空编辑区。编号从未分配时，界面应提示记录不存在。两种情况都返回 `{}`，界面就没有依据作出这项选择。读取接口需要约定怎样区分它们。

## 接口约定与前后置条件

应用程序接口（<Term id="api">API，Application Programming Interface</Term>）是组件向使用者提供的操作及其约定。接口约定写清调用要求、成功结果、状态变化和失败行为。

例如 `get_record(key)` 可以约定：

| 条件 | 结果与状态 |
| --- | --- |
| `key` 是非空字符串，记录存在 | 返回记录字典的外层副本，保留已有记录 |
| `key` 是非空字符串，记录不存在 | 抛出 `KeyError` |
| `key` 的类型或内容无效 | 查询前抛出 `ValueError` |
| 存储组件无法完成读取 | 向上报告读取故障，由调用方提示暂时无法打开 |

<Term id="precondition">前置条件</Term>规定调用开始时必须成立的要求，后置条件规定调用结束后的结果与状态。表中还规定了输入校验失败时应给出哪种异常。本例的记录字段值都是不可变值，因此外层副本可独立修改。调用方根据这些规则区分正常结果、找不到记录和输入错误。

在这些条件保持不变时，组件可以把内部存储从字典换成列表或文件，调用方无需改变处理空记录、缺失记录和输入错误的逻辑。

## 正常结果与错误的区分

下面的查找允许合法记录内容恰好是空字典。字典的 `copy()` 创建一份外层副本。

```python run id="program-composition.contracts-and-errors.missing-record"
records = {"a": {}, "b": {"count": 2}}


def get_record(key):
    if not isinstance(key, str) or key == "":
        raise ValueError("key must be a nonempty string")
    return records[key].copy()


for key in ["a", "missing", ""]:
    try:
        print(key, get_record(key))
    except KeyError:
        print(key, "not found")
    except ValueError as failure:
        print(key, "invalid:", failure)
```

`isinstance(key, str)` 检查值是不是字符串；`or` 在左边已经为真时跳过右边。正常数据、目标不存在、输入无效，在这里经过不同路径。调用方可以据此展示空内容、提示换一个键，或要求改正输入。

异常如何沿调用关系传播，见 <CrossRef id="program-logic-and-state.exceptions-and-cleanup" />。

## 在哪一层处理失败

如果草稿改为从文件加载，可以让存储模块把底层读取异常转换成一种稳定的应用错误。例如，索引文件意外丢失时，读草稿的请求应报告暂时无法读取。已经查过索引并确定编号未分配时，才报告草稿不存在。两种信息在存储模块里有明确含义，界面只需按接口约定选择提示。

Python 可以用 `raise NewError(...) from failure` 将应用错误与底层异常关联，便于维护者继续诊断，见 [Python 的 raise 语句](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)。

接口替换时还要照顾已有调用。旧接口接受任意非空字符串，改成至少三个字符会拒绝原本合法的编号。旧接口返回字典副本，直接交出内部字典会让调用方的修改影响存储。即使函数名与参数列表相同，这两个改动也改变了接口约定。

## 练习

库存接口接受正整数数量。请求无效或库存不足时应报错，并保留库存。分别把 `quantity` 设为 `2`、`5`、`0` 与 `-1`，对照输出判断哪两项检查必须放在扣减之前。`global stock` 使函数中的赋值更新外部的库存变量。

```python run id="program-composition.contracts-and-errors.exercise-reserve"
stock = 3


def reserve(quantity):
    global stock
    stock -= quantity
    if stock < 0:
        raise ValueError("insufficient stock")
    return stock


quantity = 5
try:
    print("remaining:", reserve(quantity))
except ValueError as failure:
    print("failed:", failure)
print("stock:", stock)
```
