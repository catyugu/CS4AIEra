程序可以替我们计算三个数的平均值：

```python run id="program-semantics.programs-and-execution.order"
a = 12.5
b = 11.5
c = 12.0
mean = (a + b + c) / 3
print(mean)
```

程序从第一行开始执行。前三行给数值取名，第四行计算平均值，最后一行把结果写到输出里。

## 表达式与赋值

`12.5`、`a`、`a + b + c` 都是表达式（expression）。执行一个表达式，得到它的值，这叫求值。读取名字 `a` 时，得到的是它当前关联的值。

赋值语句 `a = 12.5` 先求值等号右边，再把左边的名字关联到结果。这种关联叫绑定（binding）。`=` 在这里表示赋值；判断两个值是否相等，要用 `==`。

执行 `mean = (a + b + c) / 3` 时，先读取三个名字的值，相加得到 `36.0`，再除以 `3`。括号要求先计算加法。最后，名字 `mean` 绑定到结果 `12.0`。这一行不会改变 `a`、`b`、`c` 的绑定。

赋值也可以改变已有名字的绑定。`a = a + 1` 先用旧的 `a` 计算，再让 `a` 指向结果。它不会回头重新计算已经赋给 `mean` 的值。

## 调用函数

`print(mean)` 是一次函数调用（call）。`print` 是 Python 已经提供的函数，括号里的值是交给它的参数。它把参数写到输出中。`print(a, b)` 可以一次打印两个值。

有些函数用于计算并返回一个结果，例如 `round` 把这里的浮点数取整：

```python run id="program-semantics.programs-and-execution.calls"
value = 11.87
rounded = round(value)
shown = print(value)
print("rounded:", rounded)
print("shown:", shown)
```

`round(value)` 返回 `12`，可以把它保存到 `rounded`，继续参与运算。`print(value)` 先输出 `11.87`，它的返回值是 `None`，所以 `shown` 为 `None`。`None` 是一个表示没有结果或缺失的特殊值。

**返回值与输出是两件事。** `rounded = round(value)` 保存了计算结果，却没有打印它；`print(value)` 写出了文字，却没有返回那个数。

## 值有类型

`12` 是整数，类型名是 `int`；`12.5` 是浮点数，类型名是 `float`；带引号的 `"12"` 是字符串，类型名是 `str`。字符串可以表示文本，也可以包含看起来像数字的字符。函数 `type` 返回一个值的类型。

类型决定哪些运算有意义。同一个 `+`，对数值做加法，对字符串做拼接：

```python run id="program-semantics.programs-and-execution.types"
print(type(12), type(12.5), type("12"))
print(2 + 3)
print(2 + 3.0)
print("2" + "3")
print(1 + "2")
```

整数与浮点数相加，结果是浮点数。两个字符串相加得到 `"23"`。最后一行要求整数与字符串相加，Python 没有为这两个类型定义这种操作，于是抛出 `TypeError`，也就是类型错误。

## 出错后，哪些语句已经执行

赋值 `b = "11.5"` 本身合法，它只是把名字绑定到一个字符串。若把开头程序的第二行改成这样，错误会出现在计算平均值时：`a + b` 要求把浮点数与字符串相加。

没有捕获的异常会结束这次执行，失败语句之后的代码不再运行。已经输出的文字不会被撤回。上面的类型示例先打印了类型和三种加法结果，最后才出错；开头的平均值程序则会在到达 `print(mean)` 之前出错。

## 练习

运行前，先写出两行输出。然后分别做以下修改，预测结果，再运行验证：

1. 把 `b` 的初始值改成 `14.5`。
2. 把 `b` 的初始值改成字符串 `"11.5"`：哪一行首先失败，失败前有没有输出？

```python run id="program-semantics.programs-and-execution.exercise"
a = 12.5
b = 11.5
c = 12.0
mean = (a + b + c) / 3
a = a + 1

```
