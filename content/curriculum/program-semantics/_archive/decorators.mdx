已经有一个能工作的函数，现在想让每次调用前后各打印一行日志，又不改动它的函数体：它可能已经被别的模块引用，也不想为了加日志往测试过的代码里插入 `print`。

一个办法是不碰原函数，写一个新函数接收它，返回一个在调用前后插了日志的替代品：

```python run id="py.dec.manual"
def traced(function):
    def wrapper(*args, **kwargs):
        print(f"before {function.__name__}")
        result = function(*args, **kwargs)
        print(f"after {function.__name__} -> {result!r}")
        return result

    return wrapper


def area(width, height):
    return width * height


area = traced(area)
print(area(4, 5))
```

`traced` 接收一个函数、返回一个替代它的新函数——函数在这里是普通的值，可以作实参，也可以作返回值。替代品在调用原函数前后各打印一行。接收一个函数、返回替代品的函数叫装饰器（decorator），内层返回的 `wrapper` 是包装函数。`area = traced(area)` 之后，名字 `area` 指向替代品。

为每个函数手写这个重新绑定既重复又容易漏，Python 给了它语法：

```python
@traced
def area(width, height):
    return width * height
```

`@traced` 写在 `def` 上方，与 `area = traced(area)` 是同一件事。

## 装饰就是重新赋值

```python run id="py.dec.shorthand"
events = []


def traced(function):
    events.append(f"decorating {function.__name__}")

    def wrapper(*args, **kwargs):
        events.append(f"calling {function.__name__}")
        return function(*args, **kwargs)

    return wrapper


@traced
def area(width, height):
    return width * height


print("events before any call:", events)
print("area(4, 5):", area(4, 5))
print("events after one call:", events)
print("name is bound to the wrapper:", area.__name__)
```

`decorating area` 在任何调用之前就出现在 `events` 里：`@traced` 在 `def` 语句执行时完成，也就是模块被导入、或函数体执行到这一行的时候。此后调用 `area()` 只是调用替代品，不会重新装饰；装饰器本体里做的事——读文件、建连接、发请求——因此发生在定义那一刻，成本在定义时付出，失败也在定义时暴露。赋值之后 `area` 指向 `wrapper`，`area.__name__` 因此是 `wrapper`；原函数仍被 `wrapper` 的闭包引用。需要保留原函数的 `__name__`、`__doc__` 时，用 `functools.wraps` 在包装函数上复制它们。

## 转交实参

```python run id="py.dec.forwarding"
def traced(function):
    def wrapper(*args, **kwargs):
        print(f"before {function.__name__}({args}, {kwargs})")
        result = function(*args, **kwargs)
        print(f"after {function.__name__} -> {result!r}")
        return result

    return wrapper


@traced
def area(width, height, unit="px"):
    return f"{width * height} {unit}"


print(area(2, 3))
print(area(2, height=3, unit="cm"))
```

包装函数用 `*args, **kwargs` 原样转交，被装饰函数的签名仍然可用。漏掉转交时，包装函数会吞掉实参或抛绑定错误：

```python run id="py.dec.without-forwarding"
def traced(function):
    def wrapper():
        return function()

    return wrapper


@traced
def area(width, height):
    return width * height


try:
    area(2, 3)
except TypeError as exc:
    print("wrapper swallowed the arguments:", type(exc).__name__, "-", exc)
```

## 深入：带参装饰器与层叠顺序

装饰器本身也可以带参数。`@repeated(times=3)` 先调用 `repeated(times=3)` 得到装饰器 `decorate`，再对函数应用它，所以要多一层函数：

```python run id="py.dec.factory"
def repeated(times=2):
    def decorate(function):
        def wrapper(*args, **kwargs):
            results = [function(*args, **kwargs) for _ in range(times)]
            return results

        return wrapper

    return decorate


@repeated(times=3)
def roll():
    return "attempt"


print(roll())
```

`times` 在装饰时固定，存在闭包里，调用期不可更改。多个装饰器叠加时，靠近 `def` 的那个先应用，执行时从外到内进入、从内到外返回：

```python run id="py.dec.stacking"
def first(function):
    def wrapper(*args, **kwargs):
        print("first: before")
        result = function(*args, **kwargs)
        print("first: after")
        return result

    return wrapper


def second(function):
    def wrapper(*args, **kwargs):
        print("second: before")
        result = function(*args, **kwargs)
        print("second: after")
        return result

    return wrapper


@first
@second
def action():
    print("action body")


action()
```

自上而下读代码会把应用顺序读反。
