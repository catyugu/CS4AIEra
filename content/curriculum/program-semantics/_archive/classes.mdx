要同时维护三条各自独立的计数，用变量就得写三份重复的自增代码。类把一份状态的形状和作用于它的操作绑在一起：每条计数是一个实例，各自保存自己的值，共用同一套操作。

## 定义一个类并创建实例

```python run id="py.classes.instances"
class Counter:
    def __init__(self, start=0):
        self.value = start

    def increment(self):
        self.value += 1


first = Counter()
second = Counter(10)

print(type(first).__name__, first is second)
first.increment()
first.increment()
print(first.value, second.value)
print(Counter)
```

`first` 与 `second` 是两份独立实例，各自持有自己的 `value`，因此 `first` 自增两次之后 `second` 的值不受影响。`increment` 定义在类体里，每次调用改的是接收它的那个实例的状态。

`instance.value` 是属性访问，`instance.value = 3` 是属性赋值，赋值在实例上创建或覆盖属性。

`Counter` 本身也是一个对象：`class Counter:` 执行时创建一个类对象并把名字 `Counter` 绑定到它，调用这个类对象创建**实例**，返回值是实例。

## 实例属性与类属性

一份状态该放在实例上还是类上，在定义处语法相同，行为差别决定程序是否正确。下面这个类的 `members` 写在类体里：

```python run id="py.classes.mutable-class-attribute"
class Team:
    members = []

    def add(self, name):
        self.members.append(name)


a = Team()
b = Team()
a.add("Ada")

print(a.members, b.members)
print(a.members is b.members, Team.members is a.members)
```

`members = []` 属于类对象，是所有实例共享的一个对象；实例属性属于单个实例。对这里这种没有描述符的普通属性，读取时先看实例自己的属性，再看类，两层都没有则抛 `AttributeError`（描述符会改变这个顺序，见 <CrossRef id="python.attributes-and-descriptors" />）。

`a` 与 `b` 都没有自己的 `members`，读取时沿层次找到类上的那一个，`append` 修改的是同一个列表：两个实例的输出相同，且 `a.members is b.members` 为真。这是<Term id="class-attribute">类属性</Term>最常见的失效模式，执行过程中没有任何错误，只是两个实例的状态合流了。把可变状态放进 `__init__`，属性就属于实例：

```python run id="py.classes.instance-attribute-fix"
class Team:
    def __init__(self):
        self.members = []

    def add(self, name):
        self.members.append(name)


a = Team()
b = Team()
a.add("Ada")

print(a.members, b.members)
```

两个实例各有自己的列表，不再互为<Term id="alias">别名</Term>。同样的共享也出现在默认参数上，见 <CrossRef id="python.mutability-and-copy" />。

## self 是普通形参

定义在类体里的函数属于类对象，所有实例共用同一份。`instance.increment()` 把 `instance` 作为第一个位置实参传给这个函数，方法里的第一个形参（约定名为 `self`）接住它；`self` 只是形参名，换成别的标识符，实例仍按位置传进来。

```python run id="py.classes.missing-self"
class Greeter:
    def greet():
        return "hello"


greeter = Greeter()
print(greeter.greet())
```

方法定义里漏掉 `self` 时，调用把实例当成多出来的实参：`TypeError` 的消息指出 `Greeter.greet()` 接收 0 个位置参数，却收到了 1 个。
