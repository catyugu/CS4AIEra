用字符串 `"finished"` 表示任务已完成，`"failed"` 表示任务失败。三个任务的状态依次是 `finished`、`failed`、`finished`。程序需要数出成功和失败的任务各有多少个。它不能对每项都执行同一个加法：看到不同状态时，要执行不同的语句。

## 条件选择要执行的语句

`==` 比较两个值是否相等，结果是 `True` 或 `False`。执行 `if` 时，程序先求值条件；条件为真，执行下面缩进的语句，否则执行 `else` 下的语句。

```python run id="program-semantics.choosing-the-next-step.condition"
status = "failed"
if status == "finished":
    print("finished")
else:
    print("needs attention")
print("checked")
```

输出先是 `needs attention`，然后是 `checked`。最后一行没有缩进，属于分支之后的程序，两种状态都会执行它。把 `status` 改为 `"finished"`，第一行输出随之改变。

多于两种情况时，可以在 `if` 与 `else` 之间写 `elif`。条件按顺序判断，第一个为真的分支执行，其后的分支不再判断。

## for 逐项处理一个列表

`for status in statuses:` 每轮取列表的下一个元素，绑定到名字 `status`，再执行缩进的循环体；元素取完，循环结束。

```python run id="program-semantics.choosing-the-next-step.trace"
statuses = ["finished", "failed", "finished"]
finished = 0
failed = 0
for status in statuses:
    if status == "finished":
        finished += 1
    else:
        failed += 1
    print(status, finished, failed)
print("totals:", finished, failed)
```

这段计数程序假定状态只有 `"finished"` 和 `"failed"` 两种；若还允许 `"pending"`，就需要另写分支，不能把所有未完成项都记为失败。

`finished += 1` 在这里相当于 `finished = finished + 1`。每轮只增加一个计数，最后得到成功 2 个、失败 1 个。循环体里的 `print` 执行三次，循环后的 `print` 执行一次。把列表改成 `[]`，循环体一次也不执行，两个计数仍为 0。

## while 在条件成立时重复

还有两项工作待处理，但这次最多处理三项。`while` 在每轮开始之前检查条件：为真就执行循环体，然后重新检查；为假就继续执行循环之后的语句。

```python run id="program-semantics.choosing-the-next-step.pending"
pending = 2
processed = 0
limit = 3
while pending > 0 and processed < limit:
    pending -= 1
    processed += 1
    print("pending:", pending)
print("processed:", processed, "remaining:", pending)
```

`>` 与 `<` 分别比较是否大于、是否小于；`and` 要求两边条件都成立，`or` 要求至少一边成立，`not` 将真假反转。`!=` 表示不相等。两轮之后 `pending` 为 0，循环结束。把初始值改成 5，程序处理三项后因 `processed < limit` 为假而停下，还有两项没处理。处理次数达到上限和工作全部完成，是两种不同的结束原因。

循环条件要有机会变假。如果漏掉 `pending -= 1`，待处理数量不会减少；本例仍会被次数上限停下，但没有完成声称的工作。如果同时漏掉 `processed += 1`，两个条件都不会改变，循环会一直执行。

`break` 可以立即离开当前循环；`continue` 跳过本轮剩余语句，进入下一轮。`while` 中把推进进度的语句放在 `continue` 之后，可能导致进度一直不变。

## 比较相等时会发生什么

“最多处理三项”要求在处理次数达到 3 时停止。把条件改成 `processed <= limit`，次数为 3 时仍会再执行一轮。检查 2、3、4 这些紧邻上限的值，比只看一个远小于上限的输入更容易区分 `<` 与 `<=`。

字符串比较也按实际值进行：`"Finished"` 与 `"finished"` 不相等。程序会按写下来的条件执行，不会根据作者的意图忽略大小写。

## 练习

下面程序应当处理全部三项。运行前预测每轮的 `i`，再指出为什么次数上限会被用满。把 `i += 1` 移到合适的位置，检查结果；再用空列表检查循环是否仍能正确结束。`len(statuses)` 返回元素个数，`statuses[i]` 读取下标为 `i` 的元素，下标从 0 开始。

```python run id="program-semantics.choosing-the-next-step.exercise-increment-inside"
statuses = ["finished", "failed", "finished"]
i = 0
steps = 0
while i < len(statuses) and steps < 6:
    if statuses[i] == "failed":
        print("failed at:", i)
        i += 1
    steps += 1
print("i:", i, "steps:", steps)
```
