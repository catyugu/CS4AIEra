三次仿真跑完，结果装在一个列表里：`r1` 与 `r3` 的状态是 `converged`，`r2` 的状态是 `failed`。程序从头走一遍这个列表，对每一条测试它的状态：如果状态是 `converged`，就把 `run_id` 追加进 `finished`，否则跳过。这次运行结束，`finished` 里有两个 id。我们希望用程序化的语言描述这个流程。

## 条件决定一段语句是否执行

执行到 `if` 时先求值它后面的条件，得到一个真值：真就执行它下面缩进的那一段语句，假就整段跳过，转去看下一个 `elif`；`elif` 的条件依次不成立时才执行 `else` 那一段。缩进决定每一段的边界，缩进相同且相邻的语句在同一段里。分支按书写顺序从上往下判断，第一个为真的分支执行，它之后的条件不再求值。两个条件可以在同一条记录上同时为真时，书写顺序决定哪一个生效。

程序对每一条记录做一次这样的判断：条件为真，`finished.append(run["run_id"])` 执行；条件为假，这一句跳过，程序从 `if` 那一段直接转到循环体的下一步。

## 遍历一批数据

遍历一批记录，`for` 把这件事直接写出来：

```python run id="program-semantics.choosing-the-next-step.trace"
runs = [
    {"run_id": "r1", "status": "converged"},
    {"run_id": "r2", "status": "failed"},
    {"run_id": "r3", "status": "converged"},
]
finished = []
for run in runs:
    print(run["run_id"], run["status"])
    if run["status"] == "converged":
        finished.append(run["run_id"])
print("finished:", finished)
```

`for X in 序列:` 在每次进入循环体之前把 `X` 绑定到序列里的下一个元素，然后执行下面缩进的那一段；元素取完，循环结束。递增下标、判断是否越界、在什么时刻停止，都由这条语句处理，循环体里不出现这些。

输出是 3 行迭代记录，加一行结果。第 1 行 `r1`、`converged`，条件为真，`append` 执行；第 2 行 `r2`、`failed`，条件为假，`append` 在这一条上被跳过；第 3 行 `r3`、`converged`，`append` 执行。循环转 3 圈，等于列表长度，`append` 执行 2 次，`finished` 是 `['r1', 'r3']`。哪几条记录进入 `if` 的那一支，由每一条 `status` 的取值决定。

## 收敛循环：残差与步数上限

有一类重复，转几圈事前不知道。仿真把一个残差一步步压小，压到容差以内就停；压多少步才够，取决于每一步把残差改了多少。这类重复用 `while condition:`：进入循环体之前求值条件，为真就执行缩进的那一段，执行完再在 `while` 这一行求值一次；为假就离开循环，继续执行循环体之后的语句。循环体重复几次由条件在每次求值时的取值决定。

```python run id="program-semantics.choosing-the-next-step.converge"
tolerance = 0.001
max_iterations = 20
residual = 1.0
iterations = 0
while residual > tolerance and iterations < max_iterations:
    residual = residual / 4
    iterations += 1
print(iterations, residual, residual <= tolerance)
```

条件里的两个比较用 `and` 连起来，两个都为真时整体为真，任一个为假就离开循环。条件读 `residual` 与 `iterations` 两个量；`tolerance` 和 `max_iterations` 在循环之前定好，循环里不再变。`residual` 每圈除以 4，朝 `tolerance` 靠近；`iterations` 每圈加 1，朝上限靠近，两个量都在动，条件有变假的机会。输出的 `iterations` 是 5、`residual` 是 `0.0009765625`、`residual <= tolerance` 是 `True`：条件被求值 6 次，前 5 次为真，循环体执行 5 次，第 6 次 `residual > tolerance` 已经是假，循环在这一步结束。

循环体里若没有一条语句让 `residual` 变小，`residual > tolerance` 就一直为真，条件永远等不到由它变假。把每一步的缩小幅度改小，`residual` 每圈只乘 0.9：

```python run id="program-semantics.choosing-the-next-step.stall"
tolerance = 0.001
max_iterations = 20
residual = 1.0
iterations = 0
while residual > tolerance and iterations < max_iterations:
    residual = residual * 0.9
    iterations += 1
print(iterations, residual <= tolerance)
```

输出的 `iterations` 是 20、`residual <= tolerance` 是 `False`：20 圈之后残差仍在容差之上，循环由 `iterations < max_iterations` 这一半条件停下，这一次运行没有收敛。收敛循环通常同时写两半条件：一半是收敛判据 `residual > tolerance`，一半是步数上限 `iterations < max_iterations`。上限在残差正常下降时不影响结果，它保证即使残差不再下降，程序也在有限步内停下，并把这次运行记为未收敛；列表里 `r2` 的 `failed`，就是这类在步数上限内没压到容差以内的运行。

遍历一批元素用 `for`，圈数由序列长度决定，循环体里没有推动某个量变化的语句。重复次数由循环体里算出的量决定时用 `while`，条件里至少有一个量在每圈朝使它变假的方向移动。

## 条件写错以后

条件里的比较写错，改变的是哪些记录进入哪一支。

把测试的取值写成一个在记录里不出现的字符串，例如用 `== "Converged"` 测试，而列表里存的是 `converged`：条件在每一条上求值为假，`append` 一次也没有执行，`finished` 保持为空。记录里换进 `"Converged"` 这种取值以后这一条才会成立，因此错误在输入改变之前看不出来。

同一个 `if` 链里重复测试一个取值时，写在前面、先把该取值拦下的那条条件先成立，写在它后面的同一条测试在该输入上一次也不成立，是一段永远不会执行的语句。

判断一个分支会不会被执行，把它前面的条件在该输入上依次求值，看是否有一条更早的条件已经为真。

## 练习

两段程序都在遍历同一批三次仿真记录，第二段把 `i += 1` 挪进了条件成立的那一支。第一段结束时 `failed` 是什么、`while` 循环体运行了几次？第二段的步数上限为什么会被用满、是哪一条记录造成的？

```python run id="program-semantics.choosing-the-next-step.exercise-increment-outside"
runs = [
    {"run_id": "r1", "status": "converged"},
    {"run_id": "r2", "status": "failed"},
    {"run_id": "r3", "status": "converged"},
]
failed = []
i = 0
while i < len(runs):
    run = runs[i]
    if run["status"] != "converged":
        failed.append(run["run_id"])
    i += 1
print("failed", failed, "i", i)
```

```python run id="program-semantics.choosing-the-next-step.exercise-increment-inside"
runs = [
    {"run_id": "r1", "status": "converged"},
    {"run_id": "r2", "status": "failed"},
    {"run_id": "r3", "status": "converged"},
]
failed = []
i = 0
steps = 0
while i < len(runs) and steps < 6:
    run = runs[i]
    if run["status"] != "converged":
        failed.append(run["run_id"])
        i += 1
    steps += 1
print("failed", failed, "i", i, "steps", steps)
```
