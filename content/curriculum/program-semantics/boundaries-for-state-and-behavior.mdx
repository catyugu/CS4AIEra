两个任务看板都需要保存名称和任务清单。只用两份列表也能做到；把名称、清单和添加任务的操作写在一起，可以用一个对象表示一个看板。

## 一个类可以创建多个实例

```python run id="program-semantics.boundaries-for-state-and-behavior.instance-state"
class Board:
    def __init__(self, name):
        self.name = name
        self.tasks = []

    def add(self, title):
        self.tasks.append(title)


first = Board("draft")
second = Board("release")
first.add("parse")
second.add("review")
print(first.name, first.tasks)
print(second.name, second.tasks)
print("same list:", first.tasks is second.tasks)
```

`class Board:` 创建一个类对象，绑定到 `Board`。`Board("draft")` 创建这个类的一个实例，并调用 `__init__` 初始化它。`self` 接收到这个新实例，`name` 接收到字符串 `"draft"`。

`self.name = name` 在实例上建立属性 `name`，`self.tasks = []` 建立属性 `tasks`。每次初始化都新建列表，因此两个看板各有自己的清单，最后一行打印 `False`。用点号访问属性，例如 `first.tasks`，就能取得实例保存的对象。

## 方法接收到哪个实例

`add` 是定义在类里的函数，作为实例的方法调用。`first.add("parse")` 把 `first` 作为第一个参数传入，函数体中的 `self.tasks` 因而访问第一个看板。`Board.add(first, "parse")` 也能表达这个调用。

`self` 是约定的参数名，不是一个特殊的全局对象。对第二个看板调用方法时，这次调用中的 `self` 就是 `second`。

## 类上的列表可能被多个实例共用

把 `tasks = []` 移到类体，含义会变：

```python run id="program-semantics.boundaries-for-state-and-behavior.class-body-state"
class Board:
    tasks = []

    def __init__(self, name):
        self.name = name

    def add(self, title):
        self.tasks.append(title)


first = Board("draft")
second = Board("release")
first.add("parse")
print("first:", first.tasks)
print("second:", second.tasks)
print("same list:", first.tasks is second.tasks)
```

类体中的 `tasks = []` 在创建类时执行一次，列表保存在类对象上，这叫<Term id="class-attribute">类属性</Term>。两个实例都没有自己的 `tasks` 属性，读取时就找到类上的同一个列表。一次追加使两个看板都看到 `parse`。

如果任务清单属于各个看板，就在 `__init__` 中为每个实例新建列表；如果所有看板确实要共同维护一份清单，才使用共享对象。判断依据是清单应该由谁保存和修改。

## 模块对象与命名空间

Python 文件作为模块加载时，顶层名字保存在模块的命名空间中。命名空间是一组名字到对象的对应。其他模块可以通过导入访问这些名字。

```python run id="program-semantics.boundaries-for-state-and-behavior.module-names"
import math
from math import ceil

pages = math.ceil(5 / 2)
print("pages:", pages)
print("same function:", math.ceil is ceil)
```

`import math` 在当前命名空间建立名字 `math`，指向模块对象；`math.ceil` 访问该模块的 `ceil` 属性。`from math import ceil` 则在当前命名空间直接建立名字 `ceil`，绑定到同一个函数。导入不复制函数，也不会让模块里的所有名字自动成为本地名字。

自己的文件也是如此。例如 `board.py` 顶层定义了 `Board`，其他文件使用 `import board` 后便可以调用 `board.Board("draft")`。模块命名空间避免不同文件的顶层名字直接混在一起，但不表示这些名字无法被外部访问。导入规则见 [Python 教程：模块](https://docs.python.org/3/tutorial/modules.html)。
