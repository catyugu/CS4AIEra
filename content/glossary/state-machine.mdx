term: 状态机
english: state machine
short: 用状态、事件与转移规则描述系统允许行为的模型。
related:

---

状态机用一组状态，以及事件发生时的转移规则描述系统行为。规则可以规定允许的动作、输出和后续状态，例如收到成功的初始化结果后，组件进入可以工作的状态。

状态应保存决定后续行为所需的信息。若两个阶段允许的操作不同，却用同一个状态表示，就无法仅凭这个状态判断操作是否合法。

状态机可以作为规约，也可以实现成程序。图与状态表给出规则；某个实现是否遵守这些规则，还需要检查转移与实际动作。
