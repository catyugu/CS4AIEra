term: 源
english: origin

  - 同源
short: HTTP 与 HTTPS URL 的协议、主机和有效端口组成的身份。
related: []
---

对于通常的 HTTP 与 HTTPS URL，源由协议标识（如 http 或 https）、主机和有效端口组成。这三项相同的 URL 是同源的；路径和查询参数不参与比较。未写出的端口按相应协议的默认端口处理。

例如 `https://example.com/a` 和 `https://example.com/b` 同源，`http://example.com/a` 则与它们不同源。浏览器用源划分访问权限；两个主机即使解析到同一个 IP 地址，也不会因此同源。其他种类 URL 的源可能有不同规则，见 [MDN：同源策略](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Same-origin_policy)。
