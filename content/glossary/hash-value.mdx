---
id: hash-value
term: 哈希值
english: hash value
short: 按某种规则由对象计算出的值，可用于缩小查找范围，但不保证唯一。
---

哈希值由对象按某种规则计算得到。哈希表利用它选择查找位置，再通过相等比较确认是否找到了所需的键。不同对象可能得到相同的哈希值，这称为哈希碰撞。

Python 字典键和集合元素必须可哈希：对象在使用期间的哈希值不能改变，比较相等的对象还必须有相同的哈希值。整数和字符串可以使用；列表不能直接使用。元组能否使用取决于其中的元素是否都可哈希。

这里的哈希值用于数据查找，不承诺保密、防篡改或跨次运行稳定，不能代替唯一编号或密码学摘要。规则见 [Python 术语表：可哈希](https://docs.python.org/3/glossary.html#term-hashable)。
