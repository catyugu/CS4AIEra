聚合函数接收一组行并返回一个值：`COUNT`、`SUM`、`AVG`、`MIN`、`MAX`、`group_concat`。没有 `GROUP BY` 时整张结果集是一组；有 `GROUP BY` 时每组一行。计数对象由参数决定：`COUNT(*)` 数行，`COUNT(column)` 数该列非空的行，`COUNT(DISTINCT column)` 数不同的非空值，三者的分母互不相等。

`SUM`、`AVG`、`MIN`、`MAX` 忽略 NULL 输入，输入为空或全为 NULL 时返回 NULL，`COUNT` 在这两种情形都返回 0——把 NULL 渲染成 0 会丢掉「没有数据」这个信息。`AVG` 在 SQLite 中返回浮点数，涉及金额时应先 `SUM` 再按规则舍入。聚合结果只能出现在 `HAVING`、`SELECT` 与 `ORDER BY` 中；`WHERE` 在分组之前求值，那里没有聚合结果，把行级条件写进 `HAVING` 会让聚合包含本该排除的行。

组由数据行产生，因此 `GROUP BY` 下没有行的组不会出现；要得到零计数的分组需要左外连接。连接改变行数，在连接结果上聚合会把计数或金额按匹配行数放大，需要按正确粒度聚合，或先用子查询、CTE 按各自粒度聚合再连接。
