## 定义

聚合函数接收一组行并返回一个值：`COUNT`、`SUM`、`AVG`、`MIN`、`MAX`、`group_concat`。没有 `GROUP BY` 时整张结果集是一组；有 `GROUP BY` 时每组一行。

## 适用范围

- `COUNT(*)` 数行，`COUNT(column)` 数该列非空的行，`COUNT(DISTINCT column)` 数不同的非空值，三者的分母互不相等。
- `SUM`、`AVG`、`MIN`、`MAX` 忽略 NULL 输入；输入为空或全为 NULL 时返回 NULL，`COUNT` 返回 0。
- `AVG` 在整数列上返回浮点数，涉及金额时应先 `SUM` 再按规则舍入。
- 聚合结果只能出现在 `HAVING`、`SELECT` 与 `ORDER BY` 中；`WHERE` 在分组之前求值，那里没有聚合结果。
- 连接改变行数，在连接结果上聚合会把计数或金额按匹配行数放大，需要按正确粒度聚合。

## 判据

- **分母是什么**：指标定义要写明计数对象与 NULL 处置。
- **空输入返回什么**：区分 NULL 与 0；把 NULL 渲染成 0 会丢掉「没有数据」这个信息。
- **分组的来源**：组由数据行产生，因此 `GROUP BY` 下没有行的组不会出现；要得到零计数的分组需要左外连接。

## 常见误用

- 在连接结果上直接求和，导致金额重复计入。
- 在 `HAVING` 中写行级条件，改变聚合所包含的行。
- 依赖 `AVG` 的浮点结果做金额对账。
