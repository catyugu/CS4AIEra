term: 拓扑序
english: topological order
aliases:
  - topological order
short: 把有向图的全部顶点排成线性序列，使每条边都从前指向后。
related:
  - cycle
---

拓扑序是有向图全部顶点的一个线性排列，满足：对每条边 $(u, v)$，$u$ 排在 $v$ 之前。

存在拓扑序等价于无环。有环时不存在这样的排列；一次正确的拓扑排序过程排不完、停在剩下的顶点上。

空图没有顶点，空排列就是它唯一的拓扑序。

拓扑序通常不唯一：某一步在入度为零的候选里有多个选择时，先取哪一个都行。
