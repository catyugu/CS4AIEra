term: 拓扑序
english: topological order
aliases:
  - topological order
short: 把有向图的全部顶点排成线性序列，使每条边都从前指向后。
related:
  - cycle
---

拓扑序是有向图全部顶点的一个线性排列，满足：对每条边 $(u, v)$，$u$ 排在 $v$ 之前。

存在拓扑序与无环是同一件事。有环时不存在这样的排列，因此排出顺序失败本身就是环检测的结果。空图没有顶点，空排列就是它唯一的拓扑序。拓扑序通常不唯一：某一步在入度为零的候选里有多个选择时，先取哪一个都行。

拓扑序是依赖关系的线性化，它只说「谁必须在谁之前」，不比较没有边相连的顶点。
