---
id: input-size
term: 输入规模
english: input size
aliases:
  - 规模度量
  - size measure
short: 复杂度论断里度量输入的那个量；元素个数、位数、顶点数与边数是不同选择，换度量就换增长率。
related: []
---

输入规模是成本论断的自变量：说成本随 $n$ 增长，必须同时说清 $n$ 是哪个量。元素个数是最常见的选择，但不是唯一的选择，也不总是正确的选择。

度量方式随问题而变：图算法通常同时用顶点数与边数，字符串匹配同时依赖文本长度与模式长度，矩阵运算要说明度量的是边长还是元素个数。同一段代码换一种度量，增长阶可以完全不同，因此规模度量属于结论的一部分，不能事后补。
