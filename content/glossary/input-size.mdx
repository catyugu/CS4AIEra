term: 输入规模
english: input size
aliases:
  - 规模度量
  - size measure
short: 复杂度论断里度量输入的那个量；元素个数、位数、顶点数与边数是不同选择，换度量就换增长率。
related: []
---

输入规模是成本分析中用于度量输入大小的量。若用 $n$ 表示规模，需要同时说明它是元素个数、文本长度，还是其他量。

一个问题也可能需要多个量。例如每条记录有 $m$ 个指标、共有 $n$ 条记录，逐项求和的工作量取决于 $nm$。改变规模的度量方式，增长关系也可能改变，因此它是成本结论的一部分。
