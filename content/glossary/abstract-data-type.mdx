term: 抽象数据类型
english: abstract data type
aliases:
  - ADT
short: 由一组操作及各自规约定义的类型；内部怎么存不属于规约。
related:

---

抽象数据类型由一组操作和这些操作应当满足的规定定义，不指定内部怎样存储。例如映射提供按键保存和读取值的操作，优先队列提供按优先级取出最值的操作。

同一种抽象数据类型可以有不同实现，操作结果相同，成本却可能不同。因此“这是映射”说明能按键取值，不能单凭这个名称就推出每次查找只需固定时间。具体语言还可能补充保证，例如 Python 字典保持插入顺序；这不是所有映射都必须提供的行为。
