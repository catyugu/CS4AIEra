CPython 是用 C 实现的 Python 解释器，也是语言的参考实现。语言规范（Language Reference 与数据模型）定义语言的语义；CPython 在这些语义之上有一批实现选择，例如对象的内存布局、小整数缓存、字符串驻留、引用计数与哈希算法。判断一条论断属于哪一层：语言参考中有对应条款的属于语言保证，只在实现文档、发布说明或源码中出现的属于实现行为。

同一段代码在不同实现（CPython、PyPy 等）与不同构建（如无 GIL 构建）上的可观察行为可以不同，因此把「CPython 当前如此」写成「Python 如此」并据此作出跨实现的结论是常见的误用。依赖引用计数即时回收对象来释放资源，在换实现或出现引用环之后同样会失效。

本课程的可执行单元格运行在一份编译为 WebAssembly 的 CPython 构建（Pyodide）上：语言语义与 CPython 一致，平台层（进程、网络、持久文件系统）不完整。
