应用程序接口（API）是组件向其他代码或程序提供的使用方式，包括可调用的操作及其约定。一个库函数可以是 API，进程间的一组消息也可以是 API。

函数名和参数列表只描述接口的一部分。使用者还需要知道允许的输入、结果含义、是否修改状态，以及哪些失败会怎样报告。内部实现可以改变，但使用者依赖的约定需要保持或明确变更。

API 不限于网络服务。协议则进一步规定参与方怎样交换消息、交互次序是否合法；同一个 API 可以通过不同协议或本地调用形式提供。
