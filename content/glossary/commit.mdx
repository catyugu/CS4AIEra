term: 提交
english: commit
short: Git 中记录项目快照、父提交及相关元数据的对象。
related:

---

Git 提交记录项目在某一时刻的快照，以及父提交、作者和提交说明等信息。普通提交通常有一个父提交，合并提交可以有多个父提交。

每个提交都有根据内容计算出的标识。修改快照、父关系或其他提交信息，会得到不同的标识；分支名则指向某个提交，并能随着后续提交向前移动。因此记录精确版本时，应使用提交标识。提交与快照的内部关系见 [Pro Git：Git 对象](https://git-scm.com/book/en/v2/Git-Internals-Git-Objects)。
