term: 合并基点
english: merge base
aliases:
  - 最佳共同祖先
short: Git 用于三方合并和分支比较的最佳共同祖先提交。
related:
  - commit
---

对于两个 Git 提交，它们的合并基点是用于三方合并的最佳共同祖先。若一个共同祖先是另一个共同祖先的祖先，后者更适合作为基点。

简单分叉历史通常只有一个最佳共同祖先，复杂合并历史可以有多个。基点到分支头的变化帮助区分两条分支各自引入的改动。定义见 [Git：merge-base](https://git-scm.com/docs/git-merge-base)。
