IP 为分组提供源地址与目的地址，并规定网络设备解释和转发分组所需的信息。IPv4 与 IPv6 是不同版本，它们使用不同的地址长度和分组格式。

IP 地址标识网络接口，端口则由传输协议区分通信端点。域名是可解析的名称，可能对应多个 IP 地址，也可能随时间指向不同地址；名称、地址和端口承担不同职责。

IP 的基本服务不承诺分组必达或按顺序到达。需要这些性质的应用还要使用提供相应保证的传输或应用协议。IPv6 的格式见 [RFC 8200](https://www.rfc-editor.org/rfc/rfc8200.html#section-3)。
