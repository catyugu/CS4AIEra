term: DNS
english: Domain Name System
aliases:
  - 域名系统
short: 用分层名称空间和资源记录提供名称查询的分布式系统。
related:

---

DNS 用分层的域名组织名称空间，并通过资源记录回答查询。常见记录把域名关联到 IPv4 或 IPv6 地址，DNS 也可以保存其他类型的信息。

域名不要求和一台机器一一对应：一个名称可以返回多个地址，多个名称也可以使用同一地址。查询结果可以按记录的生存时间缓存，因此修改记录不会让所有客户端立即看到新值。

名称查询成功只提供记录内容，不证明目标服务在线。名称空间与缓存规则见 [RFC 1034](https://www.rfc-editor.org/rfc/rfc1034.html#section-3)。
