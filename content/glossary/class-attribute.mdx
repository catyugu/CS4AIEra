类属性是在类体中定义的属性，属于类对象；实例属性通过 `instance.name = value`（通常在 `__init__` 中）创建，属于单个实例。两者可能按同一个名称访问到，但存储在不同地方。

读取 `instance.name` 时，普通数据属性的解析顺序是：先查实例的 `__dict__`，再沿类型的方法解析顺序（MRO）查类字典，某一层都找不到则抛 `AttributeError`。这个顺序对数据描述符（data descriptor，定义了 `__get__` 与 `__set__` 或 `__delete__` 的属性）不成立——它的优先级高于实例字典，属性查找先交给它，实例属性只有在没有数据描述符拦截时才直接可见。方法也是类属性，它是非数据描述符，实例字典可以遮蔽它。

赋值总发生在实例上：`instance.name = value` 创建实例属性，类属性不变；`Class.name = value` 改类属性，已有实例中凡是自己持有一份实例属性的仍读到自己的值。不可变的类属性（数字、字符串、元组）可以安全地作为所有实例共用的默认值；可变的类属性（列表、字典、集合）被所有实例共享同一个对象，任一个实例通过它写入，其余实例都观察得到，`a.attr is b.attr` 为真就说明两个实例看到同一个对象。需要每个实例各自一份的可变状态应放在 `__init__` 里赋给 `self`，确实要全类共享的常量或缓存才放类体。

用 `__slots__` 的类不提供实例 `__dict__`，未声明的属性赋值会失败，因此拼写错误会被拒绝。
